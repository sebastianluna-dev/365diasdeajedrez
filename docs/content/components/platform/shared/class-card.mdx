## Purpose

The one way a class is drawn for the student, from data the mapper already decided (`mapClassCard`): the title is a link stretched over the whole card, and what sits above it — the join card's button, the link of a moved seat — keeps its own `z-index`, so nothing interactive is nested. Featured, it is today's or the next class with how to join it; compact, a row of «Próximas» or «Pasadas». A past class says whether they came (`UserCheckIcon`, «Asististe» or «No asististe»), whether there is a recording (`CircleVideoIcon`) and how many blocks there are (`LayerGroupIcon`, «4 bloques»); ahead, «2 para preparar». A group class names the classmates («Grupal, con Mateo Ríos, Diego Salas y Lucía Herrera»). A moved seat says where it went («No asististe · tu clase pasó al vie 9 oct», a link to the new class) or that it went back («… volvió a tu pago»); a make-up says which class it replaces; a cancelled class steps back in its greys, not in an opacity.

`UnscheduledClassCard`, in the same file, is the row of a class bought without a date: «Clase por programar · de tu pago del 1 de octubre» and «Administración te escribirá para fijar la fecha.», on the soft surface, with `CalendarClockIcon` and no link.

## Props

| Prop      | Type                      | Required | Meaning                                                                                                     |
| --------- | ------------------------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `card`    | `ClassCardData`           | yes      | What the mapper gives: the phase, when, the people line, the visible blocks, the join data, the past facts. |
| `variant` | `"featured" \| "compact"` | yes      | The card with the join card, or the row of a list.                                                          |

`UnscheduledClassCard` takes `item: UnscheduledClassData` (`paymentId`, `label`).
