## Purpose

Platform forms are `<form action={serverAction}>` and return failure by **redirect** with `?error=<code>` on the same URL. The page reads the code, looks it up in its message map (a code outside the map renders nothing, so a crafted link cannot put text on the page) and renders the message here. Success messages use the same component with `variant="success"`.

The parameter is said once. [`ClearResultParams`](/components/platform/sections/shell/clear-result-params), in the shell, takes it out of the address once the page has drawn it: the notice stays on screen, and the next render of the page — another action that revalidates, a reload — no longer carries it.

The live role follows the tone (2026-10-15): `role="alert"` on an error, so a screen reader announces it on return from the submit without the user having to look for it; `role="status"` on a success or a piece of information, read when the reader is free; none on a warning, which is part of the page («Sin zona horaria configurada: …») and is read where it is.

## Props

| Prop      | Type                                          | Required               | Meaning                                   |
| --------- | --------------------------------------------- | ---------------------- | ----------------------------------------- |
| `message` | `string`                                      | yes                    | The text, already translated by the page. |
| `variant` | `"error" \| "success" \| "info" \| "warning"` | no · default `"error"` | Colour, border and live role.             |

## Behaviour

None; a single `<p>`.

## Markup & styling

Block `.platform-notice` (31 lines).

**Modifiers and states:** `.platform-notice_variant_error`, `.platform-notice_variant_success`, `.platform-notice_variant_info`, `.platform-notice_variant_warning` (the warning ink on its soft fill)

**Tokens:** `--platform-danger`, `--platform-danger-border`, `--platform-danger-soft`, `--platform-success-ink`, `--platform-success-border`, `--platform-success-soft`, `--platform-surface-neutral`, `--platform-border`, `--platform-text-muted`

No media queries.

## Usage

From `components/platform/sections/staff/courses/course-editor.section.tsx`:

```tsx
import { PlatformNotice } from "@/components/platform/shared/platform-notice/platform-notice.comp";

{
  errorMessage && <PlatformNotice message={errorMessage} />;
}
```

The page side, from a staff page:

```tsx
const errorMessage = STAFF_ERROR_MESSAGES[readParam(params, "error")];
```
