## Purpose

The twin of `PlatformChoiceCards` for a set instead of one: when a course teaches two or three things out of eight and each deserves a line of explanation, a row of cards shows what a list of checkboxes hides. Every card is a checkbox (`role="checkbox"`) on Radix's `Checkbox` primitive, so each one is a tab stop, Space toggles it, and inside a form every chosen card submits through the hidden native checkbox the primitive keeps in sync: `formData.getAll(name)` reads the set, which is what `parseForm` does for an array field (`formCodeList`).

It is a sibling of `PlatformChoiceCards` and not a mode of it: a radio group is one tab stop with one value and can be `required`; a checkbox group is many of each, and "at least one" is the form's rule, not the browser's.

## Props

| Prop              | Type                         | Required | Meaning                                                                                                                                                                                                               |
| ----------------- | ---------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `options`         | `PlatformChoiceCardOption[]` | yes      | `{ value, label, meta?, description?, icon? }` per card, in order. `meta` is a short fact between the label and the description (a range, a figure). The icon is decorative.                                          |
| `name`            | `string`                     | no       | Name of the hidden native checkboxes, one per chosen card.                                                                                                                                                            |
| `value`           | `string[]`                   | no       | Controlled set.                                                                                                                                                                                                       |
| `defaultValue`    | `string[]`                   | no       | Initial set.                                                                                                                                                                                                          |
| `onValueChange`   | `(values: string[]) => void` | no       | Called with the whole new set.                                                                                                                                                                                        |
| `layout`          | `"stacked" \| "line"`        | no       | `stacked` (default): label, meta and description piled up, as many columns as fit. `line`: two columns and each card's text on a single line, the meta beside the label; for options that are a name and little else. |
| `disabled`        | `boolean`                    | no       |                                                                                                                                                                                                                       |
| `aria-labelledby` | `string`                     | no       | Id of the element that names the group. `PlatformFormGroup` sets it.                                                                                                                                                  |
| `aria-label`      | `string`                     | no       | A name when there is no visible label.                                                                                                                                                                                |

## Behaviour

- A chosen card carries `data-state="checked"` from the primitive; the stylesheet gives it the accent border and wash, paints its description in the accent ink and fills the mark in its corner.
- The mark (`Checkbox.Indicator` with `forceMount`) is always in the DOM: an empty ring when off, the accent disc with the tick when on, so nothing shifts on toggle.
- Clicking anywhere on a card toggles it; Space toggles the focused one; Tab moves between cards.
- Uncontrolled by default (`defaultValue`); with `value` the parent owns the set, which the «Nuevo curso» form uses to keep its submit off until one card is chosen.

## Markup & styling

Block `.platform-check-cards`, a grid of `repeat(auto-fit, minmax(170px, 1fr))` at `width: 100%` (so it fills a `FormFieldset`'s flex row; the fieldset takes `frame="none"`, because the cards are already boxes): as many cards per row as fit, one column on a phone.

**Elements:** `.platform-check-cards__card`, `.platform-check-cards__mark`, `.platform-check-cards__mark-icon`, `.platform-check-cards__icon`, `.platform-check-cards__label`, `.platform-check-cards__meta`, `.platform-check-cards__description`

**Modifiers and states:** `.platform-check-cards_layout_line` on the block: `repeat(2, minmax(0, 1fr))`, the card as a row aligned on the baseline, the mark centred vertically, `white-space: nowrap` with an ellipsis on the label, and one column under 620px.

**States (data attributes set by the primitive):** `[data-state="checked"]`, `[data-disabled]` on a card.

**Tokens:** `--platform-accent`, `--platform-accent-ink`, `--platform-accent-soft`, `--platform-accent-wash`, `--platform-border`, `--platform-border-strong`, `--platform-surface`, `--platform-surface-soft`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`

**Breakpoints:** none in the default layout, where the grid reflows on its own; `(max-width: 620px)` takes the `line` layout from two columns to one. Transitions are off under `prefers-reduced-motion`.

## Usage

From `components/platform/sections/staff/courses/new-course/new-course-form.comp.tsx`:

```tsx
<PlatformFormGroup label="Contenido (selecciona al menos uno)">
  <PlatformCheckCards
    name="contentTypeCodes"
    value={contentTypeCodes}
    onValueChange={setContentTypeCodes}
    options={contentTypes.map((type) => ({ value: type.code, label: type.label, description: type.description }))}
  />
</PlatformFormGroup>
```
