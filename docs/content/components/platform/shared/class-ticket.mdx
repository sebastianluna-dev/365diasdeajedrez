## Purpose

The owner's design for the student's upcoming classes (2026-10-15, «8 · Boletos y tarjetas, sin pagos»): every class ahead is a ticket, and it stays one until the class is over and counts as finished, when [`PastClassCard`](/components/platform/shared/past-class-card) takes over. The stub keeps the day («Hoy · jue 15 oct», «Mañana · vie 16 oct», «Dom 18 oct»), the start in the display face, «→ 13:00» and how long it lasts («1 h», «1 h 30», `formatClassLength`); a dotted perforation with a notch at each end separates it from the class. The class: its phase (`ClassStatusTag`), how long until it starts — `MeetingCountdown` for today's class (it ticks and asks for the page again when the link opens), «El enlace se abre a las 09:30» for a later day, «Administración agregará el enlace» without a link —, the topic as the link to the class, a make-up's line, and the fields «Profesor», «Sala» (the provider, «En línea» or «Por confirmar») and «Tipo» («Individual» or «Grupal»), with «Compañeros» as initials for a group class (their names are the faces' accessible name). The foot is how to get in: while the link is open, «Entrar a la clase» (the one accent button; «Volver a entrar» in the half hour after the end) and the link to copy; before, «Ver la clase»; and «N para preparar», a link to the class page's «Para preparar».

What a ticket never shows: the class's content (no board, no summary, no material — that waits for the class to end), and which payment the class belongs to (no «Clase 2 de 4», no «de tu pago del …»). Today's stub is the only tinted one (`--platform-accent-wash`); a later day's sits on the neutral fill. A cancelled class strikes its hours through and offers no way in.
