## Props

| Prop     | Type                                          | Required | Meaning                                         |
| -------- | --------------------------------------------- | -------- | ----------------------------------------------- |
| `series` | `{ title, description } \| null`              | yes      | The series as stored; `null` for «Nueva serie». |
| `save`   | `(prev, formData) => Promise<PopupFormState>` | yes      | Through `useActionState`.                       |

`NewSeriesButton` takes only `save`; `EditSeriesButton` takes both.

## Behaviour

The [popup-form pattern](/conventions#server-actions): «Título» (required, 120 characters) and «Descripción» (optional, 1000, «La leen tus alumnos antes de empezar.»), and the fields open again with what was sent when the server refuses. «Crear serie» creates it and the action itself goes to the new series with `?aviso=seriesCreated`; «Guardar la serie» answers `seriesSaved`, and the host closes the popup and puts the notice in the address.
