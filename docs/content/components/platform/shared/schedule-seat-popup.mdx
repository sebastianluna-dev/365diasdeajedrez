## Purpose

A class a student paid for and that has no date yet («por programar») gets one here, without leaving the student's record: in a new class of their own, dated with their rhythm, or in a group class that still has a seat. The seat spends the payment it belongs to, never another.

## Props

| Prop                                 | Type                                                                     | Required | Meaning                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------ | -------- | ----------------------------------------------------------------------------- |
| `paymentId`                          | `string`                                                                 | yes      | The payment the seat spends.                                                  |
| `studentName`                        | `string`                                                                 | yes      | «Programar una clase de Alumno Demo».                                         |
| `seatLabel`                          | `string`                                                                 | yes      | «Clase 4 de 4 del pago del jue 1 oct · Profesor: GM Profesor Demo».           |
| `teachers`                           | `TeacherOption[]`                                                        | yes      | The active teachers.                                                          |
| `rhythm`                             | `RhythmDefaults`                                                         | yes      | What the new class opens with: the student's teacher, day, hour and duration. |
| `groupClasses`                       | `OpenGroupClassOption[]`                                                 | yes      | The group classes ahead, with their seats and why one cannot be chosen.       |
| `timeZone`, `nowIso`                 | `string`                                                                 | yes      | The academy's zone, and when the page was read.                               |
| `scheduleSeat`                       | `(paymentId, prev: PopupFormState, formData) => Promise<PopupFormState>` | yes      | The server action; a stub in Storybook.                                       |
| `launcherLabel`, `launcherClassName` | `string`                                                                 | no       | The button that opens it («Programar», a small button).                       |

## Behaviour

The form follows the [popup-form pattern](/conventions#server-actions): `useActionState`, the fields open again with what was sent when the action fails (the field's message under it), and on `status: "done"` the host closes the popup and replaces the address with `?aviso=seatScheduled.<minutes>.<duration>`, which the page says as «Clase programada: mié 21 oct · 12:00–13:00.». The content is remounted on every use (its key moves in the popup's `onClose`). The line under the fields says when the class will be, in the academy's zone, as the fields change.

```tsx
<ScheduleSeatPopup
  paymentId={payment.id}

  seatLabel={label}
  teachers={teachers}

  groupClasses={groupClasses}

/>
```
