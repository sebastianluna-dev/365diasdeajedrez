| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/platform-switch/platform-switch.comp.tsx`                                                                                      |

## Purpose

An on/off that **takes effect the moment it is pressed**, with no button to save it: the lesson outline's «Sólo lecciones de prioridad», which until 2026-10-06 was a button drawn as a checkbox. What is saved with a form's button is a [`PlatformCheckbox`](/components/platform/shared/platform-checkbox), not this: a switch promises that pressing it is the whole act.

The whole row is the switch (the «C» of the 2026-10-06 checkbox study): it needs the width of a column, so it goes where a setting has a line of its own, not in a toolbar. The game viewer's engine toggle, a pill in a crowded head drawn by `components/chess` for the site too, keeps its own.

## Props

| Prop              | Type                         | Required | Meaning                                                                                                                                                                                                                                                               |
| ----------------- | ---------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

It is the switch's name (`aria-labelledby`).                                                                                                                                                                             |
| `hint`            | `string`                     | no       | A line under the label: what switching it on does. It is the switch's description (`aria-describedby`).                                                                                                                                                               |
| `name`            | `string`                     | no       | Name of the hidden native checkbox, for a switch inside a form.                                                                                                                                                                                                       |
| `form`            | `string`                     | no       | Id of the form it belongs to, when it is drawn outside it.                                                                                                                                                                                                            |
| `checked`         | `boolean`                    | no       | Controlled state.                                                                                                                                                                                                                                                     |
| `defaultChecked`  | `boolean`                    | no       | Initial state.                                                                                                                                                                                                                                                        |
| `onCheckedChange` | `(checked: boolean) => void` | no       | Called with the new state: where the effect is set off (the outline submits its form here).                                                                                                                                                                           |
| `disabled`        | `boolean`                    | no       |                                                                                                                                                                                                                                                                       |
| `tone`            | `"selection" \| "accent"`    | no       | The colour of a switch that is on and of its focus ring. `selection` (default) is the blue of filling in a form; `accent` the brand's red, for a setting of a screen one studies on, outside any form to fill in — the lesson outline's priority filter (2026-10-06). |
| `layout`          | `"row" \| "inline"`          | no       | `row` (default): the whole row is a card, grey when off and lifted when on. `inline`: the label and a smaller switch on the line they sit on, with no card, for a setting tucked under a heading — the lesson outline's filter (2026-10-06).                          |
| `className`       | `string`                     | no       | The host's class for the row, to lay it out where it goes.                                                                                                                                                                                                            |

## Behaviour

- The row is the primitive's button (`role="switch"`): a click anywhere on it switches it; Space and Enter from the keyboard.
- It does not save anything by itself. `onCheckedChange` is where the host acts; the outline's `PriorityLessonsFilter` submits its form there (`requestSubmit()`), so the server action still writes the preference and draws the page again.
- **It starts again from what was saved.** It is mounted under the value it opens with (`savedValueKey(defaultChecked)`): after the action, React resets the form and the primitive would go back to the value it was mounted with; a new value mounts it anew from that.

## Markup & styling

Block `.platform-switch`, holding the hidden native checkbox; the row is `.platform-switch__control`, the label and the hint at the left and the track at the right. **Off**, the row sinks into the neutral grey (`--platform-surface-neutral`) and the track is grey; **on**, it is the white of a card lifted off what holds it (`--platform-shadow-lift`) and the knob has crossed onto the selection's blue (`--platform-selection`). The hint is in the muted grey on the grey row and in the subtle one on the white, each the grey that reads on its fill.

**Elements:** `.platform-switch__control` (the primitive's button), `.platform-switch__text`, `.platform-switch__label`, `.platform-switch__hint`, `.platform-switch__track`, `.platform-switch__thumb` (the primitive's thumb)

**Modifiers:** `.platform-switch_tone_accent` on the block (`tone="accent"`): the track of a switch that is on and the focus ring in the accent (`--platform-accent`, `--platform-accent-ink`) instead of the selection's blue. `.platform-switch_layout_inline` on the block (`layout="inline"`): no padding, border, fill nor shadow on the row in either state, the label at `--platform-type-xs` in the muted grey, a 32×18 track and a 12px knob.

**States (data attributes set by the primitive):** `[data-state="checked"]` on the row and the thumb, `[data-disabled]` on the row.

**Tokens:** `--platform-accent`, `--platform-accent-ink`, `--platform-border`, `--platform-border-strong`, `--platform-selection`, `--platform-shadow-lift`, `--platform-surface`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`, `--platform-text-subtle`

No media queries. The knob's slide and the colour transitions are off under `prefers-reduced-motion`.

## Usage

From `components/platform/sections/courses/lesson-view/priority-lessons-filter.comp.tsx`:

```tsx
<form ref={formRef} action={action} className="lesson-outline__filter">
  <CurrentPathField name="returnTo" />
  <PlatformSwitch
    label="Sólo lecciones de prioridad"
    defaultChecked={enabled}
    onCheckedChange={() => formRef.current?.requestSubmit()}
  />
</form>
```
