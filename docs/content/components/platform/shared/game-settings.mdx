## Purpose

What Lichess keeps behind the gear of a study's chapter, for a game of a study: its name, and the three things that destroy — its annotations, its variations, the game itself. It was added on 2026-10-04, when the list of games became a list of names; before, a game was renamed through its whole record (`EditGame`) and only the game on screen could be deleted.

Lichess's dialog has three more settings that the platform has no data for yet, and they are **not** here: the board's orientation, the analysis mode (normal, practising against the computer, hiding the next moves, an interactive lesson) and a pinned comment. Each needs a column on `Game`, and the modes a feature of their own.

## Props

| Prop        | Type                  | Required | Meaning                                                                                                                                                                     |
| ----------- | --------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `game`      | `GameSettingsGame`    | yes      | `{ id, name, title? }`: `name` is what the list calls it; `title` the name it was given, absent while it is shown by its players.                                           |
| `isCurrent` | `boolean`             | yes      | Whether it is the game on screen: after a clean-up the page is loaded again (see below).                                                                                    |
| `actions`   | `GameSettingsActions` | yes      | `{ rename(gameId, formData), clearAnnotations(gameId), clearVariations(gameId), remove(gameId, formData) }`, server actions already bound to the study the game belongs to. |

## Behaviour

- **The gear** is a button named «Ajustes de «…»» after the game, always drawn — on a touch screen nothing would bring it out —, that opens a native `<dialog>` named by its title, «Ajustes de la partida», with the focus on the name: left to the browser it would land on the close button, the first control of the dialog.
- **Nombre.** A `PlatformForm` over `rename`, its field `title`: it starts from the game's own name, or empty with the pairing as its placeholder; saved empty, the game goes back to being shown by its players. The dialog closes on submit. The field is keyed by the saved name, so reopened after a save it starts from what was saved.
- **«Eliminar anotaciones», «Eliminar variantes», «Eliminar partida»** are three words in the danger ink under a rule. None acts at once: each swaps the dialog's body for its confirmation — what goes, what stays, «Esta acción no se puede deshacer» — with «Cancelar» and the button that does it. Annotations are the comments and what lives inside them (arrows, marked squares, evaluations), the signs and the opening comment; the moves and the variations stay. Variations leave the main line alone.
- **A clean-up of the game on screen reloads the page.** The two clean-ups rewrite the PGN on the server (`clearGameAnnotations`, `clearGameVariations`), while the game's page holds its own copy in the browser, with its undo history and its autosave: left there, the next autosave would write the old PGN back. So with `isCurrent` the page is loaded again once the action settles; for any other game the dialog just closes.
- **Deleting** hands the form to `remove`, which sends the browser on. A game cited in a class is not deleted from here: `deleteStudyGame` bounces to that game's page with its notice, where `DeleteGame` asks for the explicit confirmation it needs.

## Usage

From `components/platform/shared/game-list/game-list.comp.tsx`:

```tsx
{
  settings && <GameSettings game={game} isCurrent={isCurrent} actions={settings} />;
}
```

and the actions, from `components/platform/sections/studies/game-view/game-aside.comp.tsx`:

```tsx
<GameList
  games={study.games.map(listItem)}
  currentId={game.id}
  settings={{
    rename: renameStudyGame.bind(null, study.id),
    clearAnnotations: clearGameAnnotations.bind(null, study.id),
    clearVariations: clearGameVariations.bind(null, study.id),
    remove: deleteStudyGame.bind(null, study.id),
  }}
/>
```
