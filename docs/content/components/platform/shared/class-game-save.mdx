## Purpose

The student keeps a game their teacher showed in class: the button («Guardar en un estudio», `BookmarkPlusIcon`) and the popup, a sibling, that asks for the study and a name. The action is `saveClassGameToStudy(classId, blockId, formData)` (`services/classes/classes.actions.ts`), handed down from the page as a prop and bound here to the class and the block: it copies the block's game — its PGN, players and result — as a `Game` of the chosen study, indexed in the same transaction, and comes back to the class with `?aviso=gameSaved.<studyId>.<gameId>`, which the page reads as «Partida guardada en «Mis partidas».» with «Ver la copia». The class keeps its game. No component with a story imports the action.

| `studies` | `{ id: string; name: string }[]`                                          | yes      | The student's own studies (`getOwnStudyOptions`). |
| `action`  | `(classId: string, blockId: string, formData: FormData) => Promise<void>` | yes      | `saveClassGameToStudy`.                           |
