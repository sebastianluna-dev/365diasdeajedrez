# `CopyLinkButton`

|            |                                                                                                                                                |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/copy-link-button/copy-link-button.comp.tsx`                                                                        |
| Kind       | Client Component                                                                                                                               |
| Stylesheet | `copy-link-button.comp.css` → block `.copy-link-button` (the button is a `.platform-button`)                                                   |
| Story      | `copy-link-button.stories.tsx` (`platform/shared/CopyLinkButton`): at rest, large, copied (`play`)                                             |
| Used by    | The class sheets, beside the meeting link (phases 5–6 of the rebuild); [`ClassTicket`](/components/platform/shared/class-ticket) (`size="lg"`) |
| Uses       | `CopyIcon` and `CheckIcon` in Classic Solid                                                                                                    |

## Purpose

The meeting link is copied more often than opened by whoever manages the class. One press, two seconds of «copied», and back.

## Props

| Prop    | Type           | Required | Meaning                                                                                                                      |
| ------- | -------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `url`   | `string`       | yes      | What goes to the clipboard.                                                                                                  |
| `label` | `string`       | yes      | The accessible name: «Copiar el enlace de la reunión».                                                                       |
| `size`  | `"sm" \| "lg"` | no       | `sm` (default): quiet and small, beside a line of text; `lg`: the secondary box at 48px, beside a large «Entrar a la clase». |

## Behaviour

- `navigator.clipboard.writeText`; where it is not available (an insecure context) the button does nothing it cannot do.
- For two seconds the icon is the tick in the success ink and a visually hidden `role="status"` says «Enlace copiado».

## Markup & styling

Block `.copy-link-button` (20 lines).

**Elements:** `.copy-link-button__done` (the tick's colour), `.copy-link-button__status` (visually hidden)

**Tokens:** `--platform-success-ink`

No media queries.

## Usage

```tsx
<CopyLinkButton url={cls.meetingUrl} label="Copiar el enlace de la reunión" />
```
