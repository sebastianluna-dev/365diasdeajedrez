## Purpose

A COPY into one of the person's own studies, where it becomes a study's game like any other — indexed, found by the explorer —, and whatever it came from stays where it was. The study (`PlatformSelect` over the person's own studies, the first chosen) and a name (empty: the one proposed, «Ana Torres – Don Chuy»), «Guardar» («Guardando…»), and the action redirects to the new game. Without a study of one's own it says where to make one instead. A played game's page passes the action bound to the game; the analysis board passes `saveAnalysisToStudy` and its PGN, sent in a hidden field.

## Props

| Prop           | Type                                  | Required | Meaning                                                              |
| -------------- | ------------------------------------- | -------- | -------------------------------------------------------------------- |
| `ref`          | `Ref<PlatformPopupHandle>`            | yes      | The host opens and closes it.                                        |
| `studies`      | `{ id, name }[]`                      | yes      | `getOwnStudyOptions()`.                                              |
| `defaultTitle` | `string`                              | yes      | The name's placeholder: what it is called if left empty.             |
| `action`       | `(formData) => void \| Promise<void>` | yes      | `copyPlayedGameToStudy` bound to the game, or `saveAnalysisToStudy`. |
| `pgn`          | `string`                              | no       | What is saved, when the action does not know it already.             |
| `onCancel`     | `() => void`                          | yes      | «Cancelar».                                                          |

On a page moved to the new design system (the analysis board, a class's notebook) the popup is Material's dialog, its fields outlined, and its foot, `SaveToStudyFoot`, reads that look for its two buttons (`popupButton`): «Cancelar» a text button, «Guardar» a filled one (2026-10-23).
