# `GameFields`

## Purpose

The fields of a game (name, players with Elo, title and federation, result, date, event, site, round, ECO) defined once. Every form that edits a game's record — the study's and the chapter collection's, both through `EditGame` — offers exactly this set: if something could be set in one place that cannot be corrected in another, the data would be trapped. All fields are optional, because when analysis starts one does not yet know which game it is going to be.

It lives in `shared/` because two products write a game's record with it: the student's studies and the staff's chapter collections.

## Props

| Prop        | Type                | Required | Meaning                                                                                                                                |
| ----------- | ------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `values`    | `GameFieldValues`   | no       | Current values for the edit form; absent on creation. `playedAtValue` is short ISO (`yyyy-mm-dd`), what `<input type="date">` expects. |
| `results`   | `{ code, label }[]` | yes      | The results catalog; `ONGOING` is the default.                                                                                         |
| `titleHint` | `string`            | yes      | Help text for the name, different on creation and on edit.                                                                             |

## Behaviour

- Plain inputs with `defaultValue`; no state.
- `CodeSelect` handles the title and federation dropdowns, each a [`PlatformSelect`](/components/platform/shared/platform-select) with the `emptyOption` ("Sin título", "Sin federación"): a PGN may bring a title or a federation that is not in our lists (headers are written by whoever wants), so a stored value outside the options is added as one more option, "X (del PGN)", and saving without touching it keeps it. The result is a `PlatformSelect` over `results`.
- Elo inputs are `type="number"` between 100 and 4000.

## Markup & styling

Block `.game-fields` (15 lines): the two-column rows.

**Elements:** `.game-fields__row`

**Other selectors it styles:** `.platform-field` (spacing inside the rows).

No tokens, no media queries of its own.

## Usage

From `components/platform/shared/edit-game/edit-game.comp.tsx`, its only importer:

```tsx
import { GameFields, type GameFieldValues } from "@/components/platform/shared/game-fields/game-fields.comp";

<GameFields values={values} results={results} titleHint={titleHint} />;
```
