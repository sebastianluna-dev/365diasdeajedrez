# `OptionalFields`

|            |                                                                                                                                                |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/optional-fields/optional-fields.comp.tsx`                                                                          |
| Kind       | Server Component                                                                                                                               |
| Stylesheet | `optional-fields.comp.css` → block `.optional-fields`                                                                                          |
| Story      | `optional-fields.stories.tsx` (`platform/shared/OptionalFields`): three `FormField`s under the note (checked by `play`), and on `PlatformForm` |
| Used by    | [`GameFields`](/components/platform/shared/game-fields), so the record of a game in `EditGame`                                                 |

## Purpose

The third part of the rule for what is optional (see [`OptionalMark`](/components/platform/shared/optional-mark)): a form whose fields are **all** optional says it once. The record of a game has fifteen fields and none is required; fifteen pills would say nothing one line does not.

## Props

| Prop       | Type        | Required | Meaning                          |
| ---------- | ----------- | -------- | -------------------------------- |
| `children` | `ReactNode` | yes      | The fields, laid out as they are |

A container, the one kind of component that takes `children` under the conventions: its only job is to place what it is given under its note.

## Behaviour

- It writes «Todos los campos son opcionales.» first, then the fields.
- **The marks are hidden by its stylesheet**, `.optional-fields .optional-mark { display: none }`, not by telling each field: `FormField` is a Server Component, and the server has no React context to hand down. The note and the hiding live in this one piece, so neither can be there without the other. `display: none` also takes the word away from a screen reader, which it was hidden from anyway.
- Not for a form of **one** field — «Contraseña nueva» keeps its pill —, nor for a filter bar, whose fields are searches and selects and carry no mark.

## Markup & styling

Block `.optional-fields` (16 lines): a flex column with the scale's `space-4` between the note and the fields; `.optional-fields__note` in `sm` and the muted grey.

**Elements:** `.optional-fields__note`

**Other selectors it styles:** `.optional-mark`, hidden.

**Tokens:** `--platform-text-muted`

No media queries.

## Usage

From `components/platform/shared/game-fields/game-fields.comp.tsx`:

```tsx
import { OptionalFields } from "@/components/platform/shared/optional-fields/optional-fields.comp";

<OptionalFields>
  <div className="game-fields">{/* the fifteen fields */}</div>
</OptionalFields>;
```
