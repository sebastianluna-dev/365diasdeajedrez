## Purpose

The left column of a `.platform-workspace` page, as Gmail draws its labels: what the page offers — its main action, its views, its catalog — never the platform's navigation, which is the tools menu of the bar. A view lives in the address, so a link is the right element: it can be shared and the back button undoes it, as with [`FilterPills`](/components/platform/shared/filter-pills).

## Props

| Prop     | Type                                                | Required | Meaning                                                        |
| -------- | --------------------------------------------------- | -------- | -------------------------------------------------------------- |
| `label`  | `string`                                            | yes      | The nav's accessible name.                                     |
| `action` | `{ label: string; href: string }`                   | no       | The page's main action, drawn as Material 3's extended button. |
| `groups` | `{ title: string; links: PlatformSideNavLink[] }[]` | yes      | The views, in groups.                                          |

A `PlatformSideNavLink` is `{ label, href, count?, current?, icon?, level?, badge?, choice? }`; `count` is a number or a ratio such as «1/3». `icon` is a name (`"play"`, `"graduation-cap"`, `"circle-check"`, `"clock"`, `"book-open"`, and for «Mis estudios», 2026-10-23, `"chess-board"`, `"user"`, `"trophy"`, `"layer-group"`, `"books"`), never a component: the component receives data and draws the icon itself. `level` replaces the icon with a dot in a course level's colour (`--platform-level-1` … `-6`), and `badge` (`{ text, done? }`) with a small round badge: a chapter's number, or a check in the success green once it is done (the course's page, 2026-10-22). `choice` (2026-10-23, «Ordenar» on «Mis estudios») draws a radio's ring before the label, filled with the primary on the `current` one: a group of which exactly one is on. They are still links, each to its address.

## Behaviour

A `<nav aria-label>` with the action on top and a list per group. The action behaves as Gmail's «Redactar»: flat at rest (`--container-elevation: none` over the FAB's own shadow), on `--md-sys-elevation-shadow-3` under the pointer, and its colour never darkens (the library's hover tint, `--ripple-hover-opacity`, is set to 0; the press still ripples). The current link carries `aria-current="page"`, is lit in the secondary container and draws its icon solid; the rest draw it in Duotone Light. Under 1024px the column sits above the panel and its groups go side by side.

## Markup & styling

Block `.platform-side-nav`.

**Elements:** `__action` (on Material's `fab fab-primary-container`, only its place), `__group`, `__title`, `__list`, `__link`, `__icon`, `__level`, `__choice`, `__label`, `__count`

**Modifiers and states:** `.platform-side-nav__link_state_current`, `.platform-side-nav__level_tone_{1…6}`, `.platform-side-nav__choice_state_on`, `.platform-side-nav__badge` (`_state_done`, `__badge-check`), `.platform-side-nav__icon_box_tight` (an icon pasted on Font Awesome's bare 512 box, `circle-check`, drawn at three quarters so it reads the size of the padded ones)

**Tokens:** the `--platform-m3-*` roles (`on-surface`, `on-surface-variant`, `primary`, `primary-container`, `on-primary-container`, `secondary-container`, `on-secondary-container`, `container-high`, `panel`) and `--platform-level-*`.

The transitions fade colours only.

## Usage

```tsx
<div className="platform-workspace">
  <div className="platform-workspace__side">
    <PlatformSideNav label="Cursos" action={{ label: "Seguir donde iba", href: lessonHref }} groups={groups} />
  </div>
  <section className="platform-workspace__panel">…</section>
</div>
```
