## Purpose

Every list of records in the teacher and staff panels (students, classes, courses, teachers, assignments, payments) is this table, so the look is defined once and a `<table>` with `<th scope="col">` is what screen readers get.

It holds no state: no sorting, no client filtering. Filters travel in search params and the page filters on the server, which keeps every listing addressable by URL. The component receives the rows as children and only decides whether to render them or the empty message.

## Behaviour

`hasRows` flattens the children and checks that at least one is truthy, so a `.map()` over an empty array or a conditional that yields `false` still shows the empty message instead of a headless table. Nothing else: no effects, no handlers.

**The scrolling box is reached by the keyboard.** Below `minWidth` the wrapper scrolls sideways. A keyboard scrolls it by tabbing to a link in a row, but a table with none — an empty one, a read-only listing — would leave the columns past the edge out of its reach (WCAG 2.1.1; axe's `scrollable-region-focusable`. Chrome makes such a box focusable on its own since version 130; Safari and Firefox do not). So the wrapper is always `tabIndex={0}`, where the arrow keys scroll it and the platform's focus ring is drawn, and `role="region"` with `aria-label={label}`, so that what a screen reader reaches has a name. It is focusable always, not only while it overflows: knowing that would take a client leaf to measure it, to save one stop in the tab order of a wide screen. jsx-a11y's `no-noninteractive-tabindex` keeps its rule, with its reason on the line.

## Markup & styling

Block `.platform-table` (66 lines). The root is the scrolling wrapper (`role="region"`, named by `label`, `tabIndex={0}`); the `<table>` inside gets `min-width` inline.

**Elements:** `.platform-table__table`, `.platform-table__head`, `.platform-table__row`, `.platform-table__cell`, `.platform-table__empty`

**Modifiers and states:** `.platform-table__head_align_right`, `.platform-table__cell_align_right`, `.platform-table__cell_variant_strong`

**Tokens:** `--platform-accent-ink`, `--platform-bg`, `--platform-border`, `--platform-surface`, `--platform-text`, `--platform-text-muted`

No media queries: narrow screens scroll the wrapper.

## Usage

From `components/platform/sections/staff/classes/staff-class-detail.section.tsx`:

```tsx
import {
  PlatformTable,
  PlatformTableCell,
  PlatformTableRow,
} from "@/components/platform/shared/platform-table/platform-table.comp";

<PlatformTable
  label="Profesores"
  columns={["Profesor", "Email", "Alumnos", "Estado"]}
  emptyLabel="Todavía no hay profesores."
  minWidth={640}
>
  {teachers.map((teacher) => (
    <PlatformTableRow key={teacher.id}>
      <PlatformTableCell strong>{teacher.displayName}</PlatformTableCell>
      <PlatformTableCell>{teacher.email}</PlatformTableCell>
      <PlatformTableCell>{teacher.studentCount}</PlatformTableCell>
      <PlatformTableCell>{teacher.isActive ? "Activo" : "Desactivado"}</PlatformTableCell>
    </PlatformTableRow>
  ))}
</PlatformTable>;
```
