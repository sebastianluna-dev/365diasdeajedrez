## Purpose

Every list of records in the teacher and staff panels (students, classes, courses, teachers, assignments, payments) is this table, so the look is defined once and a `<table>` with `<th scope="col">` is what screen readers get.

It holds no state: no sorting, no client filtering. Filters travel in search params and the page filters on the server, which keeps every listing addressable by URL. The component receives the rows as children and only decides whether to render them or the empty message.

The student's `GameTable` in the study detail still draws its rows with `div`s because it needs drag reordering; rebuilding it on this component is `todos.md` T13.

## Props

### `PlatformTable`

| Prop         | Type                                         | Required           | Meaning                                                                                                   |
| ------------ | -------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------- |
| `columns`    | `readonly (string \| PlatformTableColumn)[]` | yes                | Header labels, or `{ label, align?: "right" }` for numeric columns. Rendered as `<th scope="col">`.       |
| `children`   | `ReactNode`                                  | no                 | `PlatformTableRow` elements. Empty (after flattening arrays) renders `emptyLabel` in one full-width cell. |
| `emptyLabel` | `string`                                     | no                 | Default "No hay nada que mostrar todavía."                                                                |
| `minWidth`   | `number`                                     | no · default `640` | Minimum table width in pixels before the wrapper scrolls horizontally.                                    |

### `PlatformTableRow`

| Prop               | Type                             | Required | Meaning                                                                                                                                                                                                                                |
| ------------------ | -------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children`         | `ReactNode`                      | yes      | `PlatformTableCell` elements.                                                                                                                                                                                                          |
| …`<tr>` attributes | `ComponentPropsWithoutRef<"tr">` | no       | Passed through to the `<tr>`; a `className` is added after `platform-table__row`. This is how [`GameTable`](/components/platform/sections/studies/study-detail/game-table) hangs its drag handlers and its dragging state on the rows. |

### `PlatformTableCell`

| Prop       | Type        | Required | Meaning                                                        |
| ---------- | ----------- | -------- | -------------------------------------------------------------- |
| `children` | `ReactNode` | yes      | Cell content.                                                  |
| `align`    | `"right"`   | no       | Right-aligned, for numbers and amounts.                        |
| `strong`   | `boolean`   | no       | Highlighted cell: the column that identifies the row (a name). |

## Behaviour

`hasRows` flattens the children and checks that at least one is truthy, so a `.map()` over an empty array or a conditional that yields `false` still shows the empty message instead of a headless table. Nothing else: no effects, no handlers.

## Markup & styling

Block `.platform-table` (68 lines). The root is the scrolling wrapper; the `<table>` inside gets `min-width` inline.

**Elements:** `.platform-table__table`, `.platform-table__head`, `.platform-table__row`, `.platform-table__cell`, `.platform-table__empty`

**Modifiers and states:** `.platform-table__head_align_right`, `.platform-table__cell_align_right`, `.platform-table__cell_variant_strong`

**Tokens:** `--platform-accent-ink`, `--platform-bg`, `--platform-border`, `--platform-surface`, `--platform-text`, `--platform-text-muted`

No media queries: narrow screens scroll the wrapper.

## Usage

From `components/platform/sections/staff/classes/staff-class-detail.section.tsx`:

```tsx
import { PlatformTable, PlatformTableCell, PlatformTableRow } from "@/components/platform/shared/platform-table.comp";

<PlatformTable
  columns={["Alumno", "Email", "Asistió", "Pago", "Importe", "Referencia"]}
  emptyLabel="Esta clase no tiene alumnos inscritos."
  minWidth={860}
>
  {classDetail.participants.map((participant) => (
    <PlatformTableRow key={participant.userId}>
      <PlatformTableCell strong>{participant.displayName}</PlatformTableCell>
      <PlatformTableCell>{participant.email}</PlatformTableCell>
      <PlatformTableCell>{participant.attended ? "Sí" : "No"}</PlatformTableCell>
      <PlatformTableCell>{participant.paidAtLabel ?? "—"}</PlatformTableCell>
      <PlatformTableCell>{participant.amountLabel ?? "—"}</PlatformTableCell>
      <PlatformTableCell>{participant.paymentRef ?? "—"}</PlatformTableCell>
    </PlatformTableRow>
  ))}
</PlatformTable>;
```
