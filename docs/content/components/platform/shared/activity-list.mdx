# `ActivityList`

|            |                                                                                                            |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/activity-list.comp.tsx`                                                        |
| Kind       | Server Component                                                                                           |
| Stylesheet | `activity-list.comp.css` → block `.activity-list`                                                          |
| Used by    | [`RecentActivitySection`](/components/platform/sections/dashboard/recent-activity/recent-activity-section) |
| Uses       | `ActivityItem` from `services/dashboard/dashboard.types`                                                   |

## Purpose

Renders the activity facts of a student ("Lección completada · Finales de torre · Aperturas · hace 2 días"). Every string arrives ready from `services/dashboard`'s mapper; the component lays them out and adds nothing. It sits in `shared/` because the teacher's student detail is expected to reuse it; today only the dashboard does.

## Props

| Prop    | Type             | Required | Meaning                                                                           |
| ------- | ---------------- | -------- | --------------------------------------------------------------------------------- |
| `items` | `ActivityItem[]` | yes      | `{ id, typeLabel, subjectName?, topicLabel?, dateLabel }` per fact, newest first. |

## Behaviour

None. The empty case is the caller's: `RecentActivitySection` renders an [`EmptyState`](/components/platform/shared/empty-state) instead.

## Usage

From `components/platform/sections/dashboard/recent-activity/recent-activity.section.tsx`:
