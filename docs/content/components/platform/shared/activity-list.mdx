# `ActivityList`

|            |                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/activity-list/activity-list.comp.tsx`                                             |

| Used by    | [`HomeSection`](/components/platform/sections/dashboard/home/home-section)                                    |
| Uses       | `ActivityItem` from `services/dashboard/dashboard.types`                                                      |

## Purpose

Renders the activity facts of a student ("Lección completada · Finales de torre · Aperturas · hace 2 días"). Every string arrives ready from `services/dashboard`'s mapper; the component lays them out and adds nothing. It sits in `shared/` because the teacher's student detail is expected to reuse it; today only the home page does. Since 2026-10-23 it is drawn in the new design system: rows parted by `--platform-m3-divider`, the topic a pale blue pill.

## Props

| Prop    | Type             | Required | Meaning                                                                           |
| ------- | ---------------- | -------- | --------------------------------------------------------------------------------- |
| `items` | `ActivityItem[]` | yes      | `{ id, typeLabel, subjectName?, topicLabel?, dateLabel }` per fact, newest first. |

## Behaviour

None. The empty case is the caller's: `HomeSection` writes a line instead.

## Usage

From `components/platform/sections/dashboard/home/home.section.tsx`:

```tsx

<ActivityList items={dashboard.recentActivity} />;
```
