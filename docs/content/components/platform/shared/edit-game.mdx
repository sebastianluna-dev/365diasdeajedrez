## Purpose

Editing a game's data without leaving the board: a [`PlatformPopup`](/components/platform/shared/platform-popup) named «Datos de la partida», the widest (`lg`, 720px, for the record's grid), with the same [`GameFields`](/components/platform/shared/game-fields) as the create form, so nothing set on creation is trapped. Saving writes the fields to the database and to the PGN headers, so an exported game carries them (`writeGameRecord` in `services/shared/game-record`, the same for both screens).

It lives in `shared/` since 2026-09-28, when the staff panel got its own game screen: two products mount it, each with its own action, because each has its own border — the student's checks the study is theirs, the staff's that they are staff.

## Behaviour

On the shell since 2026-10-06: the strip with «Datos de la partida» and the cross is `PlatformPopup`'s, and the trigger (the word or the pencil) opens it with the click, so the focus comes back to it on closing; the popup focuses the first field of the record. The content is a [`PlatformForm`](/components/platform/shared/platform-form) with `action={action}`, whose context the record's fields need, closing the popup on submit, with no state beyond the popup's handle. The form only calls `onSubmit` when it is valid: a field the browser rejects (an Elo outside 100–4000) turns red and keeps the popup open. Its first line is the paragraph that was the head's subtitle, «Al guardar, estos datos se escriben también en las cabeceras del PGN.», and then the body opens with «Todos los campos son opcionales.», which [`GameFields`](/components/platform/shared/game-fields) says through `OptionalFields`: none of the fifteen carries its own mark.

## Markup & styling

Block `.edit-game` (33 lines): the pencil and the popup's content, which pads itself under the strip; the strip, the width and the frame are `PlatformPopup`'s. The action row holds the two buttons, at its end, and nothing else: it also carried «Se escriben en las cabeceras del PGN.» beside them until 2026-10-05, which the subtitle already says.

**Elements:** `.edit-game__open` (only a hook: the pencil is the platform's quiet button, like the gear of a game's row), `.edit-game__form` (also `PlatformForm`'s root: its gap is set to 0, so the subtitle, the body and the actions keep the spacing they set themselves), `.edit-game__subtitle` (the content's first line), `.edit-game__body`, `.edit-game__actions`

**Modifiers and states:** none of its own. The word wears `.platform-row-action`; the pencil, the platform's quiet button.

**Other classes it renders:** `.platform-button`, `.platform-form`, and `PlatformPopup`'s.

**Tokens:** `--platform-accent-ink`, `--platform-text-muted`, `--platform-track`, `--platform-accent`

No media queries of its own.

## Usage

From `GameViewSection`, opened by the pencil of the record the viewer draws:

```tsx
import { EditGame, type EditGameHandle } from "@/components/platform/shared/edit-game/edit-game.comp";

const editRef = useRef<EditGameHandle>(null);

<EditGame
  ref={editRef}
  action={updateGameDetails.bind(null, game.studyId, game.id)}
  results={results}
  values={game}
  titleHint="Cómo identificas esta partida dentro del estudio. Si lo dejas vacío se usan los dos jugadores."
  trigger="none"
/>;
```
