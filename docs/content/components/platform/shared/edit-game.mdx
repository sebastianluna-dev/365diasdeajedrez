## Purpose

Editing a game's data without leaving the board: a [`PlatformPopup`](/components/platform/shared/platform-popup) named «Datos de la partida», the widest (`lg`, 720px, for the record's grid), with the same [`GameFields`](/components/platform/shared/game-fields) as the create form, so nothing set on creation is trapped. Saving writes the fields to the database and to the PGN headers, so an exported game carries them (`writeGameRecord` in `services/shared/game-record`, the same for both screens).

It lives in `shared/` since 2026-09-28, when the staff panel got its own game screen: two products mount it, each with its own action, because each has its own border — the student's checks the study is theirs, the staff's that they are staff.

## Props

| Prop        | Type                                    | Required              | Meaning                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------- | --------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `action`    | `(formData: FormData) => Promise<void>` | yes                   | The server action that saves the record, already bound to its game.                                                                                                                                                                                                                                                                                                                     |
| `values`    | `GameFieldValues`                       | yes                   | Current values. The whole game is passed (`GameView`, `ChapterGameDetail`), which is a superset.                                                                                                                                                                                                                                                                                        |
| `results`   | `{ code, label }[]`                     | yes                   | The results catalog; its label is the PGN token.                                                                                                                                                                                                                                                                                                                                        |
| `titleHint` | `string`                                | yes                   | What the name is for on this screen, under its field.                                                                                                                                                                                                                                                                                                                                   |
| `trigger`   | `"text" \| "icon"`                      | no · default `"text"` | `text` writes «Editar», the platform's **row action**, at the end of a row of a list (the staff's chapter collection); `icon` is a pencil with no word (`PenToSquareIcon` in Classic Solid, the platform's quiet small square — 32px —, named «Editar los datos de la partida»), for the head of a card already titled «Datos de la partida»: the game's record beside a study's board. |

## Behaviour

On the shell since 2026-10-06: the strip with «Datos de la partida» and the cross is `PlatformPopup`'s, and the trigger (the word or the pencil) opens it with the click, so the focus comes back to it on closing; the popup focuses the first field of the record. The content is the `<form action={action}>`, closing the popup on submit, with no state beyond the popup's handle. Its first line is the paragraph that was the head's subtitle, «Al guardar, estos datos se escriben también en las cabeceras del PGN.», and then the body opens with «Todos los campos son opcionales.», which [`GameFields`](/components/platform/shared/game-fields) says through `OptionalFields`: none of the fifteen carries its own mark.

## Markup & styling

Block `.edit-game` (27 lines): the pencil and the popup's content, which pads itself under the strip; the strip, the width and the frame are `PlatformPopup`'s. The action row holds the two buttons, at its end, and nothing else: it also carried «Se escriben en las cabeceras del PGN.» beside them until 2026-10-05, which the subtitle already says.

**Elements:** `.edit-game__open` (only a hook: the pencil is the platform's quiet button, like the gear of a game's row), `.edit-game__form`, `.edit-game__subtitle` (the content's first line), `.edit-game__body`, `.edit-game__actions`

**Modifiers and states:** none of its own. The word wears `.platform-row-action`; the pencil, the platform's quiet button.

**Other classes it renders:** `.platform-button`, and `PlatformPopup`'s.

**Tokens:** `--platform-accent-ink`, `--platform-text-muted`, `--platform-track`, `--platform-accent`

No media queries of its own.

## Usage

From `GameRecord`:

```tsx
import { EditGame } from "@/components/platform/shared/edit-game/edit-game.comp";

<EditGame
  action={updateGameDetails.bind(null, game.studyId, game.id)}
  results={results}
  values={game}
  titleHint="Cómo identificas esta partida dentro del estudio. Si lo dejas vacío se usan los dos jugadores."
  trigger="icon"
/>;
```
