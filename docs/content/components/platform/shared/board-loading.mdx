# `BoardLoading`

|            |                                                                                        |
| ---------- | -------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/board-loading.comp.tsx`                                    |
| Kind       | Server Component                                                                       |
| Stylesheet | `board-loading.comp.css` → block `.board-loading`                                      |
| Used by    | `app/(platform)/estudios/loading.tsx`, `app/(platform)/estudios/[studyId]/loading.tsx` |

## Purpose

The loading look of the studies area: the list at `/estudios` and, under it, the study's segment, where opening a study is opening its first game (`/estudios/[studyId]` redirects there). Instead of the generic spinner of [`LoadingPanel`](/components/platform/shared/loading-panel), both boundaries show a knight hopping over its shadow and "Preparando el tablero…". The same fallback covers moving between games of a study through the aside, since the boundary sits on the `[studyId]` segment.

## Props

| Prop    | Type     | Required                                | Meaning           |
| ------- | -------- | --------------------------------------- | ----------------- |
| `label` | `string` | no · default `"Preparando el tablero…"` | The visible text. |

## Behaviour

None. The root carries `role="status"` and `aria-live="polite"`; the figure is `aria-hidden`. Under `prefers-reduced-motion: reduce` nothing moves. Its exit cannot be animated, because the App Router unmounts the fallback the moment the page is ready: the page's own fade-in (`.platform-page`, in `platform.css`) is what softens that side of the swap. The swap does not move the header either: `globals.css` reserves the scrollbar's room (`scrollbar-gutter: stable`), so the bar appearing with the longer page changes no width.

## Markup & styling

Block `.board-loading` (99 lines).

**Elements:** `.board-loading__figure`, `.board-loading__knight` (the ♞ glyph, in the platform font), `.board-loading__shadow`, `.board-loading__label`

**Keyframes:** `board-loading-in` (a 200 ms fade after a 120 ms delay: a page that arrives at once never shows it, one that takes longer sees it appear instead of flash), `board-loading-hop` (up 12 px with an 8° tilt at 30 %, back at 60 %), `board-loading-shadow` (narrows to 60 % and fades while the knight is up); 1.3 s, ease-in-out, both at the top level because `@keyframes` cannot be nested.

**Tokens:** `--platform-text`, `--platform-text-muted`

**Breakpoints:** the block fills the height the 70 px bar and the content padding leave, so the figure sits where the board will; `(max-width: 1080px)` drops that to `60vh` once the bar wraps.

## Usage

From `app/(platform)/estudios/[studyId]/loading.tsx`:

```tsx
import { BoardLoading } from "@/components/platform/shared/board-loading.comp";

export default function StudyLoading() {
  return <BoardLoading />;
}
```
