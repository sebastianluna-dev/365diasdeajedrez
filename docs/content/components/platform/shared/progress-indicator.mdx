## Purpose

The shared progress bar, filled with `--platform-progress` because what it measures is a course, in three layouts: `inline` puts the bar and its label on one line (the dashboard card), `stacked` puts the percentage and the detail at the two ends with the bar underneath, and `figure` is the stacked one with the percentage as a large figure (`--platform-type-xl`, weight 800, tabular figures) and the detail small (`--platform-type-xs`) at the other end — the catalog's course card, which is read by it.

The figure's detail is in `--platform-text-subtle`, the grey made for white: the figure goes on a white surface (`--platform-surface`, a card), never on the canvas or on a grey or tinted fill, where it would fall under 4.5:1.

`tone="success"` paints the fill in `--platform-success-ink`, for what is finished. It is a prop and not read from the percentage, which is rounded: 199 lessons of 200 are 100% and still unfinished.

Until 2026-10-03 the catalog's card drew this figure with a track and a fill of its own; it is the one copy there was. The other pages of a course draw no bar: the study frame and a chapter's page carry no figure, and a chapter's card says its progress as a count («9/17 lecciones»).

## Props

| Prop      | Type                                | Required                  | Meaning                                                                                          |
| --------- | ----------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------ |
| `percent` | `number`                            | yes                       | Any number; clamped to 0–100 and rounded before rendering.                                       |
| `detail`  | `string`                            | no                        | "3 de 7 lecciones", appended to the label (inline) or placed at the right end (stacked, figure). |
| `layout`  | `"inline" \| "stacked" \| "figure"` | no · default `"inline"`   | See above.                                                                                       |
| `tone`    | `"progress" \| "success"`           | no · default `"progress"` | The fill: the progress blue, or green for what is finished.                                      |

## Behaviour

None. The fill width is an inline style with the clamped percentage.

## Usage

From `components/platform/sections/dashboard/continue-studying/continue-studying.section.tsx` (no screen passes `layout="stacked"` today):

```tsx
import { ProgressIndicator } from "@/components/platform/shared/progress-indicator/progress-indicator.comp";

<ProgressIndicator
  percent={continueStudying.percent}
  detail={`${continueStudying.completedLessons} de ${continueStudying.totalLessons} lecciones`}
/>;
```

From `components/platform/sections/courses/course-card.comp.tsx`, beside the card's button: the card's `.course-card__progress` only gives it the width the button leaves.

```tsx
<ProgressIndicator
  layout="figure"
  tone={course.isCompleted ? "success" : "progress"}
  percent={progress.percent}
  detail={`${progress.completedLessons} de ${countLessons(progress.totalLessons)}`}
/>
```
