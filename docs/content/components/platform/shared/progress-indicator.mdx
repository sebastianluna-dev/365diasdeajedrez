# `ProgressIndicator`

|            |                                                                                                                                                                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/progress-indicator.comp.tsx`                                                                                                                                                                           |
| Kind       | Server Component                                                                                                                                                                                                                   |
| Stylesheet | `progress-indicator.comp.css` → block `.progress-indicator`                                                                                                                                                                        |
| Used by    | [`ContinueStudyingSection`](/components/platform/sections/dashboard/continue-studying/continue-studying-section), [`AssignedStudentDetailSection`](/components/platform/sections/teacher/students/assigned-student-detail-section) |

## Purpose

The shared progress bar, filled with `--platform-progress` because what it measures is a course, in two layouts: `inline` puts the bar and its label on one line (the dashboard card), `stacked` puts the percentage and the detail at the two ends with the bar underneath.

The student's course pages do **not** use it: the course card, the study frame and the chapter cards draw their own bar, because their design sets a large figure and a ratio around it that neither layout has. That is four bars drawn apart; folding them into a third layout of this component is recorded as debt in `IMPROVEMENTS.md`.

## Props

| Prop      | Type                    | Required                | Meaning                                                                                  |
| --------- | ----------------------- | ----------------------- | ---------------------------------------------------------------------------------------- |
| `percent` | `number`                | yes                     | Any number; clamped to 0–100 and rounded before rendering.                               |
| `detail`  | `string`                | no                      | "3 de 7 lecciones", appended to the label (inline) or placed at the right end (stacked). |
| `layout`  | `"inline" \| "stacked"` | no · default `"inline"` | See above.                                                                               |

## Behaviour

None. The fill width is an inline style with the clamped percentage.

## Markup & styling

Block `.progress-indicator` (55 lines).

**Elements:** `.progress-indicator__track`, `.progress-indicator__fill`, `.progress-indicator__label` (inline), `.progress-indicator__legend`, `.progress-indicator__percent`, `.progress-indicator__detail` (stacked)

**Modifiers and states:** `.progress-indicator_layout_stacked`

**Tokens:** `--platform-accent-bright`, `--platform-text`, `--platform-text-muted`, `--platform-track`

The course and chapter detail sheets restyle `.progress-indicator__legend`, `__percent`, `__detail` and `__track` inside their own block to enlarge the headline figure; that is the sanctioned way to adapt it, nested under the consumer's root.

## Usage

```tsx
import { ProgressIndicator } from "@/components/platform/shared/progress-indicator.comp";

<ProgressIndicator layout="stacked" percent={percent} detail={`${completed} de ${total} completadas`} />;
```
