# `FormField`

Also exports `FormFieldset`.

|            |                                                                                                                                                                                                                                                                            |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/shared/form-field.comp.tsx`                                                                                                                                                                                                                           |
| Kind       | Server Component                                                                                                                                                                                                                                                           |
| Stylesheet | `form-field.comp.css` → block `.platform-field`                                                                                                                                                                                                                            |
| Used by    | every write form of the platform (24 importers): the staff course, chapter, lesson, author, class, student and teacher editors, the assignment panel, the account and password forms, the studies' `GameFields`, the teacher's class form, block editor pieces and profile |

## Purpose

> **Being replaced.** New forms use [`PlatformForm`](/components/platform/shared/platform-form) and [`PlatformSelect`](/components/platform/shared/platform-select), on Radix Primitives; the forms below are migrated as they are touched (`TODOS.md`). This wrapper stays until the last one moves.

One field, one look. `FormField` wraps a native control in a real `<label>` (never a placeholder acting as a label), adds an optional hint and an optional error, and defines once how an input or textarea looks in the platform. `FormFieldset` does the same with `<fieldset>`/`<legend>` for groups of checkboxes or radios, where a single label does not apply.

It is stateless on purpose. Platform forms are `<form action={serverAction}>`; validation happens in the action and the failure comes back through the page's `?error=` handling. There is no client validation to wire here.

## Props

### `FormField`

| Prop       | Type        | Required | Meaning                                                                                                                              |
| ---------- | ----------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `label`    | `string`    | yes      | The label text. Clicking it focuses the control, because the control is inside the `<label>`.                                        |
| `children` | `ReactNode` | yes      | The control: a native input or textarea, or a [`PlatformSelect`](/components/platform/shared/platform-select) with `size="compact"`. |
| `hint`     | `string`    | no       | Small help text under the control.                                                                                                   |
| `error`    | `string`    | no       | Field-level error, rendered with `role="alert"`.                                                                                     |

### `FormFieldset`

| Prop       | Type                 | Required | Meaning                                                                                                                                                                                                |
| ---------- | -------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `legend`   | `string`             | yes      | The group's `<legend>`.                                                                                                                                                                                |
| `children` | `ReactNode`          | yes      | The controls of the group.                                                                                                                                                                             |
| `hint`     | `string`             | no       | Help text under the group.                                                                                                                                                                             |
| `frame`    | `"border" \| "none"` | no       | `border` (default) draws the box around the group; `none` drops border and padding, for controls that draw their own boxes ([`PlatformCheckCards`](/components/platform/shared/platform-check-cards)). |

## Behaviour

None. The control keeps its own attributes (`name`, `required`, `maxLength`, `defaultValue`); the wrapper adds structure and styling only.

## Markup & styling

Block `.platform-field` (91 lines). The root is the `<label>` (or the `<fieldset>` with the group modifier); the control's look is defined through descendant selectors on `input` and `textarea` inside `.platform-field__control`, which is why no form in the platform styles its own inputs.

**Elements:** `.platform-field__label`, `.platform-field__control`, `.platform-field__hint`, `.platform-field__error`

**Modifiers and states:** `.platform-field_variant_group`, `.platform-field_frame_none` (on a group: no border, no padding)

**Tokens:** `--platform-accent`, `--platform-accent-soft`, `--platform-border`, `--platform-danger`, `--platform-surface`, `--platform-text`, `--platform-text-muted`

No media queries.

## Usage

From `components/platform/sections/staff/classes/staff-class-detail.section.tsx`:

```tsx
import { FormField } from "@/components/platform/shared/form-field.comp";

<FormField label="Nombre">
  <input type="text" name="name" maxLength={160} required />
</FormField>;
```

A group of native checkboxes, from `components/platform/sections/staff/courses/lesson-editor.section.tsx`:

```tsx
<FormFieldset legend="Temas">
  {topics.map((topic) => (
    <label key={topic.id}>
      <input type="checkbox" name="topicCodes" value={topic.code} defaultChecked={lesson.topicCodes.includes(topic.code)} />
      {topic.label}
    </label>
  ))}
</FormFieldset>
```

A group of cards, from `components/platform/sections/staff/courses/course-editor.section.tsx`, with `frame="none"` so the cards are not framed twice:

```tsx
<FormFieldset legend="Contenido (selecciona al menos uno)" frame="none">
  <PlatformCheckCards name="contentTypeCodes" defaultValue={course.contentTypeCodes} options={options} />
</FormFieldset>
```
