Also exports `FormFieldset`.

| Story      | `form-field.stories.tsx` (`platform/shared/FormField`): a required text input with and without its hint or error, with its clarification in an "i" inside the input (opened by `play`), focused, an optional textarea with its «Opcional», `PlatformSelect` inside it, a `FormFieldset` over a group of cards, and an optional one |

## Purpose

> **Being replaced.** New forms use [`PlatformForm`](/components/platform/shared/platform-form) and [`PlatformSelect`](/components/platform/shared/platform-select), on Radix Primitives; the forms below are migrated as they are touched (`TODOS.md`). This wrapper stays until the last one moves.

One field, one look. `FormField` wraps a native control in a real `<label>` (never a placeholder acting as a label), adds an optional hint and an optional error, and defines once how an input or textarea looks in the platform. `FormFieldset` names a group of cards ([`PlatformCheckCards`](/components/platform/shared/platform-check-cards), [`PlatformChoiceCards`](/components/platform/shared/platform-choice-cards)) with `<fieldset>`/`<legend>`, where a single label does not apply. It draws no frame of its own, since each card draws one; a group of native checkboxes in a box was the other way it had, and was removed on 2026-10-03 with its `frame` prop, when the lesson's topics and the class's students moved to `PlatformCheckCards`.

It is stateless on purpose. Platform forms are `<form action={serverAction}>`; validation happens in the action and the failure comes back through the page's `?error=` handling. There is no client validation to wire here.

## Props

### `FormField`

| Prop       | Type        | Required | Meaning                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------- | ----------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`    | `string`    | yes      | The label text. Clicking it focuses the control, because the control is inside the `<label>`.                                                                                                                                                                                                                                                                                                |
| `children` | `ReactNode` | yes      | The control: a native input or textarea, or a [`PlatformSelect`](/components/platform/shared/platform-select) or [`PlatformDatePicker`](/components/platform/shared/platform-date-picker), which are the same size.                                                                                                                                                                          |
| `hint`     | `string`    | no       | Small help text under the control.                                                                                                                                                                                                                                                                                                                                                           |
| `info`     | `string`    | no       | A clarification folded into an "i" **inside the control, at its right end** ([`PlatformInfoTip`](/components/platform/shared/platform-info-tip)), shown on hover, on focus and on a press: for what helps the first time and would be a line of small print every time after. The button is named «Sobre «label»». For a text input: a select or a date picker has its own mark at that end. |
| `error`    | `string`    | no       | Field-level error, rendered with `role="alert"`.                                                                                                                                                                                                                                                                                                                                             |

### `FormFieldset`

| Prop       | Type        | Required             | Meaning                                                                                                                       |
| ---------- | ----------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `legend`   | `string`    | yes                  | The group's `<legend>`.                                                                                                       |
| `children` | `ReactNode` | yes                  | The group's cards: `PlatformCheckCards` or `PlatformChoiceCards`.                                                             |
| `hint`     | `string`    | no                   | Help text under the group.                                                                                                    |
| `optional` | `boolean`   | no · default `false` | The group may be left with nothing chosen: «Opcional» beside its legend. Said here because a group has no `required` to read. |

## Behaviour

- The control keeps its own attributes (`name`, `required`, `maxLength`, `defaultValue`); the wrapper adds structure and styling.
- **«Opcional», read from the control** (2026-10-05). A control one can leave empty — a `<textarea>`, or an `<input>` one types into — with no `required` gets [`OptionalMark`](/components/platform/shared/optional-mark) after the label (`isOptionalControl`); a search box, a checkbox, a select or a date picker gets none, and a group says it with `optional`. It is how [`PlatformFormField`](/components/platform/shared/platform-form) does it, so a form keeps its marks when it moves to `PlatformForm`. Until then 26 labels wrote «(opcional)» by hand and some optional fields said nothing; `components/optional-mark.test.ts` now fails on the word anywhere but the pieces that draw it. The mark is **inside** the `<label>`, which wraps the whole field, but `aria-hidden`, so the field's name is its label alone, as before «(opcional)» was in it; a screen reader tells the required ones by their `required`.

## Markup & styling

Block `.platform-field` (123 lines). The root is the `<label>` (or the `<fieldset>` with the group modifier, or a `<div>` when the field has `info`); the control's look is defined through descendant selectors on `input` and `textarea` inside `.platform-field__control`, which is why no form in the platform styles its own inputs.

**Elements:** `.platform-field__label-row` (the label and the mark after it, a wrapping flex line; the `<legend>` itself in a fieldset), `.platform-field__label`, `.platform-field__control`, `.platform-field__hint`, `.platform-field__error`, and with `info` `.platform-field__body` (the `<label>`) and `.platform-field__info` (the "i")

**Modifiers and states:** `.platform-field_variant_group` (the `<fieldset>`: no border, no padding, the legend flush with the cards), `.platform-field_with_info` (a field with an "i")

**A field with `info`** (2026-10-05) is not a `<label>` around everything: the "i" is a button, and a button inside the label would put its own name and the tip's text into the input's. So the root is a `<div>`, the `<label>` (`.platform-field__body`) wraps the text and the control as always, and the "i" is the label's **sibling**. The stylesheet puts it inside the control all the same: the field is a one-column grid and the label gives up its box (`display: contents`), so the control and the "i" are placed in the same cell, the "i" at its end and centred, and the input keeps room for it (`padding-right`, the scale's `space-12`). It is where the staff's slug field had its "i", by hand, since before; the game's form first had it beside the label's text, and the owner preferred the slug's place, so that markup became this prop and [`CourseNameFields`](/components/platform/sections/staff/courses/course-name-fields) uses it too. Checked in the game's form and on the course editor: the input's name is the label alone and a click on the label focuses the input.

**Tokens:** `--platform-border`, `--platform-danger`, `--platform-selection`, `--platform-selection-soft`, `--platform-surface`, `--platform-text`, `--platform-text-muted`

No media queries.

## Usage

From `components/platform/sections/staff/courses/chapter-editor.section.tsx`:

```tsx
import { FormField } from "@/components/platform/shared/form-field/form-field.comp";

<FormField label="Nombre">
  <input type="text" name="name" defaultValue={chapter.name} maxLength={160} required />
</FormField>;
```

A group of cards, from `components/platform/sections/staff/courses/lesson-editor.section.tsx`:

```tsx
<FormFieldset legend="Temas">
  <PlatformCheckCards
    name="topicCodes"
    defaultValue={lesson.topicCodes}
    aria-label="Temas"
    layout="line"
    options={topics.map((topic) => ({ value: topic.code, label: topic.label }))}
  />
</FormFieldset>
```
