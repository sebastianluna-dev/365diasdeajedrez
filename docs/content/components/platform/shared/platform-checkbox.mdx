## Purpose

One box and what it says. It replaced, on 2026-10-06, the browser's own checkboxes the platform still had: they changed size and colour with each browser and ignored the dark theme. A setting with consequences says them in a `hint` under the label, as the editors' «Lección de prioridad» does.

It is for a value **saved with a form's button**. What takes effect the moment it is pressed is a [`PlatformSwitch`](/components/platform/shared/platform-switch); several choices drawn as cards are [`PlatformCheckCards`](/components/platform/shared/platform-check-cards). The confirmation of a destruction keeps its own box, in the danger colour ([`PlatformConfirmPopup`](/components/platform/shared/platform-confirm-popup)).

## Props

| Prop              | Type                         | Required                   | Meaning                                                                                                                                                                                            |
| ----------------- | ---------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `label`           | `string`                     | yes                        | What is ticked, beside the box. It is the box's name (`aria-labelledby`).                                                                                                                          |
| `hint`            | `string`                     | no                         | A line under the label: what ticking it does. It is the box's description (`aria-describedby`), not its name.                                                                                      |
| `name`            | `string`                     | no                         | Name of the hidden native checkbox.                                                                                                                                                                |
| `value`           | `string`                     | no                         | What it submits when ticked; `"on"` when left out. The attendance sends each student's id under one `name`.                                                                                        |
| `form`            | `string`                     | no                         | Id of the form it belongs to, when it is drawn outside it (the lesson editor's aside).                                                                                                             |
| `checked`         | `boolean`                    | no                         | Controlled state.                                                                                                                                                                                  |
| `defaultChecked`  | `boolean`                    | no                         | Initial state.                                                                                                                                                                                     |
| `onCheckedChange` | `(checked: boolean) => void` | no                         | Called with the new state.                                                                                                                                                                         |
| `disabled`        | `boolean`                    | no                         |                                                                                                                                                                                                    |
| `tone`            | `"selection" \| "accent"`    | no · default `"selection"` | The colour of a ticked box and its ring: a form's blue, or the brand's red (`platform-checkbox_tone_accent`) for a filter of what is on the screen, outside any form — the catalog's (2026-10-07). |
| `count`           | `number`                     | no                         | A figure at the row's end, how many items the option has («Intermedio 5»): `.platform-checkbox__count`, out of the accessibility tree, the label already naming the option.                        |
| `className`       | `string`                     | no                         | The host's class on the whole row, to lay it out in a list or draw it as a card (`NewGame`'s `.new-game__pick`).                                                                                   |

## Behaviour

- The whole row is a `<label>` for the box, so a click anywhere on it ticks it; Space ticks it from the keyboard.
- Inside a form, or tied to one by `form`, it submits through the hidden native checkbox the primitive keeps in sync: `formCheckbox()` reads a single one, `formData.getAll(name)` a list of them.
- **It starts again from what was saved.** It is mounted under the value it opens with (`savedValueKey(defaultChecked)`), so a save that changed it mounts it anew from it, instead of the form's reset taking it back to what it showed when the page was loaded. See [`PlatformCheckCards`](/components/platform/shared/platform-check-cards) for why.

## Markup & styling

Block `.platform-checkbox`, a flex row: the box on the first line of the text, the label and the hint piled up beside it. Ticked, the box keeps its outline and **takes the selection's blue in it**: its border, its wash inside and the tick in its ink (`--platform-selection`, `--platform-selection-wash`; not the accent, the red of an error in the light theme) (the «B» of the 2026-10-06 checkbox study), lighter than a filled box down a list of students. Under the pointer the empty box's border turns to that blue.

**Elements:** `.platform-checkbox__box` (the primitive's button), `.platform-checkbox__indicator`, `.platform-checkbox__icon`, `.platform-checkbox__text`, `.platform-checkbox__label`, `.platform-checkbox__hint`

**States (data attributes set by the primitive):** `[data-state="checked"]`, `[data-disabled]` on the box; the row reads the second with `:has()` to grey its text.

**Tokens:** `--platform-border`, `--platform-border-strong`, `--platform-selection`, `--platform-selection-wash`, `--platform-surface`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`

The hint is in the muted grey, which reads on the white of a panel and on the grey of the canvas alike. No media queries; the colour transition is off under `prefers-reduced-motion`.

## Usage

From `components/platform/sections/staff/courses/lesson-editor.section.tsx`:

```tsx
<PlatformCheckbox
  name="isPriority"
  form={METADATA_FORM_ID}
  defaultChecked={lesson.isPriority}
  label="Lección de prioridad"
  hint="Entra en el recorrido corto de quien estudia con poco tiempo."
/>
```
