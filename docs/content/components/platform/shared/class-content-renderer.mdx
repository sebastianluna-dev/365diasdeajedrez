## Purpose

A class's content is an ordered list of blocks of six kinds. This component turns the `ClassBlockView` discriminated union into markup, and it is the same component for the student, for the teacher's preview and for staff, so the three see exactly the same thing.

Chess blocks are **references** to the original material, not copies: a `GAME_REF` renders the referenced game's PGN in the [`GameViewer`](/components/chess/game-viewer/game-viewer) opened at the saved `movePath`, with a link to the game in "Mis estudios" when it lives in a study; a `LESSON_REF` does the same with the lesson and a link to it in full; a `POSITION_REF` is a [`StaticDiagram`](/components/chess/static-diagram). Correcting the source corrects every class that cites it.

## Props

| Prop       | Type                           | Required              | Meaning                                                                                                                                                                                                                                                                                                                                                                     |
| ---------- | ------------------------------ | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `blocks`   | `ClassBlockView[]`             | yes                   | Ordered blocks, each `{ id, kind, visibility, caption?, title?, isNew?, … }` with the kind-specific payload (`text`, `videoUrl`, `game` with its optional `players`, `result`, `orientation`, `conceal` and `pinnedComment`, `lesson` with its optional `missing`, `position`). The optional fields are filled by the student's mapper from phase 7 of the classes rebuild. |
| `saveGame` | `{ classId, studies, action }` | no                    | With it, [`ClassGameSave`](/components/platform/shared/class-game-save) under each game: the student's studies and `saveClassGameToStudy`, bound to the class.                                                                                                                                                                                                              |
| `groups`   | `"none" \| "byVisibility"`     | no · default `"none"` | `byVisibility` draws a `<details>` per visibility — «Para preparar», «Después de la clase», «Guion del profesor» —, the script folded: the staff's sheet, which sees every block.                                                                                                                                                                                           |

## Behaviour

| `kind`         | Rendered as                                                                                                                                                                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TEXT`         | Paragraphs split on blank lines, written with LF or CRLF (a form sends a textarea's line breaks as CRLF, and blocks saved before 2026-10-05 kept them); a paragraph starting with `## ` becomes an `<h3>`. Simple markdown only, no parser.                                                                   |
| `VIDEO`        | A link out (`target="_blank"`, `rel="noreferrer"`) with the caption or the URL, the arrow icon and «(se abre en una pestaña nueva)» for a screen reader.                                                                                                                                                      |
| `GAME_REF`     | `GameViewer` with `title`, `initialPath`, the game's `players` and `result` as its strips, its `orientation`, `pinnedComment` and `hideNextMoves` when `conceal`, plus "Abrir la partida en Mis estudios" when `game.href` is present (absent for a game transcribed in the block, which lives nowhere else). |
| `LESSON_REF`   | `GameViewer` with the lesson's orientation and `initialPath`, plus «Abrir la lección»; a lesson that is gone (`missing`) is one line: «La lección que citaba este bloque ya no existe.»                                                                                                                       |
| `POSITION_REF` | `StaticDiagram` with the caption or the position's title.                                                                                                                                                                                                                                                     |
| `FILE`         | A card labelled "Archivo" with the caption; the file itself is not linked yet.                                                                                                                                                                                                                                |

Every block is an `<article aria-labelledby>` with a head — the kind's icon in Duotone and the muted grey, an `h3` with the id `bloque-<id>` saying the block's `title`, or the material's name, or the kind's word — and the caption as its lead under the head (a position's stays inside its diagram). `isNew` adds the accent tag «Nuevo» to the head. A text's paragraphs keep their line breaks (`white-space: pre-line`) at 68ch at most.

## Markup & styling

Block `.class-content` (176 lines).

**Elements:** `.class-content__block`, `.class-content__head`, `.class-content__kind-icon`, `.class-content__title`, `.class-content__caption`, `.class-content__text`, `.class-content__text-heading`, `.class-content__text-paragraph`, `.class-content__link-card`, `.class-content__link-icon`, `.class-content__sr`, `.class-content__missing`, `.class-content__group`, `.class-content__group-summary`, `.class-content__group-count`, `.class-content__group-body`, `.class-content__link-kind`, `.class-content__link-label`, `.class-content__game`, `.class-content__game-link`, `.class-content__caption`

**Modifiers and states:** `.class-content__block_kind_{text,video,game_ref,lesson_ref,position_ref,file}` (set in markup), `.class-content_groups_visibility` on the block when folded by visibility

**Tokens:** `--platform-accent-ink`, `--platform-border`, `--platform-border-strong`, `--platform-surface`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted`

No media queries.

## Usage

From `components/platform/sections/classes/class-detail/class-detail.section.tsx`:

```tsx
import { ClassContentRenderer } from "@/components/platform/shared/class-content-renderer/class-content-renderer.comp";

<ClassContentRenderer blocks={classDetail.blocks} />;
```
