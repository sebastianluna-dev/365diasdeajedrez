## Purpose

The staff puts the link on every class (O2), from wherever the class is seen: the agenda's row, the queue «Sin enlace», the record's lane. One popup, no trigger of its own — a host opens it through its `ref`, and `MeetingLinkButton` draws a launcher («Agregar» or «Cambiar», by the current link; `variant` `row` or `button`).

## Props

| Prop                    | Type                 | Required | Meaning                                                                                               |
| ----------------------- | -------------------- | -------- | ----------------------------------------------------------------------------------------------------- |
| `classId`, `classTitle` | `string`             | yes      | The class, named under the title with when it is.                                                     |
| `current`               | `MeetingLinkCurrent` | yes      | `{ meetingUrl, visibleFromIso, startIso, durationMin }`: the link as it stands and when the class is. |
| `timeZone`, `nowIso`    | `string`             | yes      | The academy's zone, and when the page was read.                                                       |
| `setMeeting`            | `SetMeetingAction`   | yes      | `(classId, prev, formData) => Promise<PopupFormState>`; a stub in Storybook.                          |

## Behaviour

The [popup-form pattern](/conventions#server-actions). Two fields: the link (`url`, required) and «Los alumnos ven el enlace», a select of minutes before the start («30 minutos antes de empezar» is the default and stores nothing, «1 hora antes», «3 horas antes», «El día anterior», «Desde ahora») plus, when the class holds an instant none of them matches, «Desde el mié 14 oct, 15:45» to keep it. On success the host closes it and the address says `?aviso=meetingAdded.<classId>` or `meetingChanged.<classId>`, which the page turns into «Enlace agregado a «Plan de aperturas con blancas».» when it has the class at hand.

## Markup & styling

Block `.meeting-link__form` (34 lines): a column with the foot over a hairline; on a phone the foot sticks to the bottom with its button full width.

**Elements:** `.meeting-link__class`, `.meeting-link__foot`

**Breakpoints:** `(width < 640px)`.

**Tokens:** `--platform-surface`, `--platform-text-muted`, `--platform-track`
