## Purpose

«Agregar alumnos», from the staff's record of a class. No trigger of its own; a host opens it through its `ref`, and the exported button draws a launcher. The form is remounted on every use (its key moves in the popup's `onClose`); on success the host closes it and puts the notice in the address.

## Props

| Prop                    | Type                                                   | Required | Meaning                                                                     |
| ----------------------- | ------------------------------------------------------ | -------- | --------------------------------------------------------------------------- |
| `classId`, `classTitle` | `string`                                               | yes      |                                                                             |
| `seatsFree`             | `number`                                               | yes      | «2 plazas libres»; with none the button waits.                              |
| `seatedIds`             | `string[]`                                             | yes      | Their cards are greyed: «Ya está en la clase».                              |
| `students`              | `SchedulableStudent[]`                                 | yes      |                                                                             |
| `teacher`               | `{ id, displayName }`                                  | yes      | A student not assigned to them is said under their row.                     |
| `addClassParticipants`  | `(classId, prev, formData) => Promise<PopupFormState>` | yes      | A seat per student, in one transaction; a refusal takes the others with it. |

## Behaviour

Submitted by hand, as [`NewClassForm`](/components/platform/sections/staff/classes/new-class-form) is, so React's reset does not reach the controlled cards. The same cards and the same «Entra» as [`NewClassForm`](/components/platform/sections/staff/classes/new-class-form) (D6): «Con su pago» only with classes left, «Con el pago pendiente», «Gratis». On success the address says `?aviso=participantsAdded.<n>`: «2 alumnos agregados.».
