## Purpose

«Cambiar profesor», from the staff's record of a class. No trigger of its own; a host opens it through its `ref`, and the exported button draws a launcher. The form is remounted on every use (its key moves in the popup's `onClose`); on success the host closes it and puts the notice in the address.

## Props

| Prop                    | Type                                                   | Required | Meaning                                                                             |
| ----------------------- | ------------------------------------------------------ | -------- | ----------------------------------------------------------------------------------- |
| `classId`, `classTitle` | `string`                                               | yes      |                                                                                     |
| `current`               | `{ id, displayName, isActive }`                        | yes      | Chosen when active; said as deactivated otherwise.                                  |
| `teachers`              | `TeacherOption[]`                                      | yes      | The active teachers.                                                                |
| `setClassTeacher`       | `(classId, prev, formData) => Promise<PopupFormState>` | yes      | The only column the staff's actions write by hand: the teacher has no derived twin. |

## Behaviour

On success the address says `?aviso=teacherChanged`, which the page turns into «Profesor cambiado: GM Profesor Demo.». The way a class of a deactivated teacher («Profesor desactivado» in the agenda and the queues) gets one again.
