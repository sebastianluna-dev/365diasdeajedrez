## Purpose

«Reprogramar la clase», from the staff's record of a class. No trigger of its own; a host opens it through its `ref`, and the exported button draws a launcher. The form is remounted on every use (its key moves in the popup's `onClose`); on success the host closes it and puts the notice in the address.

## Props

| Prop                                               | Type                                                   | Required | Meaning                                                                 |
| -------------------------------------------------- | ------------------------------------------------------ | -------- | ----------------------------------------------------------------------- |
| `classId`, `classTitle`, `startIso`, `durationMin` |                                                        | yes      | The class as it stands.                                                 |
| `teacherId`, `teacherName`                         | `string`                                               | yes      | Whose calendar the overlaps are read from.                              |

| `rescheduleClass`                                  | `(classId, prev, formData) => Promise<PopupFormState>` | yes      | `syncClassSchedule` behind it; only a class that has not started moves. |
| `loadTeacherBusy`                                  | `(teacherId) => Promise<BusySlotView[]>`               | yes      | The class itself is taken off its own list.                             |

## Behaviour

The [popup-form pattern](/conventions#server-actions). The fields open on the class's own day, hour and duration; the line «sáb 17 oct · 10:00–11:30 → sáb 24 oct · 10:00–11:30» follows them; «Nota para los alumnos» is optional. On success the address says `?aviso=classRescheduled`, which the page turns into «Clase reprogramada al sáb 24 oct · 10:00–11:30.».
