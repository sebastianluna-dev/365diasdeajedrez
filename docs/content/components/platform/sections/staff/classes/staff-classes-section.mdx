## Purpose

Every class of every teacher, for oversight. The page parses the URL into typed filters and queries; this section renders the filter form pre-filled with the **raw** URL values (so what the user typed stays as typed, even if the service normalised it) and the table.

## Props

| Prop         | Type                                      | Required | Meaning                                                                 |
| ------------ | ----------------------------------------- | -------- | ----------------------------------------------------------------------- |
| `classes`    | `StaffClassSummary[]`                     | yes      | The filtered rows.                                                      |
| `teachers`   | `{ id, displayName }[]`                   | yes      | For the teacher select.                                                 |
| `filters`    | `StaffClassFilters`                       | yes      | The parsed filters (accepted for symmetry; the form uses `rawFilters`). |
| `rawFilters` | `{ teacherId?, status?, from?, to?, q? }` | yes      | The URL values, to re-render the form as is.                            |

## Behaviour

A GET filter on the platform's form, [`PlatformForm`](/components/platform/shared/platform-form) with `action={staffRoutes.classes}`: teacher and status selects (`PlatformSelect`, «Todos» as the empty option), two date pickers (`PlatformDatePicker`) and a title search, each a `PlatformFormField` that gives its control the `name` the URL carries. None is required, so no field ever shows a message, and the focus and the selects keep the form's blue. Then a table with title (linked), teacher, local date and time, status tag, participants and attended. Empty label: "Ninguna clase coincide con esos filtros."

## Markup & styling

Block `.staff-classes` (19 lines): the filter row. The form is `PlatformForm`, a column of its own, so the row says `flex-direction: row` (its two classes outweigh `.platform-form`'s one); each field grows from 170px and the button sits at their foot.

**Elements:** `.staff-classes__filters`

**Other selectors it styles:** `.platform-form__field` (`PlatformFormField`'s root).

No tokens or media queries of its own.

## Usage

From `app/(platform)/administracion/clases/page.tsx`:

```tsx
import { StaffClassesSection } from "@/components/platform/sections/staff/classes/staff-classes.section";

<StaffClassesSection classes={classes} teachers={teachers} filters={filters} rawFilters={raw} />;
```
