## Purpose

Every class of every teacher, for oversight. The page parses the URL into typed filters and queries; this section renders the filter form pre-filled with the **raw** URL values (so what the user typed stays as typed, even if the service normalised it) and the table.

## Props

| Prop         | Type                                      | Required | Meaning                                                                 |
| ------------ | ----------------------------------------- | -------- | ----------------------------------------------------------------------- |
| `classes`    | `StaffClassSummary[]`                     | yes      | The filtered rows.                                                      |
| `teachers`   | `{ id, displayName }[]`                   | yes      | For the teacher select.                                                 |
| `filters`    | `StaffClassFilters`                       | yes      | The parsed filters (accepted for symmetry; the form uses `rawFilters`). |
| `rawFilters` | `{ teacherId?, status?, from?, to?, q? }` | yes      | The URL values, to re-render the form as is.                            |

## Behaviour

A GET `<form action={staffRoutes.classes}>` with teacher and status selects, two date inputs and a title search, then a table with title (linked), teacher, local date and time, status tag, participants and attended. Empty label: "Ninguna clase coincide con esos filtros."

## Markup & styling

Block `.staff-classes` (17 lines): the filter row.

**Elements:** `.staff-classes__filters`

**Other selectors it styles:** `.platform-field`.

No tokens or media queries of its own.

## Usage

From `app/(platform)/administracion/clases/page.tsx`:

```tsx
import { StaffClassesSection } from "@/components/platform/sections/staff/classes/staff-classes.section";

<StaffClassesSection classes={classes} teachers={teachers} filters={filters} rawFilters={raw} />;
```
