| Kind       | Client Component                                                                                                                |

## Purpose

The status is part of how a course is named, so it sits on the title's row; and since it is what is changed most often about a course once it is written, the tag that says it is also the control that changes it.

## Props

| Prop         | Type               | Required | Meaning                                                                                                                   |
| ------------ | ------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------- |
| `courseId`   | `string`           | yes      | The course the actions are called with.                                                                                   |
| `statusCode` | `CourseStatusCode` | yes      | The status the course has.                                                                                                |
| `statuses`   | `CatalogOption[]`  | yes      | `CourseStatus`, in catalog order, from `listCourseStatuses()`.                                                            |
| `canPublish` | `boolean`          | yes      | The course has the minimum to be published: a lesson with content (`courseHasContent`, which `publishCourse` asks again). |

## Behaviour

- **The pill** is the select's trigger: a dot, the status in bold and a solid caret, green for «Publicado», soft accent for «Borrador» and grey for «Archivado».
- **It offers what the server does.** «Publicado» calls `publishCourse` and is disabled while the course cannot be published; «Archivado» calls `archiveCourse`. Nothing takes a course back to draft, so «Borrador» is only ever the current status or a disabled option.
- **It shows what the course has, not what was picked**: the select is controlled by `statusCode`, so if the action refuses the pill stays where it was and the page renders the reason from `?error=`.
- The change runs in a transition; while it is on its way the pill is disabled and dimmed.

## Markup & styling

Block `.course-status-menu`. It restyles the select's trigger, which is why its selectors double the class (`.platform-select__trigger.course-status-menu__pill`).

**Elements:** `.course-status-menu__pill`

**Modifiers and states:** `.course-status-menu__pill_state_{published,draft,archived}`

**Other selectors it styles:** `.platform-select__trigger` (with `::before` for the dot and `::after` for the caret), `.platform-select__icon` (hidden), `.platform-select__content` (as wide as its longest status).

**Tokens:** `--platform-accent-ink`, `--platform-accent-soft`, `--platform-success-ink`, `--platform-success-soft`, `--platform-surface-neutral`, `--platform-text-muted`, `--platform-selection`

No media queries. The caret's turn is off under `prefers-reduced-motion`.

## Usage

From `components/platform/sections/staff/courses/course-editor.section.tsx`:

```tsx
import { CourseStatusMenu } from "./course-status/course-status-menu.comp";

<StaffEditorHead
  title={course.name}
  badge={
    <CourseStatusMenu
      courseId={course.id}
      statusCode={course.statusCode}
      statuses={statuses}
      canPublish={course.canPublish}
    />
  }
/>;
```
