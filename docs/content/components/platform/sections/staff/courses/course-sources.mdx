## Purpose

Where a course's material comes from: a book, a digital course, a video series, the academy's own work… Several sources per course, one row each, so a compilation is registered source by source. Only the kind of resource is required: material of the academy's own making needs no title nor URL. The card lists them, in the narrow column of the editor with what is glanced at; the dialog adds, edits or removes one. It is the staff twin of the student's «Procedencia» block on the course page.

## Props

### `CourseSources`

| Prop          | Type                  | Required | Meaning                                                     |
| ------------- | --------------------- | -------- | ----------------------------------------------------------- |
| `courseId`    | `string`              | yes      | The course the sources hang from; bound into the actions.   |
| `sources`     | `CourseSourceAdmin[]` | yes      | The course's sources in order, from `getCourseAdminDetail`. |
| `sourceTypes` | `CatalogOption[]`     | yes      | The kinds of resource, from `listSourceTypes()`.            |

### `CourseSourceDialog`

Same `courseId` and `sourceTypes`, plus `source?: CourseSourceAdmin`: with it the trigger is «Editar» on the row, a quiet word, and the form carries the source; without it the trigger is «Agregar fuente» in the card's header, the soft accent button.

### `CourseSourceForm`

`titleId?` (the id its heading takes, so the dialog around it is named by it), `source?`, `sourceTypes`, `action` (the bound server action, or a stub), `deleteAction?` (removes the source being edited), `onClose`, `onSubmit?`.

## Behaviour

- **The row** is two lines: the title, which wraps as many lines as it needs (a link to the URL when there is one; the kind of resource when there is no title), and under it, in grey, who, the kind and the year joined by dots («Garry Kasparov · Libro · 2003»). Nothing is cut: the row grows with its title. Edition, specific reference and notes are read in the dialog.
- **The header** is the title and «Agregar fuente», without a count of the sources: the list under it is short enough to be seen. In the narrow column the title takes two lines.
- **The form**: `sourceTypeCode` (a `PlatformSelect`, required, the first kind chosen when adding), `originalTitle`, `authors` (free text, several separated by commas; the hint says it is who signs the resource, not the course), `url` (an `<input type="url">`, so the browser refuses anything that is not one), `publicationYear` (1400–2100) and `edition` side by side, `specificReference` and `notes`, whose hint says «Sólo para el equipo.». Every field but the kind says «Opcional» by itself (`PlatformFormField`, from its control); the foot no longer says «Sólo el tipo es obligatorio.» (2026-10-05). There is no publisher, platform nor provider field: the entities were taken out.
- Every opening remounts the form (`key` bumped in the dialog), so an abandoned edit never shows up the next time. `onSubmit` closes the dialog; the browser has validated the fields by then.
- The dialog is named by the form's heading, «Nueva fuente» or «Editar fuente»: `CourseSourceDialog` takes an id from `useId`, points the `<dialog>` at it with `aria-labelledby` and hands it to `CourseSourceForm` as `titleId`.
- A hidden `sourceId` tells `saveCourseSource` to rewrite that row instead of creating one; the action scopes it to the course, answers `sourceMissing` if it is gone, and `?error=` lands on the course editor's notice. «Quitar fuente», in the footer band of the dialog when editing, is a submit button of the same form with `formAction={deleteAction}` and `formNoValidate`: it posts `deleteCourseSource` with the same hidden field.

## Markup & styling

Block `.course-sources` is the card's content: the list, whose rules reach the card's edges through the panel's `--staff-panel-gutter`, and a row with its text column and its trigger. Block `.course-source-dialog`: a row's «Editar», the dialog's width (640 px) and rounding, head, body, the year/edition pair and the footer band. The fields' look comes from `.platform-form` and `.platform-select`; the dialog's motion from `.platform-dialog`.

**Elements:** `.course-sources__empty`, `.course-sources__list`, `.course-sources__row`, `.course-sources__text`, `.course-sources__title`, `.course-sources__meta`; `.course-source-dialog__dialog`, `.course-source-dialog__form`, `.course-source-dialog__head`, `.course-source-dialog__heading`, `.course-source-dialog__title`, `.course-source-dialog__subtitle`, `.course-source-dialog__close`, `.course-source-dialog__close-icon`, `.course-source-dialog__body`, `.course-source-dialog__pair`, `.course-source-dialog__foot`, `.course-source-dialog__actions`

**Other classes it renders:** `.platform-row-action` (and `_variant_danger` where the action destroys): «Editar», «Eliminar» and «Quitar» are the platform's row actions, written as words at the end of the row they belong to — see [Styling](/ui/styling).
**Modifiers:** none. «Agregar fuente», in the header, is the platform's button in its compact size (`.platform-button_variant_soft platform-button_size_compact`); a row's «Editar» is a quiet word, because one accent button per row would be a wall of accent. The dialog also has `.course-source-dialog__remove`.

**Other classes it renders:** `.platform-dialog`, `.platform-button`, `.platform-button_size_compact`, `.platform-button` («Cancelar»), `.platform-form`, `.platform-select`.

**Tokens:** `--platform-accent-ink`, `--platform-accent-soft`, `--platform-accent-wash`, `--platform-bg`, `--platform-border`, `--platform-danger`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** `(width < 640px)` stacks year and edition in the dialog.

## Usage

From `CourseEditorSection`:

```tsx
import { CourseSources } from "./course-sources/course-sources.comp";

<CourseSources courseId={course.id} sources={course.sources} sourceTypes={sourceTypes} />;
```
