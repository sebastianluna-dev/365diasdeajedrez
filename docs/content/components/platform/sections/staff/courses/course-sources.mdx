## Purpose

Where a course's material comes from: a book, a digital course, a video series, the academy's own work… Several sources per course, one row each, so a compilation is registered source by source. Only the kind of resource is required: material of the academy's own making needs no title, entity nor URL. The panel lists them; the dialog adds or edits one; a small form on each row removes it. It is the staff twin of the student's «Procedencia» block on the course page.

## Props

### `CourseSources`

| Prop          | Type                   | Required | Meaning                                                           |
| ------------- | ---------------------- | -------- | ----------------------------------------------------------------- |
| `courseId`    | `string`               | yes      | The course the sources hang from; bound into the actions.         |
| `sources`     | `CourseSourceAdmin[]`  | yes      | The course's sources in order, from `getCourseAdminDetail`.       |
| `sourceTypes` | `CatalogOption[]`      | yes      | The kinds of resource, from `listSourceTypes()`.                  |
| `entities`    | `SourceEntityOption[]` | yes      | The entities a source can cite, from `listSourceEntityOptions()`. |

### `CourseSourceDialog`

Same `courseId`, `sourceTypes` and `entities`, plus `source?: CourseSourceAdmin`: with it the trigger is «Editar» on the row and the form carries the source; without it the trigger is the quiet «Añadir fuente» button in the panel's header.

### `CourseSourceForm`

`source?`, `sourceTypes`, `entities`, `action` (the bound server action, or a stub), `onClose`, `onSubmit?`.

## Behaviour

- **The row** shows the kind of resource as a caption, the title (linked to the URL when there is one, «Sin título» when there is none), then authors, entity, year and edition, and the specific reference joined by dots, and the staff's notes in italics.
- **The form**: `sourceTypeCode` (a `PlatformSelect`, required, the first kind chosen when adding), `originalTitle`, `authors` (free text, several separated by commas; the hint says it is who signs the resource, not the course), the entity (a `PlatformSelect` with `emptyOption` «Ninguna» over `entities`, and under it a link to `/administracion/entidades` that opens in a new tab, since the select only refreshes with the page), `url` (an `<input type="url">`, so the browser refuses anything that is not http(s) before the submit), `publicationYear` and `edition` on one row, `specificReference` and `notes` (labelled «Sólo para el equipo»).
- **The entity field's label follows the kind of resource** through `entityFieldLabel`: «Editorial» for a book, «Plataforma o proveedor» for a digital course, «Entidad de origen» otherwise. The type select is controlled for that alone.
- Every opening remounts the form (`key` bumped in the dialog), so an abandoned edit never shows up the next time. `onSubmit` closes the dialog; the browser has validated the fields by then.
- A hidden `sourceId` tells `saveCourseSource` to rewrite that row instead of creating one; the action scopes it to the course, answers `sourceMissing` if it is gone, `entityMissing` if the entity is, and `?error=` lands on the course editor's notice. «Quitar» posts `deleteCourseSource` with the same hidden field.

## Markup & styling

Block `.course-sources` is the panel's content: the list, a row with its text column and its controls. Block `.course-source-dialog`: the two triggers, the dialog's width (640 px) and rounding, head, body, the entity note, the year/edition pair and the footer band. The fields' look comes from `.platform-form` and `.platform-select`; the dialog's motion from `.platform-dialog`.

**Elements:** `.course-sources__empty`, `.course-sources__list`, `.course-sources__row`, `.course-sources__text`, `.course-sources__type`, `.course-sources__title`, `.course-sources__link`, `.course-sources__meta`, `.course-sources__notes`, `.course-sources__controls`, `.course-sources__remove`; `.course-source-dialog__open`, `.course-source-dialog__dialog`, `.course-source-dialog__form`, `.course-source-dialog__head`, `.course-source-dialog__heading`, `.course-source-dialog__title`, `.course-source-dialog__subtitle`, `.course-source-dialog__close`, `.course-source-dialog__close-icon`, `.course-source-dialog__body`, `.course-source-dialog__entity-note`, `.course-source-dialog__pair`, `.course-source-dialog__foot`, `.course-source-dialog__note`, `.course-source-dialog__actions`

**Modifiers:** `.course-source-dialog__open_kind_edit` (the row's trigger, a bordered word instead of the quiet button).

**Other classes it renders:** `.platform-dialog`, `.platform-button`, `.platform-button_variant_quiet`, `.platform-button_variant_secondary`, `.platform-form`, `.platform-select`.

**Tokens:** `--platform-accent-ink`, `--platform-bg`, `--platform-border`, `--platform-danger`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** `(max-width: 620px)` stacks a row's controls under its text; `(max-width: 560px)` stacks year and edition.

## Usage

From `CourseEditorSection`:

```tsx
import { CourseSources } from "./course-sources/course-sources.comp";

<CourseSources courseId={course.id} sources={course.sources} sourceTypes={sourceTypes} entities={entities} />;
```
