## Purpose

Where a course's material comes from: a book, a digital course, a video series, the academy's own work… Several sources per course, one row each, so a compilation is registered source by source. Only the kind of resource is required: material of the academy's own making needs no title nor URL. The card lists them, in the narrow column of the editor with what is glanced at; the popup adds or edits one, and a confirmation on top of it deletes one. It is the staff twin of the student's «Procedencia» block on the course page.

## Props

### `CourseSources`

| Prop          | Type                  | Required | Meaning                                                     |
| ------------- | --------------------- | -------- | ----------------------------------------------------------- |
| `courseId`    | `string`              | yes      | The course the sources hang from; bound into the actions.   |
| `sources`     | `CourseSourceAdmin[]` | yes      | The course's sources in order, from `getCourseAdminDetail`. |
| `sourceTypes` | `CatalogOption[]`     | yes      | The kinds of resource, from `listSourceTypes()`.            |

### `CourseSourceDialog`

Same `courseId` and `sourceTypes`, plus `source?: CourseSourceAdmin`: with it the trigger is «Editar» on the row, a quiet word, the form carries the source and a [`PlatformConfirmPopup`](/components/platform/shared/platform-confirm-popup) is mounted beside the popup for deleting it; without it the trigger is «Agregar fuente» in the card's header, the platform's compact button.

### `CourseSourceForm`

`source?`, `sourceTypes`, `action` (the bound server action, or a stub), `onDelete?` (pressed «Eliminar fuente», the red word at the foot when editing: where the host opens the confirmation; without it the word is not drawn), `onClose`, `onSubmit?`.

## Behaviour

- **The row** is two lines: the title, which wraps as many lines as it needs (a link to the URL when there is one; the kind of resource when there is no title), and under it, in grey, who, the kind and the year joined by dots («Garry Kasparov · Libro · 2003»). Nothing is cut: the row grows with its title. Edition, specific reference and notes are read in the popup.
- **The header** is the title and «Agregar fuente», without a count of the sources: the list under it is short enough to be seen. In the narrow column the title takes two lines.
- **The form**: the subtitle «De dónde procede el material del curso.» as its first line, then `sourceTypeCode` (a `PlatformSelect`, required, the first kind chosen when adding, and the first control, so the popup opens on it), `originalTitle`, `authors` (free text, several separated by commas; the hint says it is who signs the resource, not the course), `url` (an `<input type="url">`, so the browser refuses anything that is not one), `publicationYear` (1400–2100) and `edition` side by side, `specificReference` and `notes`, whose hint says «Sólo para el equipo.». Every field but the kind says «Opcional» by itself (`PlatformFormField`, from its control); the foot no longer says «Sólo el tipo es obligatorio.» (2026-10-05). There is no publisher, platform nor provider field: the entities were taken out.
- **The popup** is a [`PlatformPopup`](/components/platform/shared/platform-popup) at `lg` (720px), named «Nueva fuente» or «Editar fuente» by its strip; the trigger opens it with `open(event)`, so the focus returns to it on closing. Every closing remounts the form (`key` bumped in the popup's `onClose`, not in the click that opens: `open()` focuses the form it finds), so an abandoned edit never shows up the next time. «Cancelar» and `onSubmit` close the popup; the browser has validated the fields by then.
- A hidden `sourceId` tells `saveCourseSource` to rewrite that row instead of creating one; the action scopes it to the course, answers `sourceMissing` if it is gone, and `?error=` lands on the course editor's notice.
- **Deleting** is «Eliminar fuente» (the source row is destroyed, so the verb is Eliminar), the platform's red row action at the foot when editing. It only opens the [`PlatformConfirmPopup`](/components/platform/shared/platform-confirm-popup) mounted as a sibling of the popup («¿Eliminar «Mi sistema»?», or the kind's label when the source has no title; «Se elimina la fuente del curso.»; «Eliminar fuente»), which stacks on top of the form. Its action is `deleteCourseSource.bind(null, courseId, source.id)`, both ids bound, nothing read from the form; when it settles the confirmation closes itself and `onDone` closes the popup beneath. «Cancelar» and Escape close only the confirmation.

## Markup & styling

Block `.course-sources` is the card's content: the list, whose rules reach the card's edges through the panel's `--staff-panel-gutter`, and a row with its text column and its trigger. Block `.course-source-dialog`: the form's body (padded 24px, to the strip's edge), the subtitle, the year/edition pair and the footer band. The shell (frame, strip, cross, width) is `PlatformPopup`'s and the confirmation draws itself; the fields' look comes from `.platform-form` and `.platform-select`.

**Elements:** `.course-sources__empty`, `.course-sources__list`, `.course-sources__row`, `.course-sources__text`, `.course-sources__title`, `.course-sources__meta`; `.course-source-dialog__form`, `.course-source-dialog__subtitle`, `.course-source-dialog__body`, `.course-source-dialog__pair`, `.course-source-dialog__foot`, `.course-source-dialog__actions`

**Other classes it renders:** `.platform-row-action` (and `_variant_danger` where the action destroys): «Editar», «Eliminar» and «Quitar» are the platform's row actions, written as words at the end of the row they belong to — see [Styling](/ui/styling).
**Modifiers:** none. «Agregar fuente», in the header, is the platform's button in its compact size (`.platform-button platform-button_size_compact`); a row's «Editar» is a quiet word, because one accent button per row would be a wall of accent; «Eliminar fuente», at the foot of the popup, is `.platform-row-action_variant_danger`.

**Other classes it renders:** `.platform-popup` and `.platform-confirm-popup` (both on `.platform-dialog`), `.platform-button`, `.platform-button_size_compact`, `.platform-form`, `.platform-select`.

**Tokens:** `--platform-bg`, `--platform-border`, `--platform-text-muted`; the row's in `course-sources.comp.css`

**Breakpoints:** `(width < 640px)` stacks year and edition in the popup.

## Usage

From `CourseEditorSection`:

```tsx
import { CourseSources } from "./course-sources/course-sources.comp";

<CourseSources courseId={course.id} sources={course.sources} sourceTypes={sourceTypes} />;
```
