## Purpose

A lesson's content is a game from its course's collection. Linking is not irreversible, which is why it is offered without ceremony: the lesson's own PGN goes dormant and comes back on unlinking. The search box is a GET against the lesson page itself, so it needs neither state nor JavaScript: the query stays in the URL and the page returns the already filtered candidates.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `courseId`, `chapterId`, `lessonId` | `string` | yes | Bound into `setLessonGame` and used for the search form's action. |
| `game` | `CourseGameRow` | no | The linked game, if any. |
| `candidates` | `CourseGameRow[]` | yes | Collection games matching the search. |
| `query` | `string` | no | What was searched, from `?partida=`. |

## Behaviour

- **Linked:** the game's title, detail and move count, a "Desvincular" form (posting the bound action without `gameId` unlinks) and a note about corrections propagating.
- **Not linked, empty collection and no query:** a single note pointing to the course record, because a search that can only return "nothing" is noise.
- **Otherwise:** the search form and the candidate list, each row with a "Vincular" form carrying a hidden `gameId`.
