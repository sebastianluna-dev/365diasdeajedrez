## Purpose

The same shape as the course editor one level down: metadata on the left with the lesson list under it, a summary and a back link on the right, and the chapter's game collection in its own tab because it is a different job.

## Props

| Prop        | Type                 | Required | Meaning                                                                                                                                                                                             |
| ----------- | -------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `chapter`   | `ChapterAdminDetail` | yes      | `id`, `courseId`, `courseName`, `courseStatusCode`, `order`, `name`, `description?`, `estimatedDuration?`, `lessons[]` (with `hasPgn`, `exerciseCount`, `roleCode`, `isPriority`, `progressCount`). |
| `gameCount` | `number`             | yes      | For the "Partidas" tab count.                                                                                                                                                                       |
| `errorCode` | `string`             | no       | `?error=` translated with `STAFF_ERROR_MESSAGES`.                                                                                                                                                   |

## Behaviour

- Metadata form: name, description, estimated duration.
- Lessons: a [`SortableList`](/components/platform/sections/staff/courses/sortable-list) whose rows show "Con PGN"/"Sin PGN", exercise count, a "Prioritaria" badge and the role label; delete only for a draft course with no progress; an inline "Añadir lección" form; intro and closing buttons while each is missing.
- The aside counts lessons, lessons with PGN, exercises and duration.

## Usage

From `app/(platform)/administracion/cursos/[courseId]/capitulos/[chapterId]/page.tsx`:

