## Purpose

The authors of **one** course. The authors themselves (name, biography, photo) are created and edited in the dialog «Gestionar» opens; here they are added to the course, given a role and taken out.

## Props

| Prop         | Type                | Required | Meaning                                                                                               |
| ------------ | ------------------- | -------- | ----------------------------------------------------------------------------------------------------- |
| `courseId`   | `string`            | yes      | The course the actions are bound to.                                                                  |
| `authors`    | `CourseAuthorRow[]` | yes      | `{ authorId, authorName, authorPhoto?, roleCode, roleLabel, order }[]`, in the order they were added. |
| `allAuthors` | `AuthorAdminRow[]`  | yes      | Every author: the ones the search can suggest and the dialog lists.                                   |
| `roles`      | `CatalogOption[]`   | yes      | `AuthorRole`. The first is the one an author is added with.                                           |

## Behaviour

- **Each author is a row**: avatar (a circle), name, role and «Quitar» (`operation: "remove"`).
- **The role is changed in the row.** It is a [`PlatformSelect`](/components/platform/shared/platform-select) drawn as the line of text it replaces: choosing another role posts `operation: "role"` in a transition, and the select is remounted with what the server saved. An author is added as «Autor del contenido» and becomes «Adaptación digital» here.
- **No order to keep**: the authors are listed as they were added. The card has no arrows, and the action no longer has `up` nor `down`.
- **The search suggests as it is typed**: `suggestAuthors` over the authors who are not in the course, ignoring case and accents, the ones that start with what was typed first, five at most. Nothing typed, nothing suggested.
- **Each suggestion is a form** whose button is the whole row (avatar, name, «Añadir»); it posts `operation: "add"` with the first role. **Enter** in the search adds the first suggestion, which is the one that is lit. Adding empties the search.
- When nothing matches: «Ningún autor coincide. Créalo en «Gestionar».», or «Todos los autores están ya en este curso.» when there is nobody left to add.
- A failure of the action comes back to the course's page as `?error=`, which the editor renders.

## Markup & styling

Block `.course-authors`, inside a `.staff-panel`. The rules between authors reach the card's edges through the panel's `--staff-panel-gutter`.

**Elements:** `.course-authors__list`, `.course-authors__row`, `.course-authors__text`, `.course-authors__name`, `.course-authors__role`, `.course-authors__remove-form`, `.course-authors__empty`, `.course-authors__search`, `.course-authors__input`, `.course-authors__suggestions`, `.course-authors__suggestion`, `.course-authors__suggestion-name`, `.course-authors__suggestion-action`, `.course-authors__none`

**Other classes it renders:** `.platform-row-action` (and `_variant_danger` where the action destroys): «Editar», «Eliminar» and «Quitar» are the platform's row actions, written as words at the end of the row they belong to — see [Styling](/ui/styling).
**Modifiers and states:** `.course-authors__suggestion_state_first`

**Other selectors it styles:** `.platform-select`, `.platform-select__trigger`, `.platform-select__chevron`, `.platform-select__content` (the role, without its box).

**Tokens:** `--platform-accent`, `--platform-accent-ink`, `--platform-accent-soft`, `--platform-accent-wash`, `--platform-border`, `--platform-danger`, `--platform-surface`, `--platform-text`, `--platform-text-subtle`; the panel's `--staff-panel-gutter`

No media queries. Transitions are off under `prefers-reduced-motion`.

## Usage

From `components/platform/sections/staff/courses/course-editor.section.tsx`:

```tsx
import { CourseAuthors } from "./course-authors/course-authors.comp";

<CourseAuthors courseId={course.id} authors={course.authors} allAuthors={authors} roles={authorRoles} />;
```
