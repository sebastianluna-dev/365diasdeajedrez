## Purpose

Creating a course is three fields, so it lives in a modal on the catalog page rather than on a page of its own (`/administracion/cursos/nuevo` no longer exists). The modal is a **native `<dialog>`**: it brings focus trapping, closing with Escape and the backdrop without writing any of that by hand. `NewCourse` is the button and the dialog; `NewCourseForm` is the form, split off so the story can mount it with a stub in place of the server action. It is the staff twin of [`NewStudy`](/components/platform/sections/studies/studies-list/new-study).

## Props

| Prop    | Type              | Required | Meaning                                                                       |
| ------- | ----------------- | -------- | ----------------------------------------------------------------------------- |
| `types` | `CatalogOption[]` | yes      | The course types on offer, from `listCourseTypes()`; the first one is chosen. |

## Behaviour

- **The trigger** is the quiet grey `platform-button_variant_quiet`, like the rest of the catalog, which has no orange button in it.
- The form is a `PlatformForm` with `action={createCourse}` and `autoComplete="off"`: a head (dark tile with the white rook, title, the "sólo lo imprescindible" subtitle, close button), `name` (required, max 160, autofocus, controlled so the submit can watch it), `slug` (required, max 160, `pattern` of lowercase words joined by single hyphens, with its own `patternMismatch` text, controlled too) and `typeCode`, a `PlatformSelect` over `types` with the first one chosen. A footer band says the course is born in draft and carries the buttons.
- **The slug writes itself.** When the name loses focus, the slug takes `generateSlug(name)` (the same helper the CMS uses: lowercase, accents stripped, words joined by single hyphens), as long as the slug is still the form's and not the user's. Once they type a slug of their own it is left alone whatever the name does; clearing it hands it back to the name. The field's hint says so.
- **Crear curso** stays disabled until both the name and the slug have a character that is not a space.
- The dialog fades in with a short rise and fades out the same way: that motion belongs to `.platform-dialog`, the shared frame every dialog of the platform carries, so this stylesheet only sets the width and the rounding.
- Every opening remounts the form (`key` bumped in `NewCourse`), so it never opens with what was typed the last time.
- `onSubmit` closes the dialog. The browser validates `required` and `pattern` before the submit event fires (the form primitive only replaces the bubble with the field's message), so the dialog does not close with a bad form.
- The action creates the course in draft and redirects to its editor. A failure it can only see on the server (a slug already in use, the rate limit) comes back to the catalog as `?error=<code>`, which [`CoursesAdminSection`](/components/platform/sections/staff/courses/courses-admin-section) renders as a `PlatformNotice` under the header.

## Markup & styling

Block `.new-course`: the dialog's width and rounding, the head, the body's spacing and the footer band. The fields' and controls' look come from `.platform-form` and `.platform-select`.

**Elements:** `.new-course__dialog`, `.new-course__form`, `.new-course__head`, `.new-course__tile`, `.new-course__heading`, `.new-course__title`, `.new-course__subtitle`, `.new-course__close`, `.new-course__close-icon`, `.new-course__body`, `.new-course__foot`, `.new-course__note`, `.new-course__actions`

**Other classes it renders:** `.platform-dialog` (the shared dialog frame in `platform.css`), `.platform-button`, `.platform-button_variant_quiet` (the trigger) and `.platform-button_variant_secondary` (inside the dialog), `.platform-form`, `.platform-select`.

**Tokens:** `--platform-bg`, `--platform-border`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** none of its own. The shared dialog frame handles narrow screens and reduced motion.

## Usage

From `CoursesAdminSection`:

import { NewCourse } from "@/components/platform/sections/staff/courses/new-course/new-course.comp";

<NewCourse types={types} />;
