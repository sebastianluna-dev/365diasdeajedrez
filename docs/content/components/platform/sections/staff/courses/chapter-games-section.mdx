## Purpose

Course content is PGN, and this is where it enters. Each chapter has a collection; its lessons choose their game from it, so fixing a game here fixes every lesson that uses it at once. It is the **only** place in the staff panel where a PGN is pasted. A game already in the collection is not pasted again to correct it: it opens on the board ([`ChapterGameSection`](/components/platform/sections/staff/courses/chapter-game-section)), where it is read and edited.

The name of the record and its tabs are not here: they are the [layout](/components/platform/sections/staff/courses/chapter-record-head) the three pages share.

## Props

| Prop           | Type                      | Required | Meaning                                                                                                                                                     |
| -------------- | ------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `chapter`      | `ChapterAdminDetail`      | yes      | For the head, tabs and bound actions.                                                                                                                       |
| `games`        | `CourseGameRow[]`         | yes      | The collection with `lessonCount` per game.                                                                                                                 |
| `errorCode`    | `string`                  | no       | `?error=` translated with `STAFF_ERROR_MESSAGES`.                                                                                                           |
| `importReport` | `PgnImportReport \| null` | no       | The result of the import that has just happened (`?importadas=`, read by the page with `readImportReport`): how many games went in and how many stayed out. |

## Behaviour

- Rows show title, detail, move count and how many lessons use the game. The title and «Abrir», at the right edge, lead to the game on the board (`game.href`). "Quitar" is offered only when `lessonCount === 0`: the foreign key is `SET NULL`, so deleting a used game would not fail, it would empty those lessons silently.
- The import form is a textarea posting `importChapterGames`; a PGN with several games creates all of them, up to `PGN_MAX_GAMES` (500) per import, which the placeholder says. The action comes back with the result, and a notice above the panel says it (`pgnImportNotice`): «Se importaron 12 partidas.» in green, or, in the neutral notice, how many of how many went in and why the rest stayed out (entries without moves, games past the limit). A paste with nothing in it answers «Ese PGN no se puede leer…»; one over 2 MB, «El PGN es demasiado grande.»
