## Purpose

Course content is PGN, and this is where it enters. Each chapter has a collection; its lessons choose their game from it, so fixing a game here fixes every lesson that uses it at once. It is the **only** place in the staff panel where a PGN is pasted.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `chapter` | `ChapterAdminDetail` | yes | For the head, tabs and bound actions. |
| `games` | `CourseGameRow[]` | yes | The collection with `lessonCount` per game. |
| `errorCode` | `string` | no | `?error=` translated with `STAFF_ERROR_MESSAGES`. |

## Behaviour

- Rows show title, detail, move count and how many lessons use the game. "Quitar" is offered only when `lessonCount === 0`: the foreign key is `SET NULL`, so deleting a used game would not fail, it would empty those lessons silently.
- The import form is a textarea posting `importChapterGames`; a PGN with several games creates all of them.
