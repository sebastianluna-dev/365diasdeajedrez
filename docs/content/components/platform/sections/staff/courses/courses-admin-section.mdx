## Purpose

The entry to course authoring. Courses are born in draft and are only visible in the platform once published, which the header states. The search is a plain GET so it can be shared and undone with the back button; the active status travels with it as a hidden field so it is not lost when searching. Each row is entirely a link: in a seven-column table, forcing the user to aim at the name is asking for marksmanship.

## Props

| Prop     | Type     | Required | Meaning                                     |
| -------- | -------- | -------- | ------------------------------------------- |
| `query`  | `string` | no       | Text search over name and slug, from `?q=`. |
| `status` | `string` | no       | Status filter, from `?estado=`.             |

## Behaviour

- `filterHref` builds the four filter links (Todos, Publicados, Borradores, Archivados) preserving the query; the active one gets `aria-current`.
- Totals line: courses, chapters, lessons over the filtered set.
- Rows show a 44 px cover frame (painted even without a cover; `isDisplayableImage` guards the URL), name and slug, type, a status pill with a per-status modifier, chapter and lesson counts, publish date, and a chevron.
- Empty copy distinguishes "nothing matches" from "no courses yet".
