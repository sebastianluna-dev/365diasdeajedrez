## Purpose

A lesson's exercises are `Exercise` rows owned by the lesson (D04, D05; [Exercises → Courses](/platform/exercises#courses-phase-2)), authored with the same editor as the bank's. This is their list in the lesson's page: it draws each one as the bank's card — the start position, the title that opens the staff editor, «Publicado»/«Borrador», the kind, the difficulty, the student's moves, the topics — and decides what can be done to it. Not behind `EXERCISES_ENABLED`: it replaced the panel that was live before phase 2, over data its migration moved.

## Behaviour

- The exercises in play, in `lessonOrder`: beside each card two square keys, «Subir» and «Bajar» (`moveLessonExercise`, a swap through `planSwap`), the first and the last disabled at their end.
- The card's words come from `lessonExerciseAllowed`: **«Eliminar»** only for an exercise nobody has tried — behind the confirmation of `DeleteExercise`, which here says «Se elimina el ejercicio con su solución. Los alumnos ya no lo verán en la lección.» —, and **«Archivar»** instead for one with attempts (PUBLISHED or DRAFT → ARCHIVED through the status writer, which takes its order away and keeps the row; the ones left close the gap in the same transaction, `closeLessonExerciseOrderGaps`, since 2026-10-16). Never both, never «Duplicar» (AGENTS.md: one action, one verb; «Quitar» would mean a deletion here). «Archivar» has no confirmation: it is reversible.
- With no exercise in play, one sentence says what an exercise is and where the student meets it.
- «Agregar ejercicio» is a `.platform-button` link to the lesson's new-exercise route, where [`LessonExerciseEditorSection`](/components/platform/sections/staff/courses/lesson-exercise-editor-section) mounts the editor.
- The archived ones, when any, under «Archivados» with a note (they are kept for the attempts made at them; «Restaurar» returns one as a draft at the end): the same cards, stepped back by the card's own archived state, each with **«Restaurar»** (`restoreLessonExercise`, since 2026-10-16: ARCHIVED → DRAFT, the place one past the highest given back in the same transaction; the notice `exerciseRestoredToLesson` says it came back as a draft, to publish again).
- «Agregar desde la biblioteca» (D28) is written (`copyLibraryExerciseToLesson`) and not drawn: it waits for the library of phase 4.

## Usage

From `components/platform/sections/staff/courses/lesson-editor.section.tsx`:

```tsx
import { LessonExercises } from "./lesson-exercises.comp";

<LessonExercises
  courseId={lesson.courseId}
  chapterId={lesson.chapterId}
  lessonId={lesson.id}
  exercises={lesson.exercises}
/>;
```
