# `CourseNameFields`

|            |                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/staff/courses/course-name-fields.comp.tsx`                                                  |
| Kind       | Client Component                                                                                                          |
| Stylesheet | `course-name-fields.comp.css` → block `.course-name-fields`                                                               |
| Used by    | [`CourseEditorSection`](/components/platform/sections/staff/courses/course-editor-section)                                |
| Composes   | [`FormField`](/components/platform/shared/form-field), [`PlatformInfoTip`](/components/platform/shared/platform-info-tip) |
| Uses       | `slugAfterRename` from `lib/generate-slug`                                                                                |

## Purpose

The one piece of the course's metadata form that needs state, split out so the rest of the editor stays on the server. It renders the «Nombre» and «Slug» fields inside the form that holds it (`#course-metadata`); it has no form nor action of its own.

## Props

| Prop   | Type     | Required | Meaning                  |
| ------ | -------- | -------- | ------------------------ |
| `name` | `string` | yes      | The course's saved name. |
| `slug` | `string` | yes      | The course's saved slug. |

## Behaviour

- **The slug follows the name.** When the name loses focus **having changed**, the slug becomes `generateSlug(name)`, whatever it was before, a slug typed by hand included.
- Leaving the name as it was touches nothing, so tabbing through the field does not undo a slug of one's own.
- A name that yields no slug («¡¿?!», or empty) leaves the slug alone: a rename never empties the field.
- **What the slug is goes in an "i"** inside its input, at the right end: a [`PlatformInfoTip`](/components/platform/shared/platform-info-tip) with «Se actualiza al cambiar el nombre; puedes ajustarlo después. Minúsculas, números y guiones.», instead of a hint under the field. The format is still enforced by the input's `pattern`, whose `title` words the browser's message.
- The slug field is drawn with the classes of `.platform-field` but is not a `FormField`: there the whole field is a `<label>`, and the button inside it would end up in the input's name. Label and input are tied with `htmlFor`/`id` (`useId`).
- The slug stays editable; what is typed there holds until the next rename.
- Nothing is saved until «Guardar metadatos»: a slug already taken is answered by `updateCourse` with «Ese identificador (slug) ya está en uso.».
- Unlike [`NewCourseForm`](/components/platform/sections/staff/courses/new-course) and [`LevelForm`](/components/platform/sections/staff/levels/level-form), where a slug typed by hand is left alone, here the name always rules: the rule is `slugAfterRename(previousName, nextName, currentSlug)` in `lib/generate-slug.ts`, tested there.
- Both inputs are uncontrolled (`defaultValue`), like the rest of the form; the only thing kept is a ref with the name the field had when it took focus.

## Markup & styling

Block `.course-name-fields`, with `display: contents`: it exists to place the "i", and the two fields stay direct items of the form's column, spaced by its gap like any other.

**Elements:** `.course-name-fields__slug` (the slug's control: `position: relative`, the input with room at its right end)

**Other selectors it styles:** `.platform-info-tip` (absolute, centred vertically at the input's right end).

**Other classes it renders:** `.platform-field`, `.platform-field__label`, `.platform-field__control`.

No tokens, no media queries.

## Usage

From `components/platform/sections/staff/courses/course-editor.section.tsx`:

```tsx
import { CourseNameFields } from "./course-name-fields.comp";

<form id={METADATA_FORM_ID} className="course-editor__form" action={updateCourse.bind(null, course.id)}>
  <CourseNameFields name={course.name} slug={course.slug} />
  {/* description, content types, levels… */}
</form>;
```
