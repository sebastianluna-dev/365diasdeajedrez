## Purpose

The header of the course screens lives in one component rather than in each page, so the four of them (catalog, course, chapter, lesson) name themselves the same way. It carries no trail above the title: the platform has none (2026-09-27). What says where one is is the size of the title: `level="root"` for a screen of the menu, whose title weighs the same as "Alumnos", and `nested` (the default) for what hangs from one, a step down.

`StaffEditorLayout` is the two-column frame: the work on the left and, on the right, what is glanced at. The narrow column is 360px, in pixels and not fractions so it does not stretch on wide screens, where a four-figure list at half the screen looks empty.

## Props

### `StaffEditorHead`

| Prop          | Type                 | Required | Meaning                                                                                                            |
| ------------- | -------------------- | -------- | ------------------------------------------------------------------------------------------------------------------ |
| `title`       | `string`             | yes      | The `<h1>`.                                                                                                        |
| `level`       | `"root" \| "nested"` | no       | `root`: a screen of the menu (the catalog), with the big title. `nested` (default): a course, a chapter, a lesson. |
| `badge`       | `ReactNode`          | no       | Beside the title, on its row: a course's status pill, for instance.                                                |
| `meta`        | `ReactNode`          | no       | Short facts under the title.                                                                                       |
| `actions`     | `ReactNode`          | no       | Top right: search, "Nuevo curso", "Ver en la plataforma".                                                          |
| `description` | `string`             | no       | One sentence under the title.                                                                                      |

### `StaffEditorLayout`

| Prop       | Type        | Required | Meaning                                                    |
| ---------- | ----------- | -------- | ---------------------------------------------------------- |
| `children` | `ReactNode` | yes      | The main column.                                           |
| `aside`    | `ReactNode` | no       | The narrow column; without it the layout is single-column. |

## Behaviour

None.

## Markup & styling

Two blocks in one sheet (102 lines).

**Elements:** `.staff-editor-head__bar`, `.staff-editor-head__heading`, `.staff-editor-head__title-row`, `.staff-editor-head__title`, `.staff-editor-head__description`, `.staff-editor-head__meta`, `.staff-editor-head__actions`; `.staff-editor__main`, `.staff-editor__aside`

**Modifiers and states:** `.staff-editor-head_level_root`, `.staff-editor_layout_single`

**Tokens:** `--platform-text`, `--platform-text-muted`

**Breakpoints:** `(width < 1024px)` stacks the aside under the main column, before the two columns of cards of the course's metadata would cut their longest name; `(width < 768px)` stacks the actions under the heading.

## Usage

From `components/platform/sections/staff/courses/chapter-record-head.comp.tsx`:

```tsx
import { StaffEditorHead } from "./staff-editor.comp";

<StaffEditorHead
  title={chapter.name}
  meta={
    <>
      <span>Capítulo {chapter.order}</span>
      <span>{chapter.courseName}</span>
      {chapter.isPriority && <span className="platform-tag platform-tag_variant_accent">Prioridad</span>}
    </>
  }
/>;
```
