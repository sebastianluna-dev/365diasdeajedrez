## Purpose

The course → chapter → lesson trail has four levels. Without a breadcrumb on every screen, the only way to go up one step is the browser's back button, so the header lives in one component rather than in each page. Without crumbs a screen is top-level and its title weighs the same as "Alumnos"; with crumbs it hangs from something and goes down one step, so the hierarchy is seen without reading the trail.

`StaffEditorLayout` is the two-column frame: the work on the left and, on the right, what is glanced at. The narrow column is in pixels and not fractions so it does not stretch on wide screens, where a four-figure list at half the screen looks empty.

## Props

### `StaffEditorHead`

| Prop          | Type        | Required | Meaning                                                                                                      |
| ------------- | ----------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| `crumbs`      | `Crumb[]`   | no       | `{ label, href }[]` up to here, **without** the current place, which is `title`. Absent means a root screen. |
| `title`       | `string`    | yes      | The `<h1>`, and the last crumb.                                                                              |
| `badge`       | `ReactNode` | no       | Beside the title, on its row: a course's status pill, for instance.                                          |
| `meta`        | `ReactNode` | no       | Short facts under the title.                                                                                 |
| `actions`     | `ReactNode` | no       | Top right: search, "Nuevo curso", "Ver en la plataforma".                                                    |
| `description` | `string`    | no       | One sentence under the title.                                                                                |

### `StaffEditorLayout`

| Prop       | Type        | Required | Meaning                                                    |
| ---------- | ----------- | -------- | ---------------------------------------------------------- |
| `children` | `ReactNode` | yes      | The main column.                                           |
| `aside`    | `ReactNode` | no       | The narrow column; without it the layout is single-column. |

## Behaviour

None. The crumbs are a `<nav aria-label="Ruta">` with the current title as a non-link span.

## Markup & styling

Two blocks in one sheet (133 lines).

**Modifiers and states:** `.staff-editor-head_level_root`, `.staff-editor_layout_single`

**Tokens:** `--platform-accent-ink`, `--platform-font`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** `(max-width: 1080px)` stacks the aside under the main column; `(max-width: 760px)` stacks the actions under the heading.

## Usage

From `components/platform/sections/staff/courses/chapter-editor.section.tsx`:

```tsx
import { StaffEditorHead, StaffEditorLayout } from "./staff-editor.comp";

<StaffEditorHead
  crumbs={[
    { label: "Cursos", href: staffRoutes.courses },
    { label: chapter.courseName, href: staffRoutes.courseDetail(chapter.courseId) },
  ]}
  title={chapter.name}
  meta={
    <>
      <span>Capítulo {chapter.order}</span>
      <span>
        {chapter.lessons.length} lección{chapter.lessons.length === 1 ? "" : "es"}
      </span>
    </>
  }
/>;
```
