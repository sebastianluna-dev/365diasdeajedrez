## Purpose

Authors only matter next to the courses they sign, so they are managed from the courses' pages and not from a page of their own: `/administracion/autores` and its menu entry are gone (2026-09-27). The same dialog opens from the catalog's header («Autores») and from the «Autores» card of a course («Gestionar»), where the author the search does not find is a press away.

An author is editorial content, not a restricted domain whose code the logic compares, which is why it is edited from the interface. Nothing is deleted: an author is taken out of each course.

## Behaviour

- **One native `<dialog>`, two views.** It always opens on the **list**: avatar, name, «2 cursos · equipo-365» and «Editar» per author, with «Nuevo autor» in the footer band. «Editar» and «Nuevo autor» swap the list for the **form** inside the same dialog, and the title follows («Autores», «Editar autor», «Nuevo autor»).
- **Saving goes back to the list**, which comes refreshed; «Cancelar» does too, without saving. The dialog is closed by its cross or with Escape.
- **The slug is not a field.** It is the name's: the line under the name says which one it will be as the name is typed («Slug: equipo-365 (se genera solo)»), with a number behind when another author has it («equipo-365-2»). It is `authorSlugFor`, the same rule the action applies, which is the one that decides. An author who keeps their name keeps their slug.
- **The photo is secondary**: a row with how the author looks now (the photo, or the initials that stand in for it), a line of text and «Añadir foto» / «Cambiar foto» / «Quitar». It uploads to Cloudinary with `useImageUpload`, cropped to a square, and travels in a hidden `photo` field.
- **The outcome comes back to the form** (`useActionState`), not to a `?error=`: the dialog stays open over the page, and an error the page rendered would be read by nobody. A failure shows as a [`PlatformNotice`](/components/platform/shared/platform-notice) above the fields (`authorName` for a name with no letter nor number, `authorPhoto`, `authorSlug`, `authorMissing`, `throttled`), with the messages of `STAFF_ERROR_MESSAGES`. It is the third form of the platform on `useActionState`, with account creation and password reset.
- The form is remounted on every opening (`key`), so it never opens with what was typed the last time nor with the last outcome.
- **The avatar** is decorative (`aria-hidden`): the name is always written next to it. Without a photo it draws `authorInitials(name)` («Equipo 365» → «E3») on one of two tiles, ink or soft, which `authorTone(name)` picks from the name: the same author looks the same everywhere, and a list without photos is not a column of identical tiles.
- A long list scrolls inside the dialog (`max-height: min(420px, 50vh)`).

## Markup & styling

Block `.authors-manager`. The dialog is `.platform-dialog`, which sets the centring, the backdrop and the entry and exit motion; the block sets its width (560px) and rounding. Every button it renders — the trigger, a row’s «Editar», «Nuevo autor» — is the shared soft one (`.platform-button`), the rows’ and the trigger’s in the compact size.

**Elements:** `.authors-manager__dialog`, `.authors-manager__head`, `.authors-manager__heading`, `.authors-manager__title`, `.authors-manager__subtitle`, `.authors-manager__close`, `.authors-manager__close-icon`, `.authors-manager__body`, `.authors-manager__list`, `.authors-manager__row`, `.authors-manager__row-text`, `.authors-manager__row-name`, `.authors-manager__row-meta`, `.authors-manager__empty`, `.authors-manager__form`, `.authors-manager__photo`, `.authors-manager__photo-file`, `.authors-manager__photo-text`, `.authors-manager__photo-actions`, `.authors-manager__photo-remove`, `.authors-manager__foot`, `.authors-manager__note`, `.authors-manager__actions`


**Other classes it renders:** `.platform-row-action` (and `_variant_danger` where the action destroys): «Editar», «Eliminar» and «Quitar» are the platform's row actions, written as words at the end of the row they belong to — see [Styling](/ui/styling).
**Modifiers and states:** `.authors-manager__photo-text_tone_error`

**Other selectors it styles:** `.platform-form__field > textarea` (a shorter textarea).

**Other classes it renders:** `.platform-dialog`, `.platform-button`, `.platform-button_size_compact`, `.platform-button` (only «Cancelar»), `.platform-form`.

Block `.author-avatar`: **modifiers** `.author-avatar_size_{small,medium,large}`, `.author-avatar_shape_{tile,circle}`, `.author-avatar_tone_{ink,soft}`, `.author-avatar_kind_photo`; **element** `.author-avatar__image`.

**Tokens:** `--platform-accent-ink`, `--platform-accent-soft`, `--platform-accent-wash`, `--platform-bg`, `--platform-border`, `--platform-danger`, `--platform-surface`, `--platform-surface-neutral`, `--platform-surface-sunken`, `--platform-text`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** `(max-width: 520px)` lets the photo row wrap.

## Usage

From `components/platform/sections/staff/courses/courses-admin.section.tsx`:

```tsx
import { AuthorsManager } from "./authors-manager/authors-manager.comp";

<AuthorsManager authors={authors} />;
```

From `components/platform/sections/staff/courses/course-authors/course-authors.comp.tsx`, as the action of the «Autores» card:

```tsx
<AuthorsManager authors={allAuthors} label="Gestionar" size="compact" />
```
