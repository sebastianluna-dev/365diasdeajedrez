## Purpose

Authors only matter next to the courses they sign, so they are managed from the courses' pages and not from a page of their own: `/administracion/autores` and its menu entry are gone (2026-09-27). The same button sits in the catalog's header and in the «Autores» card of a course, where the author missing from the select is a press away.

An author is editorial content, not a restricted domain whose code the logic compares, which is why it is edited from the interface. Nothing is deleted: an author is taken out of each course.

## Behaviour

- **One native `<dialog>`, two views.** It always opens on the **list** (name, how many courses, «Editar» per author, «Nuevo autor» in the footer band). «Editar» and «Nuevo autor» swap the list for the **form** inside the same dialog; «Todos los autores» and «Cancelar» go back.
- **Fields:** `name` (required, 160), `slug` (required, lowercase words joined by hyphens), `photo` (optional `http(s)` URL), `bio` (optional, 1000). On a new author the slug writes itself from the name when the name loses focus, while it is the form's and not the user's; an existing author's slug is only changed by hand.
- **Saving closes the dialog**, like the other dialogs of the panel. The action revalidates `/administracion/cursos` and what hangs from it, so the list and the course's author select come back refreshed; `updateAuthor` also revalidates the student's courses, which show the name.
- **A failure is reported on the page the dialog was opened on**: the form carries `returnTo`, the action passes it through `safeReturnTo` and answers `?error=` there (`authorSlug` «Ya existe un autor con ese slug.», `authorMissing`, `invalid`, `throttled`), which the page renders as a [`PlatformNotice`](/components/platform/shared/platform-notice).
- The form is remounted per author (`key`), because its fields are uncontrolled.
- A long list scrolls inside the dialog (`max-height: min(420px, 50vh)`).

## Usage

From `components/platform/sections/staff/courses/courses-admin.section.tsx`:

```tsx
import { AuthorsManager } from "./authors-manager/authors-manager.comp";

<AuthorsManager authors={authors} returnTo={staffRoutes.courses} />;
```

From `components/platform/sections/staff/courses/course-editor.section.tsx`, as the action of the «Autores» card:

```tsx
<AuthorsManager authors={authors} returnTo={staffRoutes.courseDetail(course.id)} label="Gestionar" />
```
