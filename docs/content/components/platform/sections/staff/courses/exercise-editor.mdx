## Purpose

An exercise is a mode, an optional prompt, the moves played **before** it starts and the line to train, all as SAN, the same format the seed uses. The server derives the frozen starting position from those moves. Typing SAN by hand works, but the internal `ExerciseFields` form brings an [`ExerciseMovePicker`](/components/platform/sections/staff/courses/exercise-move-picker) that fills the two move fields from the lesson's PGN, so a typo is not discovered only on save.

## Behaviour

- Rows show the mode tag, the prompt or the line, a "Desactualizado" tag when `isStale`, the ply range, and controls: up and down (`moveExercise` forms), "Editar" (or "Volver a congelar" for stale ones, toggling `editingId`), "Eliminar".
- A stale exercise not being edited shows a `role="alert"` warning: the lesson's PGN changed after it was frozen.
- `ExerciseFields`: mode select, prompt, `afterSans` and `lineSans`. The two move inputs are **controlled** because the picker writes them too; `afterSans` is not preloaded when editing, because the frozen copy stores the position, not the path that led to it.
- "Añadir ejercicio" toggles the create form.
