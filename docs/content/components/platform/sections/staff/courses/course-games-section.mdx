## Purpose

The "Partidas" tab of a course: the overview that the split by chapters would otherwise take away. Games belong to a chapter's collection (a game without a chapter would have no collection to go to), so here they are only looked at, with the chapter named on each row and a note pointing back to the course record to add or remove.

## Props

| Prop     | Type                | Required | Meaning                                                           |
| -------- | ------------------- | -------- | ----------------------------------------------------------------- |
| `course` | `CourseAdminDetail` | yes      | For the head, badge and tab links.                                |
| `games`  | `CourseGameRow[]`   | yes      | `{ id, title, detail?, chapterName?, moveCount, lessonCount }[]`. |

## Behaviour

None: a grid of rows or an [`EmptyState`](/components/platform/shared/empty-state).
