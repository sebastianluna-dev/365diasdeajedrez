## Purpose

The "Partidas" tab of a course: the overview that the split by chapters would otherwise take away. Games belong to a chapter's collection (a game without a chapter would have no collection to go to), so here they are only looked at, with the chapter named on each row and a note pointing back to the course record to add or remove.

The name of the record and its tabs are not here: they are the [layout](/components/platform/sections/staff/courses/course-record-head) the three pages share.

## Props

| Prop     | Type                | Required | Meaning                                                           |
| -------- | ------------------- | -------- | ----------------------------------------------------------------- |
| `course` | `CourseAdminDetail` | yes      | For the link back to the course when there are no games.          |
| `games`  | `CourseGameRow[]`   | yes      | `{ id, title, detail?, chapterName?, moveCount, lessonCount }[]`. |

## Behaviour

None: a grid of rows or an [`EmptyState`](/components/platform/shared/empty-state).

## Markup & styling

Block `.course-games` (112 lines).

**Elements:** `.course-games__table`, `.course-games__head`, `.course-games__rows`, `.course-games__row`, `.course-games__text`, `.course-games__title`, `.course-games__detail`, `.course-games__cell`, `.course-games__number`, `.course-games__note`, `.course-games__link`

**Tokens:** own `--course-games-columns`; `--platform-accent-ink`, `--platform-bg`, `--platform-border`, `--platform-text`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** `(width < 768px)` lets the table scroll sideways (head and rows keep a 720px minimum) instead of breaking the grid.

## Usage

From `app/(platform)/administracion/cursos/[courseId]/partidas/page.tsx`:

```tsx
import { CourseGamesSection } from "@/components/platform/sections/staff/courses/course-games.section";

<CourseGamesSection course={course} games={games} />;
```
