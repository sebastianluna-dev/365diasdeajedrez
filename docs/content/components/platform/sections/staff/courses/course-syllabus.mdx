## Purpose

The chapters of a course read as what they are for the student: a path with a first step and a last one. **The list itself is [`SyllabusList`](/components/platform/sections/staff/courses/syllabus-list)**, the same one a chapter's lessons are drawn with — they are the same thing one level apart —; this component gives it the chapters, the actions that create, reorder and delete them, and the «Temario» panel around it. The card is a vertical rail whose nodes are, top to bottom, the introduction, the numbered chapters, the slot for a new one and the closing.

## Props

| Prop       | Type                | Required | Meaning                                                                                                                                               |
| ---------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `courseId` | `string`            | yes      | The course the actions are bound to.                                                                                                                  |
| `chapters` | `ChapterAdminRow[]` | yes      | `{ id, name, order, roleCode?, roleLabel?, lessonCount, durationMin?, progressCount, href }[]`, the introduction in front and the closing at the end. |
| `isDraft`  | `boolean`           | yes      | A chapter is only deleted from a draft course (and only without progress from any student).                                                           |

## Behaviour

- **The header** is «Temario» with «3 capítulos · 15 lecciones».
- **Introduction and closing** have a fixed place, first and last, on a soft tile with a piece (a pawn, a king). While one does not exist its slot is a dashed box, «+ Añadir introducción» / «+ Añadir cierre», which creates it (`createChapter` with `role`); there is at most one of each, which the database's unique index guarantees.
- **Each chapter** is its number on a dark node, its name (a link to its editor), «2 lecciones · 14 min» — closed by «· Prioridad» when the chapter is marked as priority — and «Editar». The minutes are the chapter's own estimate or, when it has none, what its lessons add up to; without either, only the lessons are counted.
- **The numbered node is the handle**: the chapter is dragged by it, and with the up and down arrows it moves too, which is the only way to reorder with the keyboard. The order is applied at once and saved in a transition (`useSortableRows`); the introduction and the closing are neither moved nor sent.
- **«Eliminar»** appears next to «Editar» only where the server would allow it: a draft course and a chapter without progress.
- **A new chapter** is typed in the field on the rail and added with Enter; the «Añadir» button stays out of sight while the field is empty (`:placeholder-shown`). It is in the soft accent of the page's buttons, at the size the field allows, instead of the dark one it used to be.

## Markup & styling

None of its own: what is drawn is [`SyllabusList`](/components/platform/sections/staff/courses/syllabus-list) inside a [`StaffPanel`](/components/platform/sections/staff/courses/staff-panel).

## Usage

From `components/platform/sections/staff/courses/course-editor.section.tsx`:

```tsx
import { CourseSyllabus } from "./course-syllabus/course-syllabus.comp";

<CourseSyllabus courseId={course.id} chapters={course.chapters} isDraft={isDraft} />;
```
