# `TempPasswordNotice`

|            |                                                                                                                                                                                  |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/staff/students/temp-password-notice.comp.tsx`                                                                                                      |
| Kind       | Client Component                                                                                                                                                                 |
| Stylesheet | `temp-password-notice.comp.css` → block `.temp-password`                                                                                                                         |
| Used by    | [`CreateAccountForm`](/components/platform/sections/staff/students/create-account-form), [`ResetPasswordForm`](/components/platform/sections/staff/students/reset-password-form) |

## Purpose

The one place a generated password is ever visible. It is not stored, does not travel in the URL and is not shown again on reload: it only exists in the action's response held by `useActionState`. If it is lost, another one is generated from the record.

## Props

| Prop       | Type     | Required | Meaning                                                |
| ---------- | -------- | -------- | ------------------------------------------------------ |
| `password` | `string` | yes      | The temporary password.                                |
| `message`  | `string` | no       | The action's success message, shown above the warning. |

## Behaviour

"Copiar" writes to the clipboard and flips to "Copiada"; a permission failure leaves the label unchanged, since the password is in plain view to copy by hand. The container is `role="status"`.

## Usage

From `components/platform/sections/staff/students/create-account-form.comp.tsx`:

```tsx
import { TempPasswordNotice } from "./temp-password-notice.comp";

{
  state.status === "ok" && state.tempPassword && (
    <TempPasswordNotice password={state.tempPassword} message={state.message} />
  );
}
```
