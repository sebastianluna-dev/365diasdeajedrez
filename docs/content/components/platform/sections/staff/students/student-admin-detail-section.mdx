## Purpose

Operating an account (name, email, password, teacher assignment, class participations and payments) is not the same as reading a student's private content. This record gives **no** access to the student's studies or games; that is the teacher's view, and only for assigned students.

## Props

| Prop        | Type                    | Required | Meaning                                                                                                                                      |
| ----------- | ----------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `student`   | `StaffStudentDetail`    | yes      | `id`, `displayName`, `email`, `createdAtLabel`, `lastLoginAtLabel?`, `hasPassword`, `passwordUpdatedAtLabel?`, `assignments[]`, `classes[]`. |
| `teachers`  | `{ id, displayName }[]` | yes      | Active teachers, for the assignment panel.                                                                                                   |
| `errorCode` | `string`                | no       | `?error=` translated with `STAFF_ERROR_MESSAGES`.                                                                                            |

## Behaviour

Four cards: a `PlatformForm` posting `updateStudent.bind(null, id)` with name and email (`PlatformFormField`s since 2026-10-08: an emptied one shows «Este campo es obligatorio.» under it and nothing is sent) plus a facts list (creation, last login, password state); the [`AssignmentPanel`](/components/platform/sections/staff/assignments/assignment-panel) in `byStudent` mode; the [`ResetPasswordForm`](/components/platform/sections/staff/students/reset-password-form); and a [`PlatformTable`](/components/platform/shared/platform-table) of classes with teacher, date, status, attended («Sí», «No» or «Sin pasar lista») and the seat's coverage («Pagada», «Gratis» or «Sin pago», from `coverage`).

## Markup & styling

Block `.student-admin` (47 lines).

**Elements:** `.student-admin__form`, `.student-admin__facts`, `.student-admin__fact`, `.student-admin__fact-label`, `.student-admin__fact-value`

**Other selectors it styles:** `.platform-form__field` inside `.student-admin__form`, each field's share of the row. The form is a `PlatformForm`, whose own root is a column: `.student-admin__form` turns it into a bottom-aligned row that wraps.

**Tokens:** `--platform-border`, `--platform-text`, `--platform-text-muted`

No media queries.

## Usage

From `app/(platform)/administracion/alumnos/[userId]/page.tsx`:

```tsx
import { StudentAdminDetailSection } from "@/components/platform/sections/staff/students/student-admin-detail.section";

<StudentAdminDetailSection student={student} teachers={teachers} errorCode={error} />;
```
