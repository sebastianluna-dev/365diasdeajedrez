## Purpose

Operating an account (name, email, password, teacher assignment, class participations and payments) is not the same as reading a student's private content. This record gives **no** access to the student's studies or games; that is the teacher's view, and only for assigned students.

## Props

| Prop        | Type                    | Required | Meaning                                                                                                                                      |
| ----------- | ----------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `student`   | `StaffStudentDetail`    | yes      | `id`, `displayName`, `email`, `createdAtLabel`, `lastLoginAtLabel?`, `hasPassword`, `passwordUpdatedAtLabel?`, `assignments[]`, `classes[]`. |
| `teachers`  | `{ id, displayName }[]` | yes      | Active teachers, for the assignment panel.                                                                                                   |
| `errorCode` | `string`                | no       | `?error=` translated with `STAFF_ERROR_MESSAGES`.                                                                                            |

## Behaviour

Four cards: a `<form action={updateStudent.bind(null, id)}>` with name and email plus a facts list (creation, last login, password state); the [`AssignmentPanel`](/components/platform/sections/staff/assignments/assignment-panel) in `byStudent` mode; the [`ResetPasswordForm`](/components/platform/sections/staff/students/reset-password-form); and a [`PlatformTable`](/components/platform/shared/platform-table) of classes with teacher, date, status, attended and payment.

## Usage

From `app/(platform)/administracion/alumnos/[userId]/page.tsx`:

```tsx
import { StudentAdminDetailSection } from "@/components/platform/sections/staff/students/student-admin-detail.section";

<StudentAdminDetailSection student={student} teachers={teachers} errorCode={error} />;
```
