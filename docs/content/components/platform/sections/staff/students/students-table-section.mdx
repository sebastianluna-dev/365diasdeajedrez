## Purpose

The account list. Beyond identity it surfaces the two operational facts staff act on: whether the account can log in at all ("Sin contraseña" tag) and which teacher it is with ("Sin asignar"). The search is a GET form, so the filter lives in the URL.

## Props

| Prop    | Type     | Required | Meaning                              |
| ------- | -------- | -------- | ------------------------------------ |
| `query` | `string` | no       | Search by name or email, from `?q=`. |

## Behaviour

The search is a `PlatformForm` whose `action` is the list's own route, so it submits as a plain GET form and the query lands in `?q=`; its one field, «Buscar», is a `PlatformFormField` (2026-10-08; it was a `FormField`) named `q`, and a search box never says «Opcional». Awaits the filtered list; names link to the record; last login through a date-only [`LocalDateTime`](/components/platform/shared/local-datetime) or "Nunca". Empty label adapts to whether a query was given.

## Markup & styling

Block `.students-table` (27 lines): the bar with the search and the button.

**Elements:** `.students-table__bar`, `.students-table__search`

**Other selectors it styles:** `.platform-form__field` inside `.students-table__search`, the field's share of the row. The form is a `PlatformForm`, whose own root is a column: `.students-table__search` turns it into a bottom-aligned row that wraps.

No tokens or media queries of its own.

## Usage

From `app/(platform)/administracion/alumnos/page.tsx`:

```tsx
import { StudentsTableSection } from "@/components/platform/sections/staff/students/students-table.section";

<StudentsTableSection query={q} />;
```
