## Purpose

The same exception as [`CreateAccountForm`](/components/platform/sections/staff/students/create-account-form): the action returns the temporary password, so it uses `useActionState` and needs JavaScript. Resetting closes **all** sessions of the account, so whoever held a stolen session is out.

## Props

| Prop     | Type     | Required | Meaning                 |
| -------- | -------- | -------- | ----------------------- |
| `userId` | `string` | yes      | Sent as a hidden field. |

## Behaviour

One optional field, "Contraseña nueva": empty means a temporary one is generated and shown once. The submit is disabled while pending; results render as in the create form. The form is a `PlatformForm` with the field as a `PlatformFormField` (2026-10-08; it was a `FormField`), and the field says «Opcional» by itself.

## Markup & styling

Block `.reset-password` (19 lines).

**Elements:** `.reset-password__form`

**Other selectors it styles:** `.platform-form__field`, the field's share of the row. The form is a `PlatformForm`, whose own root is a column: `.reset-password__form` turns it into a bottom-aligned row that wraps.

**Other classes it renders:** `.platform-button`.

No tokens or media queries of its own.

## Usage

From `components/platform/sections/staff/students/student-admin-detail.section.tsx`:

```tsx
import { ResetPasswordForm } from "./reset-password-form.comp";

<ResetPasswordForm userId={student.id} />;
```
