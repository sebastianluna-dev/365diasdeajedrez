## Purpose

What the administration sees first. The one list that asks for action is "Alumnos sin profesor asignado": every account without an active assignment, linked to its record where the assignment is made. The rest is orientation: counts, courses by status with a link to the catalog, and the week's classes. The closing note states the rule that technical catalogs (topics, levels, course types, statuses) are managed by seed, because their codes are what the logic compares.

## Props

This component takes no props. The page opens with `requireStaff()`.

## Behaviour

Awaits the dashboard and renders. Unassigned students empty renders an [`EmptyState`](/components/platform/shared/empty-state) ("Todos los alumnos tienen profesor"); upcoming classes empty renders an inline line.
