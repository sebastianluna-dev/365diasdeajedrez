## Purpose

Course authors are editorial content, not a restricted domain whose code the logic compares, so they are the only catalog edited from the interface; topics, levels, statuses and the rest stay seed. Each author is its own inline form, so saving one never touches another.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `authors` | `AuthorAdminRow[]` | yes | `{ id, name, slug, photo?, bio?, courseCount }[]`. |
| `errorCode` | `string` | no | `?error=` translated with `STAFF_ERROR_MESSAGES`. |

## Behaviour

Fields on both forms: name (required), slug (required, `pattern="[a-z0-9]+(-[a-z0-9]+)*"`, so the browser rejects bad slugs before the server does), photo URL, bio. The row title shows how many courses credit the author.

## Usage

From `app/(platform)/administracion/autores/page.tsx`:

```tsx

<AuthorsAdminSection authors={authors} errorCode={error} />
```
