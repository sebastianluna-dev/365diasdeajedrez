## Purpose

Everything a student gets from one class: how to join it while it is upcoming, the recording afterwards, the teacher's summary, the content blocks exactly as the teacher composed them, and the transcript when there is one. The section receives the class from the page; the service already decided what the student may see (the meeting URL is included only once authorised).

## Behaviour

- `isUpcoming` is `SCHEDULED` or `LIVE`; only then is [`MeetingAccess`](/components/platform/sections/classes/class-detail/meeting-access) rendered.
- The recording is an external link button when `recordingUrl` exists.
- Blocks go to [`ClassContentRenderer`](/components/platform/shared/class-content-renderer); an empty list shows an empty state whose copy depends on whether the class is still to come.
- The transcript card shows the text when `statusCode === TRANSCRIPT_STATUS.READY`, otherwise "Estado de la transcripción: …".
- The breadcrumb is local (Mis clases / title), not a shared component, because the classes area has only one level.
