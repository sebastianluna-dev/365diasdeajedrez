## Purpose

The page the student gets from the moment a class is scheduled until half an hour after it ends: the way back («Mis clases»), the phase (the student reads «Finalizada» where the teacher reads «Por finalizar»), the topic in the display face, when and with whom, and the access card — «Entrar a la clase» from the instant the link opens, the countdown before it (the link never travels ahead of time: the server hands it over and the countdown asks for the page again), «Volver a entrar» in the half hour after the end, «Escríbenos» when there is no link yet. Under it, «Tu clase» (`TicketIcon`) with the people line and «Esta clase es gratis.» when it is — never which payment the class belongs to (the owner's rule of 2026-10-15) — and «Para preparar» (`#para-preparar`, where a ticket's «N para preparar» lands) with the blocks the student may see now.

What the staff did reaches the student as a notice: a new date («Reprogramada desde el mar 13 oct.» and the note), a cancellation («Esta clase se canceló. Te escribiremos para fijar otra fecha. Tu clase pagada sigue en pie: la programaremos contigo.» — the last sentence only for a paid seat), a make-up («Es la reposición de tu clase del vie 2 oct. Nota: …»). A cancelled class has no access card and nothing to prepare.

An «Ejercicio» block «Para preparar» (phase 3 of [Exercises](/platform/exercises#classes-phase-3)) appears under «Para preparar» as rows with the student's mark in it and «Resolver», which opens `/clases/[classId]/ejercicios/[blockId]/[n]`.
