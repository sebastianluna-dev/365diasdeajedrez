## Purpose

The student's classes in three groups. «Hoy»: today's classes as featured cards, with how to join. «Próximas»: the next ones as rows (the first featured when there is nothing today), and after them one row per class bought without a date («Clase por programar · de tu pago del 1 de octubre»). «Pasadas»: by month, newest first; a month that is one payment, spent, with every class attended, folds into a line («Las cuatro clases de tu pago del 3 de septiembre.») that unfolds its rows. Ten past classes a page: «Ver más» asks the page for one more (`?pasadas=<n>`). Without a class of any kind, one empty state: «Cuando administración programe una clase contigo, aparecerá aquí con su fecha y su enlace.» The balance is not here: the page draws [`PaidClassesCard`](/components/platform/shared/paid-classes-card) beside this.

## Props

| Prop        | Type                 | Required | Meaning                                                |
| ----------- | -------------------- | -------- | ------------------------------------------------------ |
| `view`      | `StudentClassesView` | yes      | What `getUserClasses(pastPages)` gives.                |
| `pastPages` | `number`             | yes      | How many pages are shown; «Ver más» asks for one more. |

**Other classes it renders:** `.platform-button`.

**Tokens:** `--platform-text`, `--platform-text-muted`, `--platform-surface-soft`

No media queries; the page's grid places it.

## Usage

From `app/(platform)/clases/page.tsx`:

```tsx
const view = await getUserClasses(pastPages);

<ClassesListSection view={view} pastPages={pastPages} />;
```
