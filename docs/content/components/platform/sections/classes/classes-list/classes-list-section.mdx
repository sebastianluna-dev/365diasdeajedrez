## Purpose

The student's classes in two groups, "Próximas clases" and "Clases pasadas". The service does the split (by scheduled time against now) and the section only lays it out; the dashboard's [`NextClassSection`](/components/platform/sections/dashboard/next-class/next-class-section) reads the same service and takes the first upcoming one.

## Props

This component takes no props.

## Behaviour

Awaits `{ upcoming, past }`. Each group renders its cards or an empty state with copy specific to it ("No tienes clases programadas" with a hint about the teacher scheduling; "Todavía no has tomado clases").
