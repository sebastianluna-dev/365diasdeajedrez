## Purpose

The body of "Mis estudios": a row of filter chips, a count, and the studies in two titled groups. It is a Client Component only for the active chip; everything it renders arrived from the server. The filter options are not a fixed list but the set of `kindLabel`s present in both groups, so a new kind gets its chip without touching this file.

## Props

| Prop       | Type             | Required | Meaning                                                                                                                            |
| ---------- | ---------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `own`      | `StudySummary[]` | yes      | Those that are theirs: "Mis partidas", their tournaments and their studies.                                                        |
| `received` | `StudySummary[]` | yes      | What reaches them ready-made and cannot be touched: course databases, collections a teacher handed them, games from their classes. |

## Behaviour

- `active` starts at "Todos". Chips are buttons with `aria-pressed`.
- Each group renders only when it has matches; when neither does, an [`EmptyState`](/components/platform/shared/empty-state) names the filter ("Ningún estudio de tipo «…»").
- Nothing is fetched or written here.

## Usage

From `components/platform/sections/studies/studies-list/studies-list.section.tsx`:

```tsx
import { StudiesBrowser } from "./studies-browser.comp";

<StudiesBrowser
  own={studies.filter((study) => study.permissions.canEditGames)}
  received={studies.filter((study) => !study.permissions.canEditGames)}
/>;
```
