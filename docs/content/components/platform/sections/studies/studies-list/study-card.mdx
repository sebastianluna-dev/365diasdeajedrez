# `StudyCard`

|            |                                                                                        |
| ---------- | -------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/studies/studies-list/study-card.comp.tsx`                |
| Kind       | Server Component                                                                       |
| Stylesheet | `study-card.comp.css` → block `.study-card`                                            |
| Used by    | [`StudiesBrowser`](/components/platform/sections/studies/studies-list/studies-browser) |
| Composes   | [`DeleteStudy`](/components/platform/sections/studies/studies-list/delete-study)       |
| Uses       | `StudySummary` from `services/studies/studies.types`                                   |

## Purpose

A study as a card. The tag row states the kind and, for what is not the student's, **where it comes from**: the course that brings it or the teacher who handed it out. Without that, two read-only collections would be indistinguishable in the list. The name links to the study page.

## Props

| Prop    | Type           | Required | Meaning                                                                                                                                                                            |
| ------- | -------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `study` | `StudySummary` | yes      | `id`, `name`, `href`, `description?`, `kindLabel`, `courseName?`, `sharedByName?`, `gameCount`, `citedGameCount`, `updatedAtLabel`, `permissions: { canEditGames, canDelete, … }`. |

## Behaviour

- `permissions.canDelete` renders the [`DeleteStudy`](/components/platform/sections/studies/studies-list/delete-study) cross with the counts it needs for its warning; otherwise, a read-only study shows the "Sólo lectura" mark. An editable study that cannot be deleted ("Mis partidas") shows neither.
- Game count and "Actualizado el …" come formatted from the mapper.

## Usage

From `components/platform/sections/studies/studies-list/studies-browser.comp.tsx`:

```tsx
import { StudyCard } from "./study-card.comp";

{
  ownShown.map((study) => <StudyCard key={study.id} study={study} />);
}
```
