# `DeleteStudy`

| File | `components/platform/sections/studies/studies-list/delete-study.comp.tsx` |

## Purpose

Deleting a study deletes its games, and with them variations, comments and arrows; a study whose games are cited in classes leaves those blocks empty. The dialog says exactly what will be lost and, when there is something to lose, requires a checkbox before the button enables. The same dialog is opened from two places with a different trigger.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `id` | `string` | yes | Study to delete; bound into the action. |
| `name` | `string` | yes | For the title ("¿Borrar «…»?") and the trigger's tooltip. |
| `gameCount` | `number` | yes | Drives the description. |
| `citedGameCount` | `number` | yes | Games cited in class blocks; drives the warning text. |
| `trigger` | `"icon" \| "button"` | no · default `"icon"` | `icon` is the card's cross; `button` the text button of the study page. The trigger changes, not the dialog. |

## Behaviour

- `needsConfirmation = gameCount > 0 || citedGameCount > 0`, **the same condition as the server**. If the client let the form submit without the checkbox where the server requires it, the action would bounce to `?error=confirmStudyDelete` instead of deleting.
- The checkbox **is** the field the server reads (`name="confirmDelete" value="yes"`): unticked it is not sent, so the flag only arrives when it should. `confirmed` is local state so the submit button can be disabled until it is ticked.
- The form is `<form action={deleteStudy.bind(null, id)}>` inside a native `<dialog>`; `onClose` resets the checkbox so reopening starts clean.
- Copy adapts to counts: singular/plural for games and for cited games.

## Usage

From `components/platform/sections/studies/study-detail/study-detail.section.tsx`:

```tsx
import { DeleteStudy } from "@/components/platform/sections/studies/studies-list/delete-study.comp";

<DeleteStudy
  id={study.id}
  name={study.name}
  gameCount={study.games.length}
  citedGameCount={study.citedGameCount}
  trigger="button"
/>
```
