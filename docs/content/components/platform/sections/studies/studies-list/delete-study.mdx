## Purpose

Deleting a study deletes its games, and with them variations, comments and arrows; a study whose games are cited in classes leaves those blocks empty. The confirmation says exactly what will be lost and, when there is something to lose, requires a box before the button enables. Since 2026-10-06 this piece is only the words and the triggers: the popup, the disc, the box, the note and the buttons are [`PlatformConfirmPopup`](/components/platform/shared/platform-confirm-popup)'s. The same confirmation is opened from three places with a different trigger.

## Props

| Prop             | Type                           | Required              | Meaning                                                                                                                                                                                                                                                                           |
| ---------------- | ------------------------------ | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`             | `string`                       | yes                   | Study to delete; bound into the action.                                                                                                                                                                                                                                           |
| `name`           | `string`                       | yes                   | The confirmation's `subject` («¿Eliminar «…»?») and the trigger's tooltip.                                                                                                                                                                                                        |
| `gameCount`      | `number`                       | yes                   | Drives the description.                                                                                                                                                                                                                                                           |
| `citedGameCount` | `number`                       | yes                   | Games cited in class blocks; drives the box's label.                                                                                                                                                                                                                              |
| `trigger`        | `"icon" \| "button" \| "none"` | no · default `"icon"` | `icon` is the card's cross; `button` the boxed text button of the empty study page; `none` draws no trigger, and the host opens the confirmation through `ref`. The trigger changes, not the confirmation.                                                                        |
| `ref`            | `Ref<DeleteStudyHandle>`       | no                    | `{ open() }`: how a host that draws its own trigger — «Eliminar estudio» in the study's form — opens the confirmation.                                                                                                                                                            |
| `onDone`         | `() => void`                   | no                    | Called once the study is deleted, after the confirmation closed: where a host that opened it over a popup closes that popup (`StudySettings` closes the study's form). Never on cancel. Alone, from a card or the study page, it is omitted: the action's redirect does the rest. |

## Behaviour

- `needsConfirmation = gameCount > 0 || citedGameCount > 0`, **the same condition as the server**: only then is the `acknowledgement` passed, and `PlatformConfirmPopup` keeps the button off until its box is ticked. If the client let the form submit without the box where the server requires it, the action would bounce to `?error=confirmStudyDelete` instead of deleting.
- The box **is** the field the server reads (`name="confirmDelete" value="yes"`, which the piece sends only while it is checked), so the flag only arrives when it should; the piece resets the tick on every close.
- The action is `deleteStudy.bind(null, id)`, the piece's `action`: it redirects to the studies list, which takes the popup away; opened over the study's form, the piece's `onDone` is this `onDone`, and the host closes the form with it.
- Copy adapts to counts: singular/plural for games and for cited games.

## Markup & styling

Block `.delete-study` (15 lines): the triggers alone.

**Elements:** `.delete-study__open` (the card's cross: Material's standard icon button, `mdIconButton("standard", "xs")`, with `XmarkIcon` in Classic Solid, since the library moved to the new design system on 2026-10-23; the platform's quiet small square from 2026-10-07), `.delete-study__open-label` (visually hidden text of the cross), `.delete-study__open-wide` (the boxed text button)

**Other classes it renders:** `PlatformConfirmPopup`'s.

**Tokens:** `--platform-border`, `--platform-danger`, `--platform-surface`, `--platform-text-muted`, `--platform-text-subtle`

No media queries.

## Usage

From `components/platform/sections/studies/study-detail/study-detail.section.tsx`:

```tsx
import { DeleteStudy } from "@/components/platform/sections/studies/studies-list/delete-study.comp";

<DeleteStudy
  id={study.id}
  name={study.name}
  gameCount={study.games.length}
  citedGameCount={study.citedGameCount}
  trigger="button"
/>;
```

Over the study's form, from `components/platform/sections/studies/game-view/study-settings.comp.tsx`:

```tsx
<DeleteStudy ref={deleteRef} trigger="none" … onDone={() => editRef.current?.close()} />
```
