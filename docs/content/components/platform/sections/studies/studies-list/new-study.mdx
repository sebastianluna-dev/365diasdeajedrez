## Purpose

Creating a study is three fields, so it lives in a modal on the list page rather than on a page of its own. The modal is a [`PlatformPopup`](/components/platform/shared/platform-popup), the one popup of the platform: the strip with the name and the cross, the focus trap, Escape and the backdrop come with it. `NewStudy` is the button and the popup; `NewStudyForm` is the form, split off so the story can mount it with a stub in place of the server action.

## Props

| Prop    | Type                | Required | Meaning                                                                                                                                                                 |
| ------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kinds` | `StudyKindOption[]` | yes      | Kinds the viewer can create. "Mis partidas" is never there (it is born with the account) and "Colección" only for a teacher. Decided by `services/studies/study-rules`. |

## Behaviour

- **The slot is the only way in** (2026-10-07, when «Mis estudios» became a library, the «Biblioteca» design the owner chose): a dashed cell that heads the grid of their own studies ([`StudiesBrowser`](/components/platform/sections/studies/studies-list/studies-browser)), as tall as the covers beside it, the «+» over «Nuevo estudio», in grey, lit with the accent's wash and border under the pointer; 56px tall on a phone. For a few hours the page's head also had a button to the same popup — the platform's primary one; before that a quiet white pill by the title —, which the owner took out: the grid keeps a card's place for it.
- The form is a `PlatformForm` with `action={createStudy}` and `autoComplete="off"`: the subtitle «Agrupa partidas y análisis bajo un mismo tema.» as its first line, `name` (required, max 120, controlled so the submit can watch it, with its own `valueMissing` text; the first control, so the popup opens on it), `description` (a textarea, max 500, which says «Opcional» by itself: `PlatformFormField` reads that it has no `required`) and `kindCode`, a `PlatformChoiceCards` inside a `PlatformFormGroup` over `kinds` with the first one chosen. Each card's description and piece come from `constants/platform/study-kind-cards.const.ts`; a kind missing there renders with its label alone. A footer band carries "Podrás cambiarlo todo después." and the buttons.
- **Crear estudio** stays disabled until the name has a character that is not a space. It was the first form moved to the Radix pieces.
- The popup is `PlatformPopup` at `md` (600px), named «Nuevo estudio» by its strip; the slot opens it with `open(event)`, so the focus returns to it on closing. Its motion and its frame are the popup's: this stylesheet draws nothing of the shell.
- Every closing remounts the form (`key` bumped in the popup's `onClose`), so it never opens with what was typed the last time. On closing and not on opening: `open()` focuses the form it finds, and one remounted in the same click would take that focus with it.
- «Cancelar» and `onSubmit` close the popup. The browser validates `required` before the submit event fires (the form primitive only replaces the bubble with the field's message), so the popup does not close with the form half filled.
- The action creates the study and revalidates the list, which comes back with the new study; it does not redirect. A form it cannot read, or the rate limit, bounces to the list with `?error=`.

## Markup & styling

Block `.new-study` (110 lines): the slot, the body's padding and spacing (24px, to the strip's edge), the subtitle, the pieces on the cards and the footer band. The shell (frame, strip, cross, width) is `PlatformPopup`'s; the fields' and controls' look come from `.platform-form` and `.platform-choice-cards`.

**Elements:** `.new-study__slot`, `.new-study__slot-icon`, `.new-study__form`, `.new-study__body`, `.new-study__subtitle`, `.new-study__piece`, `.new-study__foot`, `.new-study__note`, `.new-study__actions`

**Modifiers:** `.new-study__piece_name_rook`, `_king`, `_pawn` (the SVG from `public/pieces` each card draws).

**Other classes it renders:** `.platform-popup` (with `.platform-dialog`, the shared frame in `platform.css`), `.platform-button` and `.platform-button_variant_ink` (inside the popup), `.platform-form`, `.platform-choice-cards`.

**Tokens:** `--platform-bg`, `--platform-border`, `--platform-surface`, `--platform-surface-sunken`, `--platform-text`, `--platform-text-muted`

**Breakpoints:** none of its own. The popup handles narrow screens and reduced motion.

## Usage

From `app/(platform)/estudios/page.tsx`:

```tsx
import { NewStudy } from "@/components/platform/sections/studies/studies-list/new-study/new-study.comp";

<NewStudy kinds={kinds} />;
```
