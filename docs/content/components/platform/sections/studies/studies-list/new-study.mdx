## Purpose

Creating a study is three fields, so it lives in a modal on the list page rather than on a page of its own. The modal is a **native `<dialog>`**: it brings focus trapping, closing with Escape and the backdrop without writing any of that by hand. `NewStudy` is the button and the dialog; `NewStudyForm` is the form, split off so the story can mount it with a stub in place of the server action.

## Props

| Prop    | Type                | Required | Meaning                                                                                                                                                                 |
| ------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kinds` | `StudyKindOption[]` | yes      | Kinds the viewer can create. "Mis partidas" is never there (it is born with the account) and "Colección" only for a teacher. Decided by `services/studies/study-rules`. |

## Behaviour

- The form is a `PlatformForm` with `action={createStudy}` and `autoComplete="off"`: a head (dark tile with the white knight, title, subtitle, close button), `name` (required, max 120, autofocus, controlled so the submit can watch it, with its own `valueMissing` text), `description` (a textarea, max 500, marked "Opcional") and `kindCode`, a `PlatformChoiceCards` inside a `PlatformFormGroup` over `kinds` with the first one chosen. Each card's description and piece come from `constants/platform/study-kind-cards.const.ts`; a kind missing there renders with its label alone. A footer band carries "Podrás cambiarlo todo después." and the buttons.
- **Crear estudio** stays disabled until the name has a character that is not a space. It was the first form moved to the Radix pieces.
- Every opening remounts the form (`key` bumped in `NewStudy`), so it never opens with what was typed the last time.
- `onSubmit` closes the dialog. The browser validates `required` before the submit event fires (the form primitive only replaces the bubble with the field's message), so the dialog does not close with the form half filled.
- The action creates the study and redirects to it; the dialog is unmounted with the page.

## Markup & styling

Block `.new-study`: the dialog's width and rounding, the head, the body's spacing, the pieces on the cards and the footer band. The fields' and controls' look come from `.platform-form` and `.platform-choice-cards`.

**Elements:** `.new-study__open`, `.new-study__dialog`, `.new-study__form`, `.new-study__head`, `.new-study__tile`, `.new-study__heading`, `.new-study__title`, `.new-study__subtitle`, `.new-study__close`, `.new-study__close-icon`, `.new-study__body`, `.new-study__piece`, `.new-study__foot`, `.new-study__note`, `.new-study__actions`

**Modifiers:** `.new-study__piece_name_rook`, `_king`, `_pawn` (the SVG from `public/pieces` each card draws).

**Other classes it renders:** `.platform-dialog` (the shared dialog frame in `platform.css`), `.platform-button`, `.platform-button_variant_secondary`, `.platform-form`, `.platform-choice-cards`.

**Tokens:** `--platform-bg`, `--platform-border`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted`, `--platform-text-subtle`

No media queries; the shared dialog frame handles narrow screens.

## Usage

From `app/(platform)/estudios/page.tsx`:

```tsx
import { NewStudy } from "@/components/platform/sections/studies/studies-list/new-study/new-study.comp";

<NewStudy kinds={kinds} />;
```
