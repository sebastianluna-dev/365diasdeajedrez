## Purpose

Creating a study is three fields, so it lives in a modal on the list page rather than on a page of its own. The modal is a **native `<dialog>`**: it brings focus trapping, closing with Escape and the backdrop without writing any of that by hand. The only client code is the `showModal()`/`close()` calls.

## Props

| Prop    | Type                | Required | Meaning                                                                                                                                                                 |
| ------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kinds` | `StudyKindOption[]` | yes      | Kinds the viewer can create. "Mis partidas" is never there (it is born with the account) and "Colección" only for a teacher. Decided by `services/studies/study-rules`. |

## Behaviour

- The form is a `PlatformForm` with `action={createStudy}` and three `PlatformFormField`s: `name` (required, max 120, autofocus, with its own `valueMissing` text), `description` (max 500) and `kindCode`, a `PlatformSelect` over `kinds` with the first one chosen. It was the first form moved to the Radix pieces.
- `onSubmit` closes the dialog. The browser validates `required` before the submit event fires (the form primitive only replaces the bubble with the field's message), so the dialog does not close with the form half filled.
- The select's list renders inside the dialog, not portalled, which is what keeps it usable under the dialog's top layer.
- The action creates the study and redirects to it; the dialog is unmounted with the page.

## Markup & styling

Block `.new-study` (28 lines): only the dialog's width, the form's padding, the title and the actions row. The fields and the controls' look come from `.platform-form` and `.platform-select`.

**Elements:** `.new-study__open`, `.new-study__dialog`, `.new-study__form`, `.new-study__title`, `.new-study__actions`

**Other classes it renders:** `.platform-dialog` (the shared dialog frame in `platform.css`), `.platform-button`, `.platform-button_variant_secondary`, `.platform-form`, `.platform-select`.

**Tokens:** none of its own.

No media queries; the shared dialog frame handles narrow screens.

## Usage

From `app/(platform)/estudios/page.tsx`:

```tsx
import { NewStudy } from "@/components/platform/sections/studies/studies-list/new-study.comp";

<NewStudy kinds={kinds} />;
```
