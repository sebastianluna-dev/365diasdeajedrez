## Purpose

"Partidas de mis clases" is not a study of the student's: the rows are pointers to games that live in someone else's database (a teacher's study, a course collection). So each row leads to the **class** where the game was seen, where the student already has access and the context is kept, and not to the studies viewer. Copying one of them into an own study is done from [`NewGame`](/components/platform/sections/studies/study-detail/new-game)'s class tab.

## Props

This component takes no props. It is the page's first await; the service resolves the identity in the DAL.

## Behaviour

Renders its own breadcrumb (Mis estudios / Partidas de mis clases), a header with "Colección" and "Sólo lectura" tags, and a plain `<table>` with white, black, result, ECO, class (linked) and class date. No games renders an empty state.
