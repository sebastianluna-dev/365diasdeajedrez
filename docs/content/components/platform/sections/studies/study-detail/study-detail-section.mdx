## Purpose

A study is read on its game page: `/estudios/[studyId]` redirects to the game it was left on, or its first. This section only ever renders when there is no game to go to. Since 2026-10-23 it is the game pages' workspace with nothing on the board: the same side column ([`StudyAside`](/components/platform/sections/studies/game-view/study-aside): the study's name and kind, the sliders that open its form — where it is edited and, but «Mis partidas», deleted —, «Nueva partida» as the FAB, and for a collection's owner who it is shared with), the bar's search, and in the panel the trail («Estudios › the study») and the empty state. Until then it was a page of its own with a head, its tags and a row of buttons («Eliminar estudio», «Editar», «Nueva partida»): each of those is now in the column, once.

## Props

| Prop         | Type                | Required | Meaning                                                                                                                |
| ------------ | ------------------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `study`      | `StudyDetail`       | yes      | The study, with `games` empty, `gameCount`, `shares`, `permissions`, `kindCode`, `citedGameCount` and labels.          |
| `kinds`      | `StudyKindOption[]` | yes      | Kinds the student can set when editing. Empty in course databases.                                                     |
| `results`    | `StudyKindOption[]` | yes      | The results catalog, for the blank-game form.                                                                          |
| `classGames` | `ClassGameItem[]`   | yes      | Games seen in class that can be copied. Empty hides that tab of `NewGame`.                                             |
| `students`   | `StudentOption[]`   | yes      | Students to hand a collection to, for a teacher's own collection.                                                      |
| `errorCode`  | `string`            | no       | `?error=` from a bounced action; translated by `STUDY_ERROR_MESSAGES` (`confirmStudyDelete`, `fen`, the common codes). |

## Behaviour

- What is offered is the column's, which asks `services/studies/study-rules`, the same table the server actions apply.
- The empty state has different copy for writable («Agrega una con «Nueva partida».») and read-only studies.
- Errors render through [`PlatformNotice`](/components/platform/shared/platform-notice) with a fallback message for unknown codes.

## Markup & styling

Block `.study-detail` (5 lines), on `.platform-workspace__panel`: its gap.

**Tokens:** the space scale.

## Usage

From `app/(platform)/estudios/[studyId]/page.tsx`, after the redirect to a game has not happened:

```tsx
<div className="platform-page platform-page_width_full platform-page_frame_bleed">
  <StudyDetailSection
    study={study}
    kinds={kinds}
    results={results}
    classGames={classGames}
    students={students}
    errorCode={error}
  />
</div>
```
