## Purpose

Adding a game to a study, from wherever the student has it. Four tabs, each a form against its own action:

| Tab             | What it does                                                                                                                                                                                                                                                                       |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pegar PGN       | `importPgnGames`: headers, variations, comments and NAGs are read; a multi-game PGN creates all of them, up to `PGN_MAX_GAMES` (500) per import, which the hint under the field says. Entries without moves are skipped, and the page the action returns to says how many went in. |
| Desde un FEN    | `createStudyGame` with `initialFen`: the "I have this diagram and want to analyse it" case. The game is born without moves, in that position, with the notation numbered from what the FEN says.                                                                                   |
| Crear vacía     | `createStudyGame` with the game's data (names, Elos, result, date); everything optional, which «Todos los campos son opcionales.» says once over the fields (`OptionalFields`).                                                                                                    |
| Desde una clase | `copyClassGamesToStudy` with the ticked games; the tab exists only when `classGames` is not empty. Copies, so editing them here does not touch the class.                                                                                                                          |

## Props

| Prop         | Type                | Required | Meaning                                              |
| ------------ | ------------------- | -------- | ---------------------------------------------------- |
| `studyId`    | `string`            | yes      | Bound into every action.                             |
| `studyName`  | `string`            | yes      | For the subtitle "Se agregará a «…»".                |
| `results`    | `StudyKindOption[]` | yes      | The results catalog; its label is the PGN token.     |
| `classGames` | `ClassGameItem[]`   | yes      | Games seen in attended classes. Empty hides the tab. |

## Behaviour

- **The three tabs that write are `PlatformForm`s** (2026-10-05; they were hand-made `<label>`s): a field the browser rejects shows its own message — «Pega el PGN de la partida.», «Pega el FEN de la posición.» — and the popup stays open, and an optional field says «Opcional» by itself. The PGN's textarea got a label, «PGN», which it lacked. The PGN and the FEN carry their explanation as the field's `hint`. The blank tab's fields sit in `OptionalFields`, which replaced the hint «Puedes dejarlo casi vacío y jugar las jugadas después en el editor.». The result and the date are a `PlatformSelect` and a `PlatformDatePicker` inside `PlatformFormField`s, which give them their `name`.
- **On the shell** (2026-10-06): a [`PlatformPopup`](/components/platform/shared/platform-popup) named «Nueva partida» (size `md`, 600px), which gave it the cross it lacked; «Se agregará a «…».» is the content's first paragraph, under the strip. The trigger opens it with the click, so the focus comes back to it on closing, and the popup focuses the first tab. `tab` and the `picked` ids are local state, both reset in `onClose`, so the next opening starts on «Pegar PGN» with nothing ticked (until then only the ticks were reset, and the popup reopened on the last tab).
- A badly written FEN bounces to the study's URL with `?error=fen` (`createStudyGame` always goes back to `studyDetail`), which forwards it to the first game or renders the empty study; the message shows over the board.
- The class tab is not a form: the footer button is `type="button"` and calls the action inside a transition with the picked ids, then closes.
- The internal `Footer` renders the note, cancel and the confirm button: a `SubmitButton` that says «Agregando…» while the form is on its way; with `onConfirm` it is a plain button instead, so it does not submit an enclosing form.
- Tabs use `role="tablist"`/`role="tab"` with `aria-selected`. Each on one line, with a `space-3` side padding: wider, «Pegar PGN» and its neighbours broke over two lines in the 600px popup; on a phone the row scrolls sideways.
- **Its own buttons keep their look beside the board.** The popup lives inside the aside's «Nueva partida» slot, whose rule drew the trigger as a line with a «+»; it reached `.platform-button`, so «Cancelar» and «Agregar partida» took it too, until 2026-10-05 (the rule now names `.new-game__open`). The footer's buttons do not wrap: the note gives way.

## Markup & styling

Block `.new-game` (166 lines): the trigger and the popup's content, which pads itself under the strip; the strip, the width and the frame are `PlatformPopup`'s.

**Elements:** `.new-game__open`, `.new-game__subtitle` (the content's first line), `.new-game__tabs`, `.new-game__tab`, `.new-game__panel`, `.new-game__textarea`, `.new-game__hint` (the class tab's), `.new-game__grid`, `.new-game__list`, `.new-game__pick` (the class on each `PlatformCheckbox` row: border and padding, the border darkening under the pointer), `.new-game__actions`, `.new-game__note`

**Modifiers and states:** `.new-game__tab_state_active`

**Other selectors it styles:** `.platform-button` inside the popup; `.platform-form__field:first-child` of the blank tab's grid, which spans both columns (the name); the PGN's textarea through the panel, to beat `PlatformForm`'s own rule for a field's textarea.

**Tokens:** `--platform-accent`, `--platform-bg`, `--platform-border`, `--platform-border-strong`, `--platform-surface`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`, `--platform-text-subtle`, `--platform-track`

**Breakpoints:** `(width < 640px)` collapses the two-column grid.

## Usage

From `components/platform/sections/studies/study-detail/study-detail.section.tsx`:

```tsx
import { NewGame } from "./new-game.comp";

<NewGame studyId={study.id} studyName={study.name} results={results} classGames={classGames} />;
```
