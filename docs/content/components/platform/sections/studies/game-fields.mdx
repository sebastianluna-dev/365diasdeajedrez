# `GameFields`

Also exports the `GameFieldValues` type.

|            |                                                                                                                                               |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/studies/game-fields.comp.tsx`                                                                                   |
| Kind       | Server Component                                                                                                                              |
| Stylesheet | `game-fields.comp.css` → block `.game-fields`                                                                                                 |
| Used by    | [`EditGame`](/components/platform/sections/studies/game-view/edit-game)                                                                       |
| Composes   | [`FormField`](/components/platform/shared/form-field)                                                                                         |
| Uses       | `federationOptions`, `FIDE_TITLES`, `FIDE_TITLE_LABELS` from `lib/chess/federations`; `StudyKindOption` from `services/studies/studies.types` |

## Purpose

The fields of a game (name, players with Elo, title and federation, result, date, event, site, round, ECO) defined once. Both forms, create and edit, have to offer exactly the same set: if something could be filled in on creation that cannot be corrected later, the data would be trapped. All fields are optional, also on creation, because when analysis starts one does not yet know which game it is going to be.

It lives at the root of `studies/` rather than in a subfolder because two different subfolders use it.

## Props

| Prop        | Type                | Required | Meaning                                                                                                                                |
| ----------- | ------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `values`    | `GameFieldValues`   | no       | Current values for the edit form; absent on creation. `playedAtValue` is short ISO (`yyyy-mm-dd`), what `<input type="date">` expects. |
| `results`   | `StudyKindOption[]` | yes      | The results catalog; `ONGOING` is the default.                                                                                         |
| `titleHint` | `string`            | yes      | Help text for the name, different on creation and on edit.                                                                             |

## Behaviour

- Plain inputs with `defaultValue`; no state.
- `CodeSelect` handles the title and federation dropdowns, each a [`PlatformSelect`](/components/platform/shared/platform-select) with the `emptyOption` ("Sin título", "Sin federación"): a PGN may bring a title or a federation that is not in our lists (headers are written by whoever wants), so a stored value outside the options is added as one more option, "X (del PGN)", and saving without touching it keeps it. The result is a `PlatformSelect` over `results`.
- Elo inputs are `type="number"` between 100 and 4000.

## Markup & styling

Block `.game-fields` (16 lines): the two-column rows.

**Elements:** `.game-fields__row`

**Other selectors it styles:** `.platform-field` (spacing inside the rows).

No tokens, no media queries of its own.

## Usage

From `components/platform/sections/studies/study-detail/new-game.comp.tsx` (the blank tab of the dialog):

```tsx
import { GameFields } from "@/components/platform/sections/studies/game-fields.comp";

<GameFields results={results} />;
```
