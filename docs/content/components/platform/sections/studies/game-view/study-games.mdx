## Purpose

[`StudyAside`](/components/platform/sections/studies/game-view/study-aside) is mounted by a layout so that the list holds still from one game to the next, and a layout is not rendered again when the game changes: the server cannot tell the list which game is the current one. This leaf reads it from the address — `useParams().gameId`, which does change — and hands it to [`GameList`](/components/platform/shared/game-list) as `currentId`. The shared list stays as it was, told its current game by a prop; what knows about the route is here.

For the same reason the paging is here. A study's list shows a hundred games at once (`STUDY_GAMES_PAGE_SIZE`). Until 2026-10-05 the server chose the hundred — the page the current game fell on (`getStudyPageOfGame`), or `?pagina=` — and each turn of the page was a navigation. A layout knows neither the game nor the query string, so now the list carries every game (light rows: no PGN, no tags) and the pages are turned in the browser.

## Props

| Prop        | Type                                      | Required | Meaning                                                                                                                                      |
| ----------- | ----------------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `games`     | `GameListItem[]`                          | yes      | Every game of the study, in its order.                                                                                                       |
| `pageSize`  | `number`                                  | yes      | How many of them the list shows at once.                                                                                                     |
| `onReorder` | `(orderedIds: string[]) => Promise<void>` | no       | Saves a new order; `StudyAside` only passes it for a study that fits on one page.                                                            |
| `settings`  | `GameSettingsActions`                     | no       | What a game's settings do. The rows carry no gear: the open game's card has «Configurar»; without them, for whoever only reads, it does not. |

## Behaviour

- **The page shown** is the one the current game falls on (`pageOfGame`; the first for a game that is not in the list). «← Anteriores» and «Siguientes →» turn it without navigating; the page turned to is remembered together with the game one was on when turning, so on another game the list goes back to that game's page — derived during render, with no effect to reset it. A page beyond the last (a game was deleted) answers the last.
- The nav «← Anteriores · Página n de m · Siguientes →» only exists with more than one page; its two controls are buttons — Material's text buttons (`mdButton("text", "xs")`) since 2026-10-23 —, disabled at the ends, since they go nowhere.
- The list is [`GameList`](/components/platform/shared/game-list) in its material look (`look="material"`), the study's side column being on the new design system's canvas.
- `GameList` is keyed by the page: each page is a list of its own, whose scroll starts at the top.
- **The open game, under the list** (2026-10-23, the owner's choice «B»): «Partida abierta», its name and its result, on the panel's white, and for whoever may write «Configurar», which opens its settings ([`GameSettings`](/components/platform/shared/game-settings) with `trigger="button"`). A game is configured only once it is open, so the rows stay one line each. Read from the address like the current row, so it follows the board from game to game.

## Markup & styling

Block `.study-games` (47 lines): the wrapper, the pages nav and the open game's card. The list is `GameList`'s own block.

**Elements:** `.study-games__pages`, `.study-games__page-status`, `.study-games__open`, `.study-games__open-text`, `.study-games__open-label`, `.study-games__open-name`

**Other classes it renders:** `btn btn-text btn-xs` (`mdButton`).

**Tokens:** `--platform-m3-on-surface-variant`, `--platform-m3-on-surface`, `--platform-m3-panel`, `--md-sys-shape-corner-lg`, the type and space scales.

No media queries.

## Usage

From `components/platform/sections/studies/game-view/study-aside.comp.tsx`:

```tsx
import { StudyGames } from "./study-games.comp";

<StudyGames
  games={study.games.map(listItem)}
  pageSize={STUDY_GAMES_PAGE_SIZE}
  onReorder={canReorder ? reorderStudyGames.bind(null, study.id) : undefined}
  settings={canWrite ? { save, clearAnnotations, clearVariations, remove } : undefined}
/>;
```
