## Signature

```ts
function useGameAutosave(options: {
  studyId: string;
  gameId: string;
  pgn: string;
  enabled: boolean;
  save?: (studyId: string, gameId: string, pgn: string) => Promise<AutosaveResult>;
}): { saveLabel: string | undefined };
```

## Behaviour

- With `enabled`, `AUTOSAVE_DELAY_MS` (1.2 s) after the last change the latest PGN goes to `save`; a change during the wait restarts the timer, so intermediate versions are never sent. `lastSaved` is what the server confirmed; "unsaved" is derived by comparing it with the current PGN, not one more state to maintain.
- A `beforeunload` handler warns when the PGN differs from `lastSaved`: no request can be awaited there, so the only honest thing is to ask.
- `saveLabelOf({ enabled, saveState, dirty })` is the pure derivation: `undefined` when disabled or when there is nothing to say, "no se pudo guardar" whenever the last write failed (the error wins even if something was written again), "guardando…" while sending, "sin guardar" with a pending change, "guardado" otherwise.
