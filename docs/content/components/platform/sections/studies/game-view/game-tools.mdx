## Purpose

Everything one does to the **current move** that is not playing on the board: write its comment, mark its quality, evaluate the whole game, and get it out (FEN, full PGN, bare main line, PNG, GIF). It sits under the board as the viewer's `boardFooter`, so it is hidden in fullscreen.

Comment and NAGs are read from the PGN on every render, not kept in state: what is seen is always what is saved and there are no two truths to sync. Editing them goes through `lib/chess/pgn-edit` and up through `onPgnChange`; saving is the section's job.

## Behaviour

- **Tabs** (`role="tablist"`): "Comentario" and "Calidad" only with `canEdit`, then "Evaluación" and "Compartir". The comment tab shows a dot when the move has a comment; the quality tab shows the move's glyphs, so one knows what is inside without opening it. The bar ends with the move's name and the save label.
- **Comment:** an uncontrolled textarea keyed on `path:comment` so it remounts when the saved comment changes (the same move can be commented from the right-click menu). Saved on blur through `setCommentText` when the value differs.
- **Quality:** three NAG groups in two columns, the layout of chess programs: left what qualifies the move ("Jugada", "Matices"), right how the position stands ("Posición"). Each group is exclusive inside (a move is not "!" and "?" at once) but combines across groups. Paired signs (white/black variants) are picked by whose move it is through `nagCodeFor`. Disabled at the initial position.
- **Evaluación:** mounts [`GameReview`](/components/chess/game-viewer/game-review).
- **Compartir:** copy buttons for the FEN, the full PGN and the bare main line (`plainMovetext`: no variations, comments or headers), each flashing "Copiado" for two seconds; PNG and GIF export buttons that `import()` the export module on click, because almost nobody exports and it used to travel with every game. `exporting` disables both buttons while one runs; failures show an error hint.
