## Purpose

Two cards beside the board. The first lists the study's games so one can jump between them without going back; the second is the game's record, read top to bottom: where it was played, when and how it ended, and at the foot where the game came from and, for the owner, the delete control. The moves are edited on the board itself, so nothing else is left here.

## Props

| Prop       | Type              | Required | Meaning                                                                                                                                                                    |
| ---------- | ----------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `game`     | `GameView`        | yes      | The current game.                                                                                                                                                          |
| `siblings` | `StudyGameItem[]` | yes      | The study's games, current included; the current one gets `aria-current="page"`.                                                                                           |
| `newGame`  | `ReactNode`       | no       | The new-game modal, mounted by whoever has its data. Passed as a node so the aside does not carry the results catalog and the class games, which it uses for nothing else. |
| `editGame` | `ReactNode`       | no       | The "Datos de la partida" modal, rendered in the record card's head; absent when writing is not allowed.                                                                   |

## Behaviour

- Sibling rows show the student's title or the mapper's `label` fallback (round, event or position in the study), the players as a second line with a `title` tooltip because long names are cut, and the result.
- `metaCells` always yields **four** cells (Fecha, Ronda, ECO, Resultado) with a dash where there is no value: in a two-by-two grid, hiding one cell displaces the other three, and an incomplete record reads worse than one with declared gaps.
- With `game.canEdit`, [`DeleteGame`](/components/platform/sections/studies/game-view/delete-game) renders at the foot in its `inline` size with the label "Borrar".
