## Purpose

Opening a study is opening a game of it, so what is waited for on arrival is the whole workspace (2026-10-23, in place of the turning knight): the bleeding page, the side column with the study's name, its chip, «Nueva partida»'s FAB and seven rows of games, softly pulsing on the canvas; and the panel with the board's skeleton and its ring (the trail's row went with the toolbar on 2026-10-23; the blank record above the board went on 2026-10-23 with the record itself, which heads the moves' column now). From one game to the next only the page is waited for, since the layout stays: that wait is `GameSkeleton`'s alone (`partidas/[gameId]/loading.tsx`).

It is a `loading.tsx`'s, so it imports no Client Component, however indirectly (`components/loading-boundaries.test.ts`).
