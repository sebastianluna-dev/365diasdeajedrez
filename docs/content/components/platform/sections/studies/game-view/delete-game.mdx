## Purpose

Deleting one game with its variations, comments and arrows. Like [`DeleteStudy`](/components/platform/sections/studies/studies-list/delete-study), the dialog requires a confirmation checkbox exactly when the server does: here, when the game is cited in class blocks, which will be left empty.

## Props

| Prop              | Type                                 | Required                        | Meaning                                                                                    |
| ----------------- | ------------------------------------ | ------------------------------- | ------------------------------------------------------------------------------------------ |
| `studyId`         | `string`                             | yes                             | Bound into the action.                                                                     |
| `gameId`          | `string`                             | yes                             | Bound into the action.                                                                     |
| `name`            | `string`                             | yes                             | For the title.                                                                             |
| `classBlockCount` | `number`                             | yes                             | Class blocks that cite it. Above zero, the checkbox is required.                           |
| `size`            | `"regular" \| "compact" \| "inline"` | no · default `"regular"`        | `compact` spans the record column's width; `inline` is one more word of the record's foot. |
| `label`           | `string`                             | no · default `"Borrar partida"` | Trigger text; at the foot "Borrar" is enough.                                              |

## Behaviour

- `needsConfirmation = classBlockCount > 0`, the same condition as the action; otherwise the submit would bounce to `?error=gameInClasses` instead of deleting.
- The checkbox is `name="confirmClassBlocks" value="yes"`: sent only when ticked. `confirmed` gates the submit button and resets on close.
- Native `<dialog>`, `<form action={deleteStudyGame.bind(null, studyId, gameId)}>`; the action redirects to the study after deleting.

## Usage

From `components/platform/sections/studies/game-view/game-aside.comp.tsx`:

```tsx
import { DeleteGame } from "./delete-game.comp";

<DeleteGame
  studyId={game.studyId}
  gameId={game.id}
  name={game.title ?? `${game.white} – ${game.black}`}
  classBlockCount={game.classBlockCount}
  size="inline"
  label="Borrar"
/>;
```
