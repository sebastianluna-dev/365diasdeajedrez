## Purpose

The second tool of «Herramientas»: the study the game goes into (the person's own, `getOwnStudyOptions`) and the PGN, «Importar» («Importando…»), and «Sólo quiero analizarla» to the analysis board instead. `importPgnToStudy` reads the study from the form and runs the study's own `importPgnGames`: the same reader, the same limits, the games indexed in the same transaction, and the redirect to the first game that went in with the import's report. Without a study of their own, the page says so and leads to «Mis estudios».
