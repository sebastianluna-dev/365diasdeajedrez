## Purpose

The whole of [Analysis board](/chess/analysis-board) on the client. It receives the source the page resolved (or none), the person's own studies and `saveAnalysisToStudy`, and owns:

- the PGN with an undo stack (`usePgnHistory`), the current move, and the work kept for the tab in `sessionStorage` (written only once something changed; read once per visit in the browser, and the board keyed by what it opened with);
- **one engine** (`useEngineClient(true)`, created on arrival) for the viewer's analysis (`engineClient`) and the module;
- `useEngineSparring`: the position played against the module, every move added after the line's last with `addMoveToPgn`, the module's answered at once.
