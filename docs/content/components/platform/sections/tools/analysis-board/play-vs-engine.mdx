## Purpose

Planning decision B, drawn as T3 asks. Analysing, a card: what it does («A máxima potencia y al instante, sin reloj. Lo que juegues queda como variante del análisis.»), the colour as two cards — the side to move at the node on the board first — and «Jugar contra el módulo». Playing, the band above the board in the selection's blue: «Juegas con blancas contra el módulo», then «Te toca mover.», «El módulo piensa…» or how it ended («Jaque mate: ganaste.»), said politely to a screen reader, and «Volver al análisis».

## Props

| Prop         | Type                                     | Required | Meaning                                                      |
| ------------ | ---------------------------------------- | -------- | ------------------------------------------------------------ |
| `sideToMove` | `"white" \| "black"`                     | yes      | The colour offered first.                                    |
| `playing`    | `{ color, status, end, failed } \| null` | yes      | The line being played (`Sparring`), or null while analysing. |
| `onStart`    | `(color) => void`                        | yes      | Starts playing the node on the board with that colour.       |
| `onStop`     | `() => void`                             | yes      | «Volver al análisis».                                        |
