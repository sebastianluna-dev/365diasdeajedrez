## Purpose

K1, chosen on 2026-10-08: two fields with their labels under the board and one «Cargar» that reads whichever has text — the PGN when both do, as the FEN's hint says. A `PlatformForm` that submits nothing: `readPositionInput` checks it in the browser, and a failure is drawn under its own field («No es un FEN válido.», «No es un PGN válido.») through the field's `serverError`, cleared as soon as anything is typed. A good one calls `onLoad` with the PGN to open and empties the fields.

## Props

| Prop     | Type                    | Required | Meaning                               |
| -------- | ----------------------- | -------- | ------------------------------------- |
| `onLoad` | `(pgn: string) => void` | yes      | The board starts again from this PGN. |
