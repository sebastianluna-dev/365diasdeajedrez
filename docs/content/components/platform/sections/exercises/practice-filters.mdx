## Props

| Prop      | Type               | Required | Meaning                                                                                                                                                        |
| --------- | ------------------ | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `filters` | `PracticeFilters`  | yes      | The topics with a library exercise (a parent with such a child too), the active levels with their Elo range, and whether the library is empty.                 |
| `choice`  | `PracticeChoice`   | yes      | What the address says, `tema` and `nivel`, or nothing.                                                                                                         |
| `variant` | `"home" \| "page"` | yes      | On the home's card the choice waits for «Empezar» (a link to `/ejercicios/practica?tema=&nivel=`); on the practice page a change replaces the address at once. |
| `accent`  | `boolean`          | no       | On the home: whether «Empezar» is the screen's accent (when no series is left to continue).                                                                    |

## Behaviour

A filter, not a form (AGENTS.md): the two selects wear the accent's tone and never say an error. The topic select lists the first level as options and each parent's children under its heading (`groups`); the level select says «Intermedio · 1200–1599» (the Level catalog's bands, `formatEloRange`). «Empezar» is disabled until both are chosen. With `libraryEmpty` it draws one line instead: «Todavía no hay ejercicios en la biblioteca para practicar.»
