## Purpose

L4, chosen on 2026-10-08 for `/perfil/<slug>/partidas`. The day is written once, on its first game («Hoy», «Ayer», or the date, on the study day's calendar); each row says «Ganaste contra Don Chuy 783» («Ganó» on somebody else's profile), «Tablas con…», «En curso contra…» or «Anulada contra…», with the reason, the colour and the moves, and opens the game. Under the list, «Más recientes» and «Anteriores» between the pages. Empty, it says so — and offers «Jugar» on one's own profile, or «Ninguna partida con estos filtros» when a filter is on.

## Props

| Prop       | Type                       | Required | Meaning                                             |
| ---------- | -------------------------- | -------- | --------------------------------------------------- |
| `page`     | `PlayedGamesPage`          | yes      | One page from `listPlayedGamesOf`.                  |
| `isOwn`    | `boolean`                  | yes      | «Ganaste» or «Ganó».                                |
| `hrefOf`   | `(page: number) => string` | yes      | The address of another page, with the same filters. |
| `filtered` | `boolean`                  | yes      | A filter is on: the empty list says so.             |
| `now`      | `Date`                     | no       | The instant «Hoy» is read from; a story pins it.    |
