## Purpose

The streak of the person whose profile it is (`streakSummaryOf(userId)` in `services/study-goal`), not of whoever reads it. It only reads the activity: no game writes it (`services/play/no-activity.test.ts`), so playing never moves these figures — the streak measures studying.
