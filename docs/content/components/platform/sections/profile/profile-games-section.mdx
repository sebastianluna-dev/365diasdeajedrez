## Purpose

The list R1 asked for, drawn as the timeline L4 chose. The filters live in the URL — `?rival=<slug>`, `?resultado=win|loss|draw|open`, `?pagina=` — so a filtered list can be linked and reloaded; `PlayedGamesFilters` are two selects that navigate (a filter, not a form: the accent's focus, never an error), and a change goes back to the first page. The list is paginated on the server (`PLAYED_GAMES_PAGE_SIZE`, 20), open games first; the rivals are the bots the person has played, weakest first.
