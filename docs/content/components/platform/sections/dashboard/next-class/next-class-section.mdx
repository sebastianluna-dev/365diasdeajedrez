## Purpose

The first class ahead that is not cancelled, drawn exactly as «Mis clases» draws it — the same ticket, the same join data —, so the dashboard and `/clases` can never disagree about which class is next or whether its link is open. The foot says what is left, in counts and never of which payment («Te quedan 3 clases · Ver mis clases»). Without a class: «Tienes 1 clase por programar» and «Administración te escribirá para fijar la fecha.» when a payment has classes without a date, else «No tienes clases programadas» with «Cuando administración programe una clase contigo, aparecerá aquí.».

On the day of a class the page puts this section first, across the row, and «Continuar estudiando» steps back to a secondary button ([`ContinueStudyingSection`](/components/platform/sections/dashboard/continue-studying/continue-studying-section), `emphasis="secondary"`).
