## Purpose

The last block of the dashboard: what the student did recently, newest first. The list itself is the shared [`ActivityList`](/components/platform/shared/activity-list); this section owns the card, the title and the empty case.

## Props

This component takes no props.

## Behaviour

Awaits the dashboard data; renders the list when `recentActivity` has items, otherwise an empty state ("Sin actividad todavía") without an action link, because the action is the whole platform.

## Markup & styling

Block `.recent-activity` (4 lines): card spacing only.

**Other classes it renders:** `.platform-card`, `.platform-card__title`.

## Usage

From `app/(platform)/inicio/page.tsx`:

```tsx
<ActivityStatsSection />
<RecentActivitySection />
```
