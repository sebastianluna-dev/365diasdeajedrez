## Purpose

The metric cards ("Lecciones completadas", "Ejercicios resueltos"…) for a period, with a strip of toggle buttons to change the period and a "Por tema" row of pills. Since 2026-10-23 it is drawn in the new design system, under «Tus estadísticas» on the home page: the toggles are Material's filter chips (`mdChip("filter", pressed)`), the metrics tiles on the container's grey with their figure in the display face, the topics pale blue pills. It is a Client Component because the selected range is interface state; the numbers themselves are all in the props, so switching is instant and involves no data fetching.

## Props

| Prop    | Type             | Required | Meaning                                                                                                                    |
| ------- | ---------------- | -------- | -------------------------------------------------------------------------------------------------------------------------- |
| `stats` | `DashboardStats` | yes      | `Record<StatsRangeKey, { totals: { label, count }[]; topics: { label, count }[] }>` for `week`, `month`, `year` and `all`. |

## Behaviour

- `range` starts at `"week"`. The strip is a `role="group"` labelled "Periodo de estadísticas" of toggle buttons, the chosen one `aria-pressed="true"`. Not tabs: the ranges filter the one panel below rather than each showing its own, so the tabs pattern (a `tabpanel` each, `aria-controls`, arrow keys between them, a single Tab stop) would announce a structure that is not there.
- The grid renders `stats[range].totals`; the topics row renders only when the range has topics.
- Labels come from a local constant (`RANGE_LABELS`), in Spanish.

## Markup & styling

Block `.stats-cards` (76 lines).

**Elements:** `.stats-cards__filters`, `.stats-cards__filter`, `.stats-cards__grid`, `.stats-cards__card`, `.stats-cards__value`, `.stats-cards__label`, `.stats-cards__topics`, `.stats-cards__topics-title`, `.stats-cards__topic`

**Other classes it renders:** Material's filter chip (`mdChip`) on each range, `chip-selected` on the pressed one.

**Tokens:** `--platform-m3-container`, `--platform-m3-on-surface`, `--platform-m3-on-surface-variant`, `--platform-m3-info-container`, `--platform-m3-on-info-container`, `--md-sys-shape-corner-md`, `--platform-font-display`

**Breakpoints:** `(width < 1024px)` drops the grid from five columns to three; `(width < 640px)` to two. The buttons wrap at any width.

## Usage

From `components/platform/sections/dashboard/home/home.section.tsx`:

```tsx
<section id="estadisticas" className="home__block" aria-labelledby="home-stats-title">
  <h2 id="home-stats-title" className="home__block-title">
    Tus estadísticas
  </h2>
  <StatsCards stats={dashboard.stats} />
</section>
```
