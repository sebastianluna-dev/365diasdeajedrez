## Purpose

The metric cards ("Lecciones completadas", "Ejercicios resueltos"…) for a period, with a tab strip to change the period and a "Por tema" row of tags. It is a Client Component because the selected range is interface state; the numbers themselves are all in the props, so switching is instant and involves no data fetching.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `stats` | `DashboardStats` | yes | `Record<StatsRangeKey, { totals: { label, count }[]; topics: { label, count }[] }>` for `week`, `month`, `year` and `all`. |

## Behaviour

- `range` starts at `"week"`. The strip is a `role="tablist"` labelled "Periodo de estadísticas"; each button is `role="tab"` with `aria-selected`.
- The grid renders `stats[range].totals`; the topics row renders only when the range has topics.
- Labels come from a local constant (`RANGE_LABELS`), in Spanish.

## Usage

From `components/platform/sections/dashboard/activity-stats/activity-stats.section.tsx`:

```tsx
import { StatsCards } from "./stats-cards.comp";

const { stats } = await getUserDashboard();
// …
<StatsCards stats={stats} />
```
