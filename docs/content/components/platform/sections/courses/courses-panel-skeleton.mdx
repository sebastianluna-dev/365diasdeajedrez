## Purpose

The loading state of «Mis cursos» and the catalog (2026-10-22). Their layout keeps the side column and the bar's search on screen, so while a view loads only the panel waits: it draws, in the container's grey, a block where «Sigue donde ibas» or the catalog's heading goes, a line, and a row of four cards with their covers and two lines each, all pulsing softly together (`opacity`, 1.2s, still under `prefers-reduced-motion: reduce`). To a screen reader it is one status, «Cargando cursos…» (visually hidden).

It is a `loading.tsx`'s, so it is markup and CSS only: no Client Component behind it (`components/loading-boundaries.test.ts`). Arriving at `/cursos` from another screen, before the layout itself is ready, is the platform's other wait, `BoardLoading` (`app/(platform)/cursos/loading.tsx`).
