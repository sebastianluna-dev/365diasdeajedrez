## Purpose

The one part of the frame of «Cursos» that waits for the database (2026-10-22): the reads the side column counts — cached per request, so the page under it reads them again for free —, the groups (`coursesNavGroups`) and the next lesson of the course to go on with («Seguir donde iba», `resumeCourseOf`). Being its own async component, it streams in behind [`CoursesSideSkeleton`](/components/platform/sections/courses/courses-side-skeleton) while the rest of the frame is already on screen.

No props.
