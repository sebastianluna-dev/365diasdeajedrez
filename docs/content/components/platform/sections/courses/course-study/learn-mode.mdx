# `LearnMode`

|            |                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/courses/course-study/learn-mode.comp.tsx`                     |
| Kind       | Server Component                                                                            |
| Stylesheet | `learn-mode.comp.css` → block `.learn-mode`                                                 |
| Used by    | [`CourseStudyFrame`](/components/platform/sections/courses/course-study/course-study-frame) |
| Writes     | `setOnlyPriorityLessons()` · `services/courses/courses.actions.ts`                          |

## Purpose

The course's one setting, «Aprender»: «Todo» or «Prioridad». With «Prioridad» on, what stays in view is every lesson marked as priority and every lesson of a chapter marked as priority — **and nothing else**: since 2026-10-07 a lesson the student opened or finished no longer stays in view for that alone, because a list of priority lessons with others among them, untagged, read as a mistake. The price: while it is on, the course's progress counts the priority lessons only, so the figure can drop when it is switched on and comes back when it is switched off. It replaces `PriorityFilter`, the switch the old course and chapter pages had; the rule it sets (`UserCourseSettings.onlyPriorityLessons`) is the same.

It is a **lens**: it writes the settings row and not a single progress row, so switching it is free and reversible. It is per course, which is why it shows on every page of the course.

## Props

| Prop            | Type      | Required | Meaning                                                    |
| --------------- | --------- | -------- | ---------------------------------------------------------- |
| `courseId`      | `string`  | yes      | The course the setting is of.                              |
| `onlyPriority`  | `boolean` | yes      | The student asked to see only what is marked as priority.  |
| `hiddenLessons` | `number`  | yes      | How many lessons that hides.                               |
| `returnTo`      | `string`  | yes      | The page the control sits on, where a failure is reported. |

## Behaviour

- Each option is a `<form action={setOnlyPriorityLessons.bind(null, courseId, value)}>` with a hidden `returnTo`, and not one form with two radios: a preference is saved and the page is drawn again, so there is no state to keep and nothing to hydrate. The value is bound because a checkbox cannot transmit "false".
- The pressed one carries `aria-pressed="true"`; the two are a `role="group"` labelled by «Aprender».
- With the filter on, a note says what it hides and what follows from it: «56 lecciones ocultas. El progreso cuenta sólo las de prioridad.»

## Markup & styling

Block `.learn-mode` (65 lines): a sunken track with two halves, the pressed one raised.

**Elements:** `.learn-mode__label`, `.learn-mode__options`, `.learn-mode__form`, `.learn-mode__option`, `.learn-mode__note`

**Modifiers and states:** `.learn-mode__option_state_on`

**Tokens:** `--platform-surface`, `--platform-surface-neutral`, `--platform-surface-sunken`, `--platform-text`, `--platform-text-subtle`

The transition is off under `prefers-reduced-motion`.

## Usage

```tsx
<LearnMode
  courseId={course.id}
  onlyPriority={course.onlyPriorityLessons}
  hiddenLessons={course.hiddenLessons}
  returnTo={returnTo}
/>
```
