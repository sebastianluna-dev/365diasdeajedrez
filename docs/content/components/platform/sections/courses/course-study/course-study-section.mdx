## Purpose

`/cursos/10000004`: the course once it is the student's. Whoever opens it without having added the course is redirected by the page to its information page, which is where it is added.

## Props

| Prop        | Type           | Required | Meaning                                                          |
| ----------- | -------------- | -------- | ---------------------------------------------------------------- |
| `course`    | `CourseDetail` | yes      | The course with its chapters and the student's progress in each. |
| `errorCode` | `string`       | no       | Passed on to the frame.                                          |

## Behaviour

- One card per chapter, the whole card a link to it (`/cursos/<id>/<order>`): «Capítulo 1», the chapter's name whole («Los años de aprendizaje (1957–1959)»), a tag with how many lessons the staff marked as essential («2 imprescindibles») and the progress.
- A chapter's figures are of the lessons the student **sees**: with only the essential ones asked for, the bar is over those, which is the list that opens when the card is pressed. The tag counts the chapter's essential lessons whatever the filter says.
- A course without chapters shows an `EmptyState`.

**Breakpoints:** `(max-width: 620px)` one column. The hover transition is off under `prefers-reduced-motion`.

## Usage

From `app/(platform)/cursos/[courseRef]/page.tsx`:

```tsx
if (found.kind === "study") {
  if (!course.isAdded) redirect(course.infoHref);
  return <CourseStudySection course={course} errorCode={error} />;
}
```
