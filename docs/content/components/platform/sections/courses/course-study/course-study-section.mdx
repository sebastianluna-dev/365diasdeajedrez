## Purpose

`/cursos/10000004`: the course once it is the student's. Whoever opens it without having added the course is redirected by the page to its information page, which is where it is added.

## Props

| Prop        | Type           | Required | Meaning                                                          |
| ----------- | -------------- | -------- | ---------------------------------------------------------------- |
| `course`    | `CourseDetail` | yes      | The course with its chapters and the student's progress in each. |
| `errorCode` | `string`       | no       | Passed on to the frame.                                          |

## Behaviour

- One card per chapter, the whole card a link to it (`/cursos/<id>/<order>`): the chapter's name whole («Los años de aprendizaje (1957–1959)») and nothing above it — a chapter is not numbered —, the «Prioridad» tag when the staff marked the chapter (`chapter.isPriority`), and at the foot its progress as a count: «9/17 lecciones».
- **A chapter has no percentage and no bar**, and **the page does not show the course's progress** either: the frame draws «Tu progreso» on a chapter's page only, so here the aside is the course's options and its setting. A finished chapter (`chapter.isCompleted`) gets an orange check in front of its count (`CircleCheckSolidIcon`, the filled one); an unfinished one gets nothing, which is what "not yet" looks like.
- A chapter's count is of the lessons the student **sees**: with only the priority ones asked for, it is over those, which is the list that opens when the card is pressed.
- A course without chapters shows an `EmptyState`.

**Elements:** `.course-study__item`, `.course-study__chapter`, `.course-study__title`, `.course-study__foot`, `.course-study__tag`, `.course-study__progress`, `.course-study__done`, `.course-study__done-icon`, `.course-study__ratio`, `.course-study__ratio-value`

## Usage

From `app/(platform)/cursos/[courseRef]/page.tsx`:

```tsx
if (found.kind === "study") {
  if (!course.isAdded) redirect(course.infoHref);
  return <CourseStudySection course={course} errorCode={error} />;
}
```
