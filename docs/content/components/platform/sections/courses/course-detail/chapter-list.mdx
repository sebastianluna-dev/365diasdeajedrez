# `ChapterList`

|            |                                                                                                    |
| ---------- | -------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/courses/course-detail/chapter-list.comp.tsx`                         |
| Kind       | Server Component                                                                                   |
| Stylesheet | `chapter-list.comp.css` → block `.chapter-list`                                                    |
| Used by    | [`CourseDetailSection`](/components/platform/sections/courses/course-detail/course-detail-section) |
| Composes   | [`ProgressIndicator`](/components/platform/shared/progress-indicator)                              |
| Uses       | `CourseChapterItem` from `services/courses/courses.types`                                          |

## Purpose

The chapters of a course as an `<ol>`. The **whole row** is the link, not just the name: it is what the design draws and it avoids having to aim at small text. Each row shows the order number, name, optional description, "n lecciones · m min", a progress bar and a chevron.

## Props

| Prop       | Type                  | Required | Meaning                                                                                                                                       |
| ---------- | --------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `chapters` | `CourseChapterItem[]` | yes      | `{ id, order, name, description?, href, totalLessons, completedLessons, estimatedDuration? }[]`, already filtered by the priority preference. |

## Behaviour

None. The percentage is computed inline with a zero guard and passed to the stacked [`ProgressIndicator`](/components/platform/shared/progress-indicator) with "done/total" as detail. The chevron is an inline `aria-hidden` SVG.

## Markup & styling

No modifiers.

**Tokens:** `--platform-accent-ink`, `--platform-accent-wash`, `--platform-font`, `--platform-shadow-card`, `--platform-surface`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`, `--platform-text-subtle`

**Breakpoints:** `(max-width: 900px)` wraps the progress under the info.

## Usage

From `components/platform/sections/courses/course-detail/course-detail.section.tsx`:

```tsx
import { ChapterList } from "./chapter-list.comp";

<ChapterList chapters={course.chapters} />;
```
