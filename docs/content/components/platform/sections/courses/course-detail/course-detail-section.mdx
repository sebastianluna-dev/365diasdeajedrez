## Purpose

Everything about one course on one screen: the hero with the facts the card folded away (description, levels, authors), the overall progress and the "Continuar curso" button, the cover, and the chapters. The [`PriorityFilter`](/components/platform/shared/priority-filter) rests at the foot of the cover column so it lands at the height of the progress bar beside it.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `course` | `CourseDetail` | yes | `id`, `name`, `description?`, `cover?`, `typeLabel`, `levelLabels`, `authors: { name, roleLabel }[]`, `progress`, `continueHref`, `ctaLabel`, `chapters`, `onlyPriorityLessons`, `hiddenLessons`. Already filtered by the priority preference. |
| `errorCode` | `string` | no | Code from `?error=` (`throttled`, `invalid`…), translated with `STUDENT_ERROR_MESSAGES` into a `PlatformNotice`. |

## Behaviour

- The cover link goes to `continueHref`, the same as the button that already names it, so it is `tabIndex={-1}` and `aria-hidden` to avoid announcing one link twice. `next/image` with `sizes="(max-width: 980px) 100vw, 470px"`.
- When the filter is on and it leaves zero lessons, a warning under the switch says so ("Ninguna lección de este curso está marcada como imprescindible…").
- The chapters header counts chapters and lessons with singular/plural handling; the list is [`ChapterList`](/components/platform/sections/courses/course-detail/chapter-list).
- No writes here: the filter's form belongs to `PriorityFilter`.
