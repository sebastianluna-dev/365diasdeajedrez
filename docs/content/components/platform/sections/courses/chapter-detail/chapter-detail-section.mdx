## Purpose

One chapter: "Capítulo n", name, description, lesson count and estimated time, the stacked progress bar with "Continuar capítulo", and the lessons. Two controls live here and nowhere else in the student area: the **Move Trainer toggle** ("Agregar al Move Trainer"), shown only when the chapter has exercises, and the [`PriorityFilter`](/components/platform/shared/priority-filter) next to the "Lecciones" title.

## Props

| Prop        | Type          | Required | Meaning                                                                                                                                                                                                                  |
| ----------- | ------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `chapter`   | `ChapterView` | yes      | `id`, `courseId`, `order`, `name`, `description?`, `totalLessons`, `completedLessons`, `estimatedDuration?`, `continueHref`, `ctaLabel`, `hasExercises`, `inTrainer`, `lessons`, `onlyPriorityLessons`, `hiddenLessons`. |
| `errorCode` | `string`      | no       | Code from `?error=` (`throttled`, `invalid`…), translated with `STUDENT_ERROR_MESSAGES` into a `PlatformNotice`.                                                                                                         |

## Behaviour

- The trainer toggle is a `<form action={toggleTrainerChapter.bind(null, chapter.id, !chapter.inTrainer)}>`: bound argument rather than a checkbox for the same reason as the priority filter (a checkbox cannot submit `false`). The design does not draw this button, but the trainer is reached from here and from nowhere else, so it stays beside the primary button as a secondary one.
- The resume button renders only when the chapter has lessons.
- When the filter is on and leaves no lessons, a warning replaces the list and names how many lessons are hidden.
