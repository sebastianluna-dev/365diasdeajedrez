## Purpose

The information page places the course **among all the levels** instead of only naming its own: six segments, the easiest first, with the course's lit. Above, the span in one sentence: «Para jugadores con Elo 1200–1999».

The range guides whoever is choosing. It closes the course to nobody.

## Props

| Prop     | Type                | Required | Meaning                                                          |
| -------- | ------------------- | -------- | ---------------------------------------------------------------- |
| `scale`  | `CourseLevelItem[]` | yes      | Every level of the catalog, the easiest first: one segment each. |
| `levels` | `CourseLevelItem[]` | yes      | The levels the course is aimed at: the segments that are lit.    |

## Behaviour

- Renders nothing when the catalog is empty or the course has no level.
- Each segment shows the level's name and its range in the compact wording (`compactEloRange`: «< 800», «1200–1599», «2200+»), with the level's description as `title`.
- The columns are as many as the catalog has levels, set inline (`grid-template-columns: repeat(n, …)`): it is a figure of the data, not of the design.
- What the colour says is also written for whoever does not see it: a lit segment ends with a visually hidden «: nivel del curso».
