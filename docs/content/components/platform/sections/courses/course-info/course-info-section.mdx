## Purpose

What a course **is**, for whoever has not added it: nothing on this page is the student's — there is no progress here — except the button. It is the page the staff's «Ver en la plataforma» opens and the one a course is shared by, since its URL carries the slug.

## Props

| Prop        | Type                | Required | Meaning                                                            |
| ----------- | ------------------- | -------- | ------------------------------------------------------------------ |
| `course`    | `CourseDetail`      | yes      | The course whole; see `services/courses/courses.types.ts`.         |
| `levels`    | `CourseLevelItem[]` | yes      | Every level of the catalog, for the scale the course is placed on. |
| `errorCode` | `string`            | no       | What `addCourse` bounced back with in `?error=` (`throttled`).     |

## Behaviour

- **The button.** Not added: a `<form action={addCourse.bind(null, course.id)}>` with «Agregar a mis cursos», which writes the progress row and redirects to the course to study. Added: a link to `course.studyHref` that reads «Empezar curso», «Continuar curso» or «Repasar curso».
- **The title is the cover's.** The staff's covers carry the course's name drawn on them, so the `<h1>` is there for whoever does not see the picture and is visually hidden. A course without cover gets a dark box with the name written on it in the serif (`.course-info__cover_kind_blank`), which is `aria-hidden`: the heading still names the page.
- **Figures:** chapters, lessons and total time, of the WHOLE course (`lessonCount`, `totalMinutes`), whatever the student's essential-lessons filter says.
- **Chapters** are cards and **not links**: a dark header with «Capítulo n» and, in the serif, the note the chapter's name closes with («1957–1959», from `splitChapterName`) or the name itself when it has none; then the title, the description and «17 lecciones · 340 min».
- **«Procedencia»**: one line per source, the title linked when there is a URL. The staff's notes never reach here.

**Breakpoints:** `(max-width: 980px)` the card becomes one column, the figures and the button under a rule; `(max-width: 620px)` tightens the card's margins and padding. The chapters are a grid that fills (`repeat(auto-fill, minmax(300px, 1fr))`), so they need no breakpoint.

`.course-info__cta` is a link or the button of a form, so its width is set (`width: 100%`) and not flexed: the side column is a flex column, where `flex: 1` would take its height.

## Usage

From `app/(platform)/cursos/[courseRef]/page.tsx`:

```tsx
const found = await resolveCourseReference(courseRef);
// found.kind === "info"
<CourseInfoSection course={found.course} levels={await listCourseLevels()} errorCode={error} />;
```
