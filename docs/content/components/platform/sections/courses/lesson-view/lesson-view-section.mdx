## Purpose

Where a student studies. The lesson is a PGN with commentary, so the screen is the [`GameViewer`](/components/chess/game-viewer/game-viewer) with `moveList="flow"`: a lesson is **read**, the running text accompanies the narrative, whereas the table is for consulting a game move by move. The viewer's header slots carry what used to sit above the board: "n. Name" as title, the chapter, position within it and duration as subtitle, the description, and a "Prioridad" badge.

Under the viewer, the actions: mark as completed (or the completed state), next lesson or back to the chapter, "Entrenar esta lección (n)" when it has exercises, and a quiet "← Lección anterior" that the design does not draw but without which one could only go back with the browser button.

## Behaviour

- [`LessonTracker`](/components/platform/sections/courses/lesson-view/lesson-tracker) is rendered first and marks the lesson as opened from the client, because writes never happen during the server render.
- "Marcar como completada" is `<form action={completeLesson.bind(null, lesson.id)}>`; the action records completion, updates the course's return point and revalidates. When `statusCode` is `COMPLETED` the form is replaced by the check mark and "Lección completada".
- The viewer's `skip` slot gets a "Saltar" link to the next lesson (titled "Pasar a la siguiente lección sin marcar esta") when there is one.
- Next and previous hrefs respect the priority filter: the mapper computes them over the visible lessons.
