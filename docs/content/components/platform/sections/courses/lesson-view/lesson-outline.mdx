# `LessonOutline`

|            |                                                                                                                                                                       |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/courses/lesson-view/lesson-outline.comp.tsx`                                                                                            |
| Kind       | Server Component                                                                                                                                                      |
| Stylesheet | `lesson-outline.comp.css` → block `.lesson-outline`                                                                                                                   |

## Purpose

Where the lesson stands: the course at the top, the chapter under it and the chapter's lessons below, with the one open marked. It is the chapter's page condensed into a column, so moving on to the next lesson does not mean going back twice — which is what the screen used to ask for, since the only way on was the «Siguiente lección» button at the foot.

It is **pinned to the window**, not laid out in the page: it begins right under the bar, touches the left edge and runs to the bottom one, so the lessons read as a panel of the screen rather than a card floating on it.

## Props

| Prop              | Type              | Required | Meaning                                                                                                              |
| ----------------- | ----------------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `courseName`      | `string`          | yes      | The course, linking to its chapters.                                                                                 |
| `courseHref`      | `string`          | yes      | `platformRoutes.courseDetail`, built by the mapper.                                                                  |
| `courseThumbnail` | `string`          | no       | The course's square image (40 px), its cover cropped square while it has none. Without one, only the name is drawn.  |
| `chapterName`     | `string`          | yes      | The chapter these lessons belong to, linking to its list.                                                            |
| `chapterHref`     | `string`          | yes      | `platformRoutes.chapterDetail`.                                                                                      |
| `lessons`         | `LessonSibling[]` | yes      | `{ id, name, href, statusCode }`, in reading order and already filtered by the student's preferences.                |
| `currentLessonId` | `string`          | yes      | Which one is being read.                                                                                             |

## Behaviour

- The lesson being read **is not a link**: it would lead where one already is. It is drawn as a `<span>` with `aria-current="page"` and the accent background, which is also what tells it apart in the list.
- A completed lesson carries `CircleCheckSolidIcon`, the same mark the chapter's page uses. The current one paints it in its own colour so the row reads as one piece.
- The list is the **same sequence** `prevLessonHref`/`nextLessonHref` walk: the mapper builds both from `flattenLessons`, so a lesson hidden by the priority filter is missing from the column and from the buttons alike, and the two never disagree.
- **The course's head does not scroll and the chapter does not leave.** The panel keeps its scroll inside: `.lesson-outline__course` stays out of it — where one is should not scroll away — and only `.lesson-outline__body` moves, with the chapter's name `position: sticky` at its top, its own background and hairline covering the lessons that pass underneath.
- **Every lesson carries its stop on a thread.** A dotted line runs down the marks' column behind them, and each row ends in a filled check (done) or an empty ring (pending), painted with the row's own background so the line stops at it instead of crossing.
- The whole `<nav>` is labelled "Lecciones del capítulo".

## Markup & styling

Block `.lesson-outline` (179 lines).

**Pinned, which takes a page with no transform.** It is `position: fixed` at `top: 70px` (the bar's height, in the page's own px, which under the zoom are the ones the bar is drawn with) with `left: 0`, `bottom: 0` and `width: var(--outline-width, 300px)`, set by `.lesson-view`. A `fixed` element is anchored to the window only while no ancestor carries a transform, which is why `.platform-page_height_screen` turns off the page's entrance animation: `animation: … both` left a transform on the page for good, and with it the panel hung from the page's box instead of the window's.

**Elements:** `.lesson-outline__course`, `.lesson-outline__cover` (56px), `.lesson-outline__course-name`, `.lesson-outline__body` (what scrolls), `.lesson-outline__chapter`, `.lesson-outline__list` (its `::before` is the dotted thread), `.lesson-outline__item`, `.lesson-outline__lesson`, `.lesson-outline__name`, `.lesson-outline__done`, `.lesson-outline__pending`

**Modifiers and states:** `.lesson-outline__lesson_state_current`

**Tokens:** `--outline-width` (given by `.lesson-view`), `--platform-accent`, `--platform-accent-ink`, `--platform-accent-soft`, `--platform-bg`, `--platform-border`, `--platform-border-strong`, `--platform-shadow-card`, `--platform-surface`, `--platform-text`, `--platform-text-title`

**Breakpoints:** at `(max-width: 1080px)` or `(max-height: 620px)` it stops being an edge of the window — `position: static`, its rounding and card shadow back — and goes into the flow under the lesson, at whatever height its lessons need, with nothing inside scrolling on its own.

## Usage

From `lesson-view.section.tsx`:

```tsx
<LessonOutline
  courseName={lesson.courseName}
  courseHref={lesson.courseHref}
  courseThumbnail={lesson.courseThumbnail}
  chapterName={lesson.chapterName}
  chapterHref={lesson.chapterHref}
  lessons={lesson.chapterLessons}
  currentLessonId={lesson.id}
/>
```
