## Purpose

Opening a lesson is an event worth recording: it marks the lesson `IN_PROGRESS` and makes it the course's return point (what "Continuar" on the dashboard leads to). A Server Component must not write during render, so the write is moved into an effect in this tiny Client Component, which renders nothing.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `lessonId` | `string` | yes | The lesson being opened. |

## Behaviour

- An effect calls `touchLesson(lessonId)` once per lesson id, guarded by a ref so React strict mode's double effect and re-renders do not fire it twice.
- The promise is not awaited and its result is ignored: the page does not depend on it, and the dashboard reads the effect on its next render. The action itself resolves the user through the DAL and ignores ids the student may not access.

## Markup & styling

Nothing rendered.
