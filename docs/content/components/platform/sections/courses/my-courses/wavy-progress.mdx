## Purpose

The progress of the new design system: an SVG 200 units wide stretched to its box (`preserveAspectRatio="none"`, the stroke kept at 4px by `vector-effect`), the done part a sine wave, a 6-unit gap, and the track. It is always read beside a figure that says the same in words, so it is `aria-hidden`. It does not move.

## Props

| Prop      | Type      | Required | Meaning                                                 |
| --------- | --------- | -------- | ------------------------------------------------------- |
| `percent` | `number`  | yes      | 0–100.                                                  |
| `isDone`  | `boolean` | no       | Finished: one straight line in `--platform-m3-success`. |
| `size`    | `"lg"`    | no       | 12px high, its track in the secondary container.        |
