## Purpose

«Buscar cursos, temas o autores», in the bar of both «Cursos» pages through `PlatformHeaderContext`, drawn as Material's search bar (the library has none, so it is ours): a 48px pill in `--platform-m3-container-high` that turns white with a shadow while it has the focus. It searches the **whole** catalog from any view, as Gmail searches every label: a GET form to `/cursos/catalogo` with `q`, so it works without JavaScript and its results have an address. The catalog matches the name, the description, the authors, the topics and the levels, without accents or case (`foldForSearch`).

A search is not a form that validates — nothing to err —, so it is a bare `<form role="search">` and not a `PlatformForm`; the pill says where the focus is.

It is a Client Component because it lives in the layout both pages share, which does not render again when the address changes, and it still has to show what was searched on the catalog's results: it reads `q` from the address (on the catalog only) and remounts the field when it changes.

No props.
