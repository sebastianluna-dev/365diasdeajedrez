## Purpose

The main column of `/cursos`. Unlike the dashboard sections it does not fetch: the page calls `getUserCourses()` because its header summary (course count, lessons done) comes from the same list, and fetching twice would be wasteful even with `cache()`.

It receives **every** course and the level asked for, and narrows the list itself: the header summary is of all the courses whatever the filter says, because what the student has done does not shrink by looking at less.

## Props

| Prop        | Type                | Required | Meaning                                                                                  |
| ----------- | ------------------- | -------- | ---------------------------------------------------------------------------------------- |
| `courses`   | `CourseSummary[]`   | yes      | Every published course with the student's progress, unfiltered, from the page.           |
| `levels`    | `CourseLevelItem[]` | yes      | The levels in use, the easiest first, from `listCourseLevels()`.                         |
| `levelSlug` | `string`            | no       | What `?nivel=` brought. A slug the catalog does not have is ignored: the list shows all. |

## Behaviour

- Empty array → an [`EmptyState`](/components/platform/shared/empty-state) ("Todavía no hay cursos disponibles"), without the filter.
- Otherwise the [`LevelFilter`](/components/platform/sections/courses/courses-list/level-filter) (when there is any level) and a column of cards, one per course aimed at the level, keyed by id. A course with several levels appears under each of them.
- A level with no course → «Todavía no hay cursos de nivel …» with a link back to all of them.
- The filter is a lens over the list, not a permission: nothing here looks at the student's rating, and a course of any level opens from «Todos» or by its URL.

## Markup & styling

Block `.courses-list`: a vertical flex column with a gap, and a little more room under the filter (`.level-filter`). Everything else is the card's and the filter's.

## Usage

From `app/(platform)/cursos/page.tsx`:

```tsx
import { CoursesListSection } from "@/components/platform/sections/courses/courses-list/courses-list.section";

<div className="courses-page__layout">
  <CoursesListSection courses={courses} levels={levels} levelSlug={nivel} />
  <StudyGoalAside goal={goal} />
</div>;
```
