## Purpose

«Cursos» is one place with two collections (2026-10-22): the student's courses at `/cursos` and the catalog at `/cursos/catalogo`. Each has its own address — the catalog is not a filter of the student's courses —, and both live under one layout, `app/(platform)/cursos/(lista)/layout.tsx`, which draws this frame **once**: the `.platform-workspace`, the side column ([`CoursesSideNav`](/components/platform/sections/courses/courses-side-nav): «Seguir donde iba» and the groups of `coursesNavGroups`, counted on the server, the view on screen lit by the browser) and the catalog's search in the bar. Moving between views keeps all of it in place and draws only the panel again, as Gmail's labels do; meanwhile each page's `loading.tsx` puts [`CoursesPanelSkeleton`](/components/platform/sections/courses/courses-panel-skeleton), in that page's shape, where the panel goes. A container: its one job is to place the panel it is given (`children`).

The layout reads the student's courses, the catalog and the levels (cached per request, so the page under it reads them again for free), builds the groups and finds the course to go on with (`resumeCourseOf`).

## Props

| Prop         | Type                     | Required | Meaning                                                          |
| ------------ | ------------------------ | -------- | ---------------------------------------------------------------- |
| `groups`     | `PlatformSideNavGroup[]` | yes      | `coursesNavGroups(mine, catalog, levels, view)`.                 |
| `resumeHref` | `string`                 | no       | The next lesson of the course to go on with: «Seguir donde iba». |
| `query`      | `string`                 | no       | What the search already holds, on the catalog's results.         |
| `children`   | `ReactNode`              | yes      | The panel.                                                       |

No stylesheet of its own: the workspace's rules live in `platform.css`.
