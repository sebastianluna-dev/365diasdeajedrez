## Purpose

The column lives in the layout both pages share (2026-10-22), which is drawn once and not again when the view changes, so it cannot be told on the server which link is lit. The server counts it (`coursesNavGroups`: «Tus cursos» by state, «Catálogo» whole and by level), and this leaf lights the view on screen from the address: a link is current when it is the same page and carries the same value of that page's view parameter — `estado` on «Mis cursos», `nivel` on the catalog —, so the catalog's topic and search narrow a view without unlighting it.
