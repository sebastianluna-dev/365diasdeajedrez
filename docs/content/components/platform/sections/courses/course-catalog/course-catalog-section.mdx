# `CourseCatalogSection`

|            |                                                                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/courses/course-catalog/course-catalog.section.tsx`                                                                  |
| Kind       | Server Component                                                                                                                                  |
| Stylesheet | `course-catalog.section.css` → block `.course-catalog`                                                                                            |
| Used by    | `/cursos/explorar` (in the wide page, `platform-page_width_wide`)                                                                                 |
| Composes   | [`CatalogBrowser`](/components/platform/sections/courses/course-catalog/catalog-browser), [`EmptyState`](/components/platform/shared/empty-state) |
| Reads      | `getCourseCatalog()`, `listCourseLevels()` · `services/courses/courses.service.ts`                                                                |

## Purpose

Every course the academy has published, to find the ones to add. The section is the page's head — the title and «4 cursos publicados» — and hands the catalog to [`CatalogBrowser`](/components/platform/sections/courses/course-catalog/catalog-browser), which filters it in the browser (2026-10-07). Until then the section filtered on the server by one level from the URL, with a row of chips (`LevelFilter`, removed).

`?nivel=<slug>` still works: it is handed over as the level ticked on arrival, and one the catalog does not have is ignored.

## Props

| Prop        | Type                | Required | Meaning                                                 |
| ----------- | ------------------- | -------- | ------------------------------------------------------- |
| `courses`   | `CourseSummary[]`   | yes      | Every published course, the ones the student added too. |
| `levels`    | `CourseLevelItem[]` | yes      | The catalog's levels, the easiest first.                |
| `levelSlug` | `string`            | no       | What `?nivel=` brought, ticked on arrival.              |

## Markup & styling

Block `.course-catalog` (6 lines): a column, the head over the catalog.

## Usage

From `app/(platform)/cursos/explorar/page.tsx`:

```tsx
const [courses, levels, { nivel }] = await Promise.all([getCourseCatalog(), listCourseLevels(), searchParams]);

<div className="platform-page platform-page_width_wide course-catalog-page">
  <CourseCatalogSection courses={courses} levels={levels} levelSlug={nivel} />
</div>;
```
