## Purpose

Where a course to add is found. It lists **every** published course, the ones already added too — marked by their progress — so a course does not vanish from where it was found the day it is added.

## Props

| Prop        | Type                | Required | Meaning                                                              |
| ----------- | ------------------- | -------- | -------------------------------------------------------------------- |
| `courses`   | `CourseSummary[]`   | yes      | Every published course.                                              |
| `levels`    | `CourseLevelItem[]` | yes      | The levels the list can be narrowed to, the easiest first.           |
| `levelSlug` | `string`            | no       | What `?nivel=` brought. A slug the catalog does not have is ignored. |

## Behaviour

- The summary counts what is **listed**: «4 cursos publicados» with no filter, «2 de 4 cursos · nivel Avanzado» with one.
- A level without courses shows an `EmptyState` with a way back to «Todos»; a catalog without courses, one that says so, and no filter.
- The filter only narrows the list. No course is closed to anybody by their rating, and the student has none stored.

## Markup & styling

Block `.course-catalog` (39 lines): the cards in a grid of `repeat(auto-fill, minmax(360px, 1fr))` with a 20px gap, which is two to a row in the page's 960px.

**Elements:** `.course-catalog__head`, `.course-catalog__title`, `.course-catalog__summary`, `.course-catalog__list`

**Tokens:** `--platform-text-muted`

**Breakpoints:** `(max-width: 760px)` one column.

## Usage

From `app/(platform)/cursos/explorar/page.tsx`:

```tsx
const [courses, levels, { nivel }] = await Promise.all([getCourseCatalog(), listCourseLevels(), searchParams]);

<CourseCatalogSection courses={courses} levels={levels} levelSlug={nivel} />;
```

## Related

- `explorar` is a reserved course slug (`isReservedCourseSlug`), so no course can take this URL.
