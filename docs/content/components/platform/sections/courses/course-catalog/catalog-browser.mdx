## Purpose

The catalog as the owner chose it on 2026-10-07 («E2», with the filters at the side of «F3»): a column with the search and the filters, and over the courses how many are left and what is filtered, so that with several filters on one never loses track of them.

## Props

| Prop           | Type                | Required | Meaning                                                                                 |
| -------------- | ------------------- | -------- | --------------------------------------------------------------------------------------- |
| `courses`      | `CourseSummary[]`   | yes      | Every published course, the ones the student added too.                                 |
| `levels`       | `CourseLevelItem[]` | yes      | The catalog's levels, the easiest first.                                                |
| `initialLevel` | `string`            | no       | A level's slug ticked on arrival (`?nivel=`); one the catalog does not have is ignored. |

## Behaviour

- **The column** (240px, sticky under the shell's bar): the search, then «Nivel», «Tema» and «Tus cursos» («Los que llevas», «Sin empezar»), each option a [`PlatformCheckbox`](/components/platform/shared/platform-checkbox) in the accent's tone — a filter is not a form, so it is never blue — with how many courses it has. The topics come from the courses: a topic no course teaches has no filter.
- **How they combine**: the options of one filter add up (a course of any ticked level); the filters narrow each other (that level and that topic). «Tus cursos» with both or neither ticked is everything.
- **The search** matches the name, the description, the authors, the topics and the levels, folded (`foldForSearch`: no case, no accents); its focus is the accent's, a search not being a form.
- **Over the courses**: how many are left (a live region), «Quitar filtros» (a row action) while something is filtered, and the filtered options as pills in the accent's tint, each taking its filter off.
- **The covers** ([`CourseCard`](/components/platform/sections/courses/course-card)), three to a row, two under 1024px, one on a phone. Nothing left: an [`EmptyState`](/components/platform/shared/empty-state) says how to find something.
- **On a phone** (under 768px) the column keeps only the search, above the courses, and «Filtros» — with how many are on — opens the filters in a [`PlatformPopup`](/components/platform/shared/platform-popup) («Filtros», `sm`), closed by «Ver N cursos».
