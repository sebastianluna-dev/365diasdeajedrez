## Purpose

What students see of their teacher in the classes they attend, plus the one setting that changes behaviour: the **time zone**, which is how the class form interprets the dates the teacher types and how the student's `datetime-local` values are converted to UTC. The login email is shown but not editable; staff changes accounts.

## Props

| Prop        | Type             | Required | Meaning                                                                                                     |
| ----------- | ---------------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `profile`   | `TeacherProfile` | yes      | `displayName`, `email`, `title?`, `timezone?`, `photo?`, `bio?`.                                            |
| `errorCode` | `string`         | no       | `?error=` from the action, translated with `TEACHER_ERROR_MESSAGES` (unknown codes fall back to `invalid`). |

## Behaviour

The whole card is a [`PlatformForm`](/components/platform/shared/platform-form) posting to `updateTeacherProfile`, each field a `PlatformFormField`: name (required, and an empty one says so under it instead of submitting), title, time zone (a [`PlatformSelect`](/components/platform/shared/platform-select) over `TIMEZONE_OPTIONS`, underscores shown as spaces), photo as a URL (moving it to [`ImageUpload`](/components/platform/shared/image-upload) is an open improvement) and a bio textarea. The action validates, saves and revalidates `/profesor/perfil`.

## Markup & styling

Block `.teacher-profile` (29 lines), on top of `.platform-card` and `.platform-form`.

**Elements:** `.teacher-profile__hint`, `.teacher-profile__fields`

**Other selectors it styles:** `.platform-form__field` (the whole width: the card's column starts its children at the left edge).

**Tokens:** `--platform-text-muted`

**Breakpoints:** `(width < 768px)` collapses the two-column field grid.

## Usage

From `app/(platform)/profesor/perfil/page.tsx`:

```tsx
import { TeacherProfileSection } from "@/components/platform/sections/teacher/profile/teacher-profile.section";

<TeacherProfileSection profile={profile} errorCode={error} />;
```
