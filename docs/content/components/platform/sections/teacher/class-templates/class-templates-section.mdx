## Purpose

«Clases prediseñadas» (2026-10-19), the second entry of the teacher's «Material»: classes the academy has already written — the text, the diagrams, the questions — for a teacher to read as their student would, or to start from. Each card shows the class's board, its course and level, what it teaches, how long it takes and how many blocks it has, and opens [`ClassTemplateSection`](/components/platform/sections/teacher/class-templates/class-template-section).

Front-only: the three classes are sample data (`class-templates.sample.ts`), every teacher sees the same ones, and nothing is stored or can be used in a class yet; the notice at the top says so.
