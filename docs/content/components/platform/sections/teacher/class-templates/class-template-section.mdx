## Purpose

One of the «Clases prediseñadas» (2026-10-19): the page's head says its title, course, level and length, and the class's content opens in the class editor in the student's view, so it reads as the student would read it; «Editar» turns it into the editor to try changes, which, like everything in the editor, are not stored. A slug no template has answers 404.
