## Purpose

A game block's game is transcribed on the platform's one viewer in its editing mode, the same one the studies and the chapter games mount: moves are played on the board, the move list's right click comments, promotes or deletes, the tools under the board annotate (comment, quality, evaluation), the engine is on offer and Ctrl+Z undoes. It replaced `AnalysisBoard`, a separate editor, on 2026-10-03.

The block is saved by its form, not by itself: the PGN is published in a hidden input named by `name`, so the bound server action reads `formData.get("pgn")` like any other field. Nothing autosaves.

## Props

| Prop         | Type     | Required | Meaning                                                                             |
| ------------ | -------- | -------- | ----------------------------------------------------------------------------------- |
| `name`       | `string` | yes      | Name of the hidden input the PGN travels in.                                        |
| `defaultPgn` | `string` | no       | The block's game. Absent, empty or unreadable, the field starts from an empty game. |

## Behaviour

- The PGN lives in `usePgnHistory` (with undo): the viewer's edits come back through `onPgnChange` and feed the viewer again. The starting PGN is the block's, rewritten once by `serializeGame` so the first edit does not also reformat it.
- **Pegar un PGN** (a `<details>`): a textarea (up to `PGN_MAX_LENGTH`) and «Cargar este PGN», which reads the text with `parseEditableGame` and, if it is a game, replaces the whole one as one more step of the history (Ctrl+Z brings back the previous). An unreadable text leaves the game alone and shows an error with `role="alert"`. The textarea has no `name`, so it is not sent with the block.
- The viewer is not a `PlatformFormField`'s control, which is a single input the label points at: a viewer is a whole board with its buttons. The field is a `role="group"` named by its own label and described by its hint, drawn as a `PlatformFormField`'s are (the text size, regular weight, the muted grey).
