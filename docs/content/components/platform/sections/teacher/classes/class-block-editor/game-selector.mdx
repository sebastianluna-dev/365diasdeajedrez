# `GameSelector`

|            |                                                                                            |
| ---------- | ------------------------------------------------------------------------------------------ |
| File       | `components/platform/sections/teacher/classes/class-block-editor/game-selector.comp.tsx`   |
| Kind       | Client Component                                                                           |
| Stylesheet | none (a `FormField` with a native `<select>`)                                              |
| Used by    | [`BlockForm`](/components/platform/sections/teacher/classes/class-block-editor/block-form) |
| Composes   | [`FormField`](/components/platform/shared/form-field)                                      |
| Uses       | `ReferenceableGameGroup` from `services/teacher-classes/teacher-classes.types`             |

## Purpose

The games a teacher may cite in a class: their own studies' games and those of their active students, grouped as `<optgroup>`s labelled "owner · study". Only ids and labels travel; PGNs are requested one at a time by the [`MovePathPicker`](/components/platform/sections/teacher/classes/class-block-editor/move-path-picker) when a preview is needed, so the page does not carry every game's moves.

## Props

| Prop       | Type                       | Required | Meaning                                                                                    |
| ---------- | -------------------------- | -------- | ------------------------------------------------------------------------------------------ |
| `groups`   | `ReferenceableGameGroup[]` | yes      | `{ ownerLabel, studyName, studyId, isOwn, games: { id, label }[] }[]`. Empty shows a hint. |
| `value`    | `string`                   | yes      | The selected `gameId`.                                                                     |
| `onChange` | `(gameId: string) => void` | yes      |                                                                                            |

## Behaviour

A controlled `<select name="gameId" required>` with an empty placeholder option. Client only because the parent needs the value to decide whether to show the move-path picker.

## Markup & styling

No stylesheet: the field look comes from [`FormField`](/components/platform/shared/form-field).

## Usage

From `components/platform/sections/teacher/classes/class-block-editor/block-form.comp.tsx`:

```tsx
import { GameSelector } from "./game-selector.comp";

<GameSelector groups={options.games} value={gameId} onChange={setGameId} />;
```
