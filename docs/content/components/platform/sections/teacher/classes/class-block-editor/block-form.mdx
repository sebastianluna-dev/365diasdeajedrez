## Purpose

Not a form since 2026-10-15: the fields only, inside the popup's `PlatformForm`. For a game, «Transcribir» (the board) and «De un estudio» (a game of the teacher's or of an assigned student's) are mutually exclusive cards; in a group class a student's game warns «Los 4 alumnos de la clase verán esta partida de Mateo Ríos.». The lesson is cited by id, and its viewer under the field is the check.

## Props

| Prop                | Type                         | Required | Meaning                                                              |
| ------------------- | ---------------------------- | -------- | -------------------------------------------------------------------- |
| `kind`              | `ClassBlockKindCode`         | yes      | Which fields to draw.                                                |
| `options`           | `BlockFormOptions`           | yes      | `{ games: ReferenceableGameGroup[] }`.                               |
| `block`             | `Partial<TeacherClassBlock>` | no       | The block being edited, or the preset of a new one.                  |
| `values`, `errors`  | `Record<string, …>`          | no       | What was sent before the server refused, and what it said, by field. |
| `groupSize`         | `number`                     | no       |                                                                      |
| `fetchReferencePgn` | `FetchReferencePgn`          | yes      | For the position picker.                                             |
