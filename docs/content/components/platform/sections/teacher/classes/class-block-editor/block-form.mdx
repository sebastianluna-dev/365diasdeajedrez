## Purpose

One form per block, whatever its kind; the kind decides which fields render. State here is interface only (which reference is chosen, which position is marked); saving is always the bound server action, which revalidates the fields on its own.

For a **game** block, transcribing on the [`AnalysisBoard`](/components/chess/analysis-board/analysis-board) is the main path: the game lives in the block, not in a study, and the board brings its own "Pegar un PGN" box. Discussing a game a student played is the second route, folded into a `<details>` because it is not the usual case; when that game belongs to one of the teacher's own studies, a link offers to annotate it on its own screen.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `action` | `(formData: FormData) => void` | yes | Server action already bound to the class (and the block, when editing). |
| `kind` | `ClassBlockKindCode` | yes | Which fields to render; sent as a hidden `kind` field. |
| `options` | `BlockFormOptions` | yes | `{ games: ReferenceableGameGroup[], positions: PositionOption[] }`. |
| `block` | `TeacherClassBlock` | no | Existing values when editing (or the game prefill). |
| `submitLabel` | `string` | yes | "Guardar bloque" / "Añadir bloque". |
| `onCancel` | `() => void` | no | Renders the cancel button. |

## Behaviour

| `kind` | Fields |
| --- | --- |
| `TEXT` | `text` textarea (max 10 000, "## " for subheadings). |
| `VIDEO` | `videoUrl` (`type="url"`, required). |
| `GAME_REF` | `AnalysisBoard name="pgn"` with the block's PGN; folded `GameSelector` for a student's game (`gameId`), plus "Anotar esta partida" when `annotatableStudyOf` finds it in an own study. |
| `LESSON_REF` | `LessonReferenceField` (`lessonId`). |
| `POSITION_REF` | `PositionSelector` (`positionId`). |
| all | `caption` (max 200). |

- `supportsMovePath` is true for lessons and for game blocks that reference a student's game (a transcribed game is traversed on its own board and needs no second viewer). Then a hidden `movePath` input and the [`MovePathPicker`](/components/platform/sections/teacher/classes/class-block-editor/move-path-picker) render; a broken saved path shows a `role="alert"` warning explaining the student will see the block from the start.
- `gameId`, `lessonId`, `positionId` and `movePath` are controlled so the pickers can write them; everything else is uncontrolled with `defaultValue`.

## Usage

From `components/platform/sections/teacher/classes/class-block-editor/class-block-editor.comp.tsx`:

```tsx
import { BlockForm, type BlockFormOptions } from "./block-form.comp";

<BlockForm
  action={updateClassBlock.bind(null, classId, block.id)}
  kind={block.kind}
  options={options}
  block={block}
  submitLabel="Guardar bloque"
  onCancel={() => setEditingId(null)}
/>
```
