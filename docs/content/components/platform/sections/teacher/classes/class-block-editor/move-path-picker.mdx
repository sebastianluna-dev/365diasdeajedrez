## Purpose

A game or lesson block opens at a chosen move (`movePath`). To choose it, this component mounts the usual viewer on the referenced PGN and reads where the teacher navigated. There is no second viewer and no PGN editor: it is the same component the student will see, which is also why the viewer's `onPathChange` prop exists.

## Props

| Prop          | Type                     | Required | Meaning                                                                                  |
| ------------- | ------------------------ | -------- | ---------------------------------------------------------------------------------------- |
| `kind`        | `GAME_REF \| LESSON_REF` | yes      | What the id refers to.                                                                   |
| `referenceId` | `string`                 | yes      | Game or lesson id. Empty renders nothing.                                                |
| `value`       | `string`                 | yes      | The dotted path already saved, if any.                                                   |
| `onChange`    | `(path: string) => void` | yes      | Called with the current path on "Usar esta posición" and with `""` on "Quitar posición". |

## Behaviour

- An effect fetches the PGN with `fetchReferencePgn(kind, referenceId)` whenever either changes; the result is stored **together with the id it belongs to** and a `cancelled` flag drops late responses, so a slow answer is never painted over a reference the teacher already changed.
- Status texts: "Cargando el contenido…" while pending, an error line when the action returned `null`.
- The viewer is keyed by `referenceId` so changing the game resets it rather than dragging along the previous path; `initialPath` reopens at the saved value.
- The footer shows "Posición guardada: jugada n" (n from the path's segment count) or "Sin posición marcada".
