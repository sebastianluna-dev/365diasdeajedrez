## Behaviour

«Próximas · Por finalizar · 1 · Pasadas · Canceladas», each a link that changes the address (`?vista=&q=&pagina=`); «Por finalizar» rows carry «Finalizar», which opens the popup in place. «Pasadas» is a `PlatformTable` (Fecha, Clase, Alumnos, Asistencia, Material) above 640px and `ClassRow` cards below it. «Ver más» adds a page of twenty.
