## Purpose

"Mis clases" for a teacher. The status filter is a row of links (`?status=`), so it is shareable and the back button undoes it; the service applies it in the `where`. The result is then split into today, upcoming and past on the server, each in its own table with the same columns.

## Props

| Prop         | Type              | Required | Meaning                                                |
| ------------ | ----------------- | -------- | ------------------------------------------------------ |
| `statusCode` | `ClassStatusCode` | no       | Filter from `?status=`, already validated by the page. |

## Behaviour

- `STATUS_FILTERS` renders "Todas", "Programadas", "En vivo", "Terminadas", "Canceladas" as links with `aria-current` on the active one.
- The split uses the server's local midnight: `today` is within the current day, `upcoming` after it (reversed so the soonest is first), `past` before it. Being server time rather than the teacher's zone is a known approximation.
- `ClassesTable` renders title (linked), local date and time, duration, participants, attended, status tag; `minWidth` 780.
