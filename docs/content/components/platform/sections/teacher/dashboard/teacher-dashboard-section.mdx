## Purpose

What the teacher does first: enter the next class, finalize the ones that ended, prepare the week's. Nothing is created here: the dates, the students and the links are the staff's (the page says so under the greeting). The page draws the head («Hola, GM Profesor Demo. Hoy tienes 3 clases.») and, with the link open, the [`ClassJoinBar`](/components/platform/shared/class-join-bar) beside the page.

## Props

| Prop                     | Type               | Required | Meaning                                    |
| ------------------------ | ------------------ | -------- | ------------------------------------------ |
| `dashboard`              | `TeacherDashboard` | yes      | `next`, `awaitingClose`, `week`, the zone. |
| `notice`, `errorMessage` | `string`           | no       | What the address said, in words.           |
