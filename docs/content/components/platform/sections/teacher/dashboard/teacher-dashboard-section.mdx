## Purpose

What a teacher needs on arrival: what I have today, what is coming, and what I still have to document. No analytics. The "Pendientes de documentar" card is the useful one: classes already held whose attendance or summary is missing, each tagged with what is missing, so nothing stays half-recorded.

## Props

This component takes no props. The page opens with `requireTeacher()`; the service reads the teacher's classes and assignments.

## Behaviour

- Three metric cards: classes today, classes in the next seven days, active assigned students.
- Three lists (`today`, `upcoming`, `pending`) rendered by the local `ClassRow` (title linked, local date and time, duration, participant count, status tag). The pending list uses a date-only `LocalDateTime` and adds "Falta asistencia" / "Falta resumen" tags from `needsAttendance` and `needsSummary`.
- Empty texts are inline for the first two; the pending card uses an [`EmptyState`](/components/platform/shared/empty-state) ("Todo al día").
- Footer buttons link to new class, students and all classes.
