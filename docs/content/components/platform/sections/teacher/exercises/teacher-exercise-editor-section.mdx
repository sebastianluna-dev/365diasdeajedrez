|          |                                                                                                                                                              |

| Kind     | Server Component                                                                                                                                             |

## Props

| Prop                     | Type                    | Required | Meaning                                                                       |
| ------------------------ | ----------------------- | -------- | ----------------------------------------------------------------------------- |
| `editor`                 | `TeacherExerciseEditor` | yes      | The exercise, its catalogs, the teacher's games, the permissions and buttons. |
| `notice`, `errorMessage` | `string`                | no       |                                                                               |

## Behaviour

The editor is keyed by `editor.version` (the exercise's `updatedAt`): the save of a saved exercise redirects to its own page, and the board and the fields open again on what was stored instead of keeping the draft. Another teacher's exercise never reaches here: the page answers 404 when the service finds nothing.
