## Purpose

The teacher reads a student's game and, if it is worth discussing, takes it to class. "Usar en una clase" copies and modifies nothing: each button is a link to the block editor of one of the teacher's **scheduled** classes with `?gameId=` set, which preselects a game block there. It is on insert, in that class's action, that the server re-checks the assignment is still active.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `studentId` | `string` | yes | Breadcrumb link. |
| `studentName` | `string` | yes | Breadcrumb text. |
| `game` | `GameView` | yes | The game with `pgn`, players, record fields, `studyHref`, `studyName`, `sourceLabel`. |
| `scheduledClasses` | `TeacherClassSummary[]` | yes | Destinations of "Usar en una clase". Empty shows a hint with a link to create one. |

## Behaviour

None beyond rendering: breadcrumb (Mis alumnos / student / study), a title with both players and Elos, a subtitle joining event, site, date, ECO and result, the viewer with defaults (read-only, table list, no engine), the "Usar en una clase" card and the source line.
