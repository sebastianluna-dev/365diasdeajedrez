## Purpose

"Mis alumnos": one row per student currently assigned to the teacher, with the assignment date, the next class with this teacher and the last activity. The search is a GET form against the same route, so the filter lives in the URL and the service applies it in the `where`; there is no client state.

## Props

| Prop    | Type     | Required | Meaning                              |
| ------- | -------- | -------- | ------------------------------------ |
| `query` | `string` | no       | Search by name or email, from `?q=`. |

## Behaviour

Awaits the filtered list. Name cells link to the student's page. Dates go through [`LocalDateTime`](/components/platform/shared/local-datetime) without time. The empty label distinguishes "no match" from "no assigned students yet (staff assigns them)".

## Usage

From `app/(platform)/profesor/alumnos/page.tsx`:

```tsx
import { AssignedStudentsSection } from "@/components/platform/sections/teacher/students/assigned-students.section";

<AssignedStudentsSection query={q} />;
```
