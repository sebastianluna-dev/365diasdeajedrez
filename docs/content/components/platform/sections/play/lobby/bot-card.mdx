# `BotCard`

|            |                                                                                                                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/play/lobby/bot-card/bot-card.comp.tsx`                                                      |
| Kind       | Component without state, rendered by the client `BotGallery`                                                              |
| Stylesheet | `bot-card.comp.css` → block `.bot-card`                                                                                   |
| Story      | `bot-card.stories.tsx` (`platform/sections/play/lobby/BotCard`): with a record, without games, a game open, a team player |

## Props

| Prop     | Type                          | Required | Meaning                                                                     |
| -------- | ----------------------------- | -------- | --------------------------------------------------------------------------- |
| `bot`    | `BotView`                     | yes      | From `services/bots`.                                                       |
| `score`  | `BotScore \| null`            | yes      | The record against it: «2 G 1 P 0 T», «Sin partidas» or «Partida en curso». |
| `onPick` | `(event: MouseEvent) => void` | yes      | Opens the bot's popup from this card, so the focus comes back to it.        |
