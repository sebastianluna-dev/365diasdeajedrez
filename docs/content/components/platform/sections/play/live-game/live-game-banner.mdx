# `LiveGameBanner`

|            |                                                                                                          |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| File       | `components/platform/sections/play/live-game/live-game-banner/live-game-banner.comp.tsx`                 |
| Kind       | Server Component (no state; its `onReload` comes from the client section)                                |
| Stylesheet | `live-game-banner.comp.css` → block `.live-game-banner`                                                  |
| Story      | `live-game-banner.stories.tsx` (`platform/sections/play/live-game/LiveGameBanner`): stale, engine failed |

## Props

| Prop       | Type                         | Required | Meaning                                                                                                 |
| ---------- | ---------------------------- | -------- | ------------------------------------------------------------------------------------------------------- |
| `kind`     | `"stale" \| "engine-failed"` | yes      | «Esta partida cambió en otra pestaña.», or «El módulo dejó de responder. Lo que jugaste está guardado.» |
| `onReload` | `() => void`                 | yes      | «Recargar»: starts again from what the server has.                                                      |

## Markup & styling

**Elements:** `.live-game-banner__text`. `role="alert"`, in the new design system since 2026-10-25 (the game's page is): on `--platform-m3-warning-container` in its ink, `--md-sys-shape-corner-lg`, with «Recargar» as Material's text button.
