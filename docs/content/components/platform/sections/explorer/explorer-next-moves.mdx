## Purpose

The "Continuaciones" panel: what was played from this position and how often. Each row is a button that plays the move, which is the natural way to walk the tree of the games in the database. The percentages are over the total of continuations, so they add up to 100.

## Props

| Prop          | Type                    | Required | Meaning                                                                               |
| ------------- | ----------------------- | -------- | ------------------------------------------------------------------------------------- |
| `moves`       | `ExplorerNextMove[]`    | yes      | `{ uci, san, count, percentage }[]`, ordered by the service.                          |
| `onPlay`      | `(san: string) => void` | yes      | Plays the row's move.                                                                 |
| `isSearching` | `boolean`               | yes      | Chooses "Buscando…" over "Ninguna partida siguió desde aquí." when the list is empty. |

## Behaviour

None beyond rendering. The frequency bar is an `aria-hidden` span whose width is the percentage, placed behind the text so it reads at a glance without depending on the number.
