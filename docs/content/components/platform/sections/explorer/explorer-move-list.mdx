## Purpose

«Jugadas», at the top of the explorer's side column in the new design system (2026-10-23): a title as [`PlatformSideNav`](/components/platform/shared/platform-side-nav) writes its own, and the line in a white box (`--platform-m3-panel`, `--md-sys-shape-corner-lg`) as move pills that wrap. It uses `buildNotationRows`, the same row builder as the standalone board, so the notation comes out in Spanish piece letters, numbered and with piece glyphs exactly as in the rest of the platform.

## Props

| Prop       | Type                    | Required | Meaning                                 |
| ---------- | ----------------------- | -------- | --------------------------------------- |
| `sans`     | `string[]`              | yes      | The line.                               |
| `index`    | `number`                | yes      | Current ply; 0 is the initial position. |
| `onSelect` | `(ply: number) => void` | yes      | Click on a half-move.                   |

## Behaviour

None beyond rendering: an `<ol>` whose items are whole moves (`__row`: the number and both halves), so a line never breaks between a number and its move; each half-move is a button, the current one `_state_current` (a pill of `--platform-m3-primary`, as the viewer's notation) with `aria-current="true"`. The section is named by its `<h2>` through an id from `useId`. An empty line shows the hint «Mueve una pieza en el tablero para empezar a explorar», and that the search is by position, which the page's subtitle used to say. The box is capped at 220px and scrolls, so a long line does not push «Buscar en» out of the column. The piece glyph is a picture, so its own text is the piece's Spanish initial (`piece` from `buildNotationRows`), pushed out of its box and clipped: the eye sees the knight and a screen reader says "C f3".
