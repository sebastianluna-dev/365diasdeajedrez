# `ExplorerGames`

|            |                                                                        |
| ---------- | ---------------------------------------------------------------------- |
| File       | `components/platform/sections/explorer/explorer-games.comp.tsx`        |
| Kind       | Client Component                                                       |
| Stylesheet | `explorer-games.comp.css` → block `.explorer-games`                    |
| Used by    | [`GameExplorer`](/components/platform/sections/explorer/game-explorer) |
| Uses       | `ExplorerGame` from `services/game-explorer/game-explorer.types`       |

## Purpose

The "Partidas" panel. The list is capped by the service and the total is not: the heading counts every game found even when fewer are listed, and a footer line says "Se muestran las n más recientes de N".

Each game carries its **origin** (a student's study, a course, the teaching staff) because a continuation played by twenty students does not mean the same as seeing it in twenty master games from the course material. Games seen in one of the student's classes are also marked.

## Props

| Prop          | Type             | Required | Meaning                                                                                                               |
| ------------- | ---------------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| `games`       | `ExplorerGame[]` | yes      | `{ id, href?, white, black, whiteElo?, blackElo?, resultLabel, event?, playedAtLabel?, originLabel, seenInClass }[]`. |
| `totalGames`  | `number`         | yes      | The full count, beyond the capped list.                                                                               |
| `isSearching` | `boolean`        | yes      | Chooses "Buscando…" over the no-results message.                                                                      |

## Behaviour

None beyond rendering. A game without `href` (no screen the viewer could open it in) renders as a static row rather than a link to a 404.
