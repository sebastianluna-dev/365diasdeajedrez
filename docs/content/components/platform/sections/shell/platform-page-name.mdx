## Purpose

The Google-style header (2026-10-19) names the page — «Calendario», «Ejercicios», «Clases» — in the display font, and since 2026-10-22 (the new design system's header) with the tool's drawing before it (the `NavArt` of its tile in the tools menu, still) and **in the wordmark's place**: the shell hides the wordmark while a name is drawn (`:has(.platform-page-name)`), so the wordmark stays only where no tool names the page. The name is the label of the tool the page belongs to (`activeApp`, the longest address that starts the page's), so a deep page keeps its tool's name («Mis alumnos» on one student's page), and a page no tool leads to (a lesson) shows none. The one exception is the home page (2026-10-23, `pageNameOf`): `/inicio` is no tool's — no tile leads to it —, and the bar names it «Inicio» with the academy's mark (`HOME_PAGE`, `NavArt` `home`), as the owner's «CabeceraInicio» draws it; the menu still lights no tile there. «Herramientas» (`/herramientas`, 2026-10-25) is the other: the page of every tool, named with the nine squares (`TOOLS_PAGE`, `NavArt` `tools`); its child, the analysis board, keeps its own tool's name. Client, because it follows the address.
