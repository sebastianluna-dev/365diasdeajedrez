## Purpose

The streak where every page sees it, as the new design system's header draws it (2026-10-22): before the tools menu, Material's assist chip (`mdChip("assist")`) with the flame and «12 días». It only says; the day's goal and the rest are behind the avatar ([`PlatformUserMenu`](/components/platform/sections/shell/platform-user-menu)). A screen reader hears «Racha de estudio: 12 días» (the first words are visually hidden). Only a student's: the shell reads `getStudyStreak()` only for someone who neither teaches nor runs the academy.

## Props

| Prop   | Type     | Required | Meaning                                    |
| ------ | -------- | -------- | ------------------------------------------ |
| `days` | `number` | yes      | Days in a row studying (`getStudyStreak`). |

## Markup & styling

Block `.platform-streak-chip`, on Material's `chip chip-outlined`, which draws the pill. **Elements:** `__flame`, `__core`, `__hint`. **Breakpoints:** `(width < 640px)` hides it: on a phone the bar keeps the name and its two buttons.
