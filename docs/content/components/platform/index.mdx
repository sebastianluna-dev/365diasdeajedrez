# Platform components

`components/platform/` mirrors `app/(platform)`: `shared/` holds the primitives every section builds on, `sections/` holds one folder per area of the authenticated app. Every section is a Server Component unless marked client; sections receive their data from the page or call the service themselves, and the service resolves the user through the DAL, so no section checks identity. The behaviour behind these screens is described in [Student features](/platform/student) and [Teacher & staff panels](/platform/teacher-and-staff).

## Choosing a shared piece

| Need                                 | Use                                                                                                                                                          |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A list of records in a panel         | `PlatformTable` (filters through search params).                                                                                                             |
| A form control with a label          | `FormField`; groups of checkboxes in `FormFieldset`.                                                                                                         |
| One of a few, or several of a few    | `PlatformChoiceCards` (radio) or `PlatformCheckCards` (checkboxes), each option as a card with a line of explanation.                                        |
| A clarification that is not a rule   | `PlatformInfoTip`, an "i" with the text behind it; what is needed to fill the field in stays a visible hint.                                                 |
| Show the outcome of an action        | `PlatformNotice` from the page's message map.                                                                                                                |
| Nothing to show yet                  | `EmptyState` with a link to the action that creates the first item.                                                                                          |
| A date or time of a class            | `LocalDateTime` with the server-formatted fallback.                                                                                                          |
| A cover or photo                     | `ImageUpload` inside the form that will save the URL.                                                                                                        |
| A submit button with a pending state | [`SubmitButton`](/components/platform/shared/submit-button) (on the login screen, [`LoginSubmit`](/components/auth/sections/login/login-submit), its model). |
| Anything with a board                | see [Chess components](/components/chess#which-one-to-use).                                                                                                  |

A piece belongs in `shared/` when a second section of the platform needs it; until then it stays next to the section that uses it.
