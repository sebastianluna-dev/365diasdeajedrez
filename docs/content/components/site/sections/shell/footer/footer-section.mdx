## Purpose

The closing block of every public page except the chess clock. Its copy and links are fixed in code (programme, teacher, packages, FAQ, the clock, the contact email); only the WhatsApp number and its default message come from the `site-settings` Global, so the contact stays editable without turning the footer into a CMS block.

## Props

| Prop     | Type                | Required       | Meaning                                                                  |
| -------- | ------------------- | -------------- | ------------------------------------------------------------------------ |
| `accent` | `"orange" \| "red"` | no, `"orange"` | Logo accent and `.site-footer_accent_<accent>`; the blog passes `"red"`. |

## Behaviour

- Awaits the site settings and builds the WhatsApp URL with the number and the default message.
- Links to home anchors (`/#programa`, `/#maestro`, `/#planes`, `/#preguntas`) and to `/reloj-de-ajedrez`; the WhatsApp link opens in a new tab.

## Markup & styling

Block `.site-footer` (87 lines).

**Elements:** `.site-footer__wrap`, `.site-footer__grid`, `.site-footer__description`, `.site-footer__heading`, `.site-footer__links`, `.site-footer__link`, `.site-footer__text`, `.site-footer__bottom`

**Modifiers:** `.site-footer_accent_red`

**Tokens:** `--color-primary`, `--color-accent-red-on-dark`, `--foreground`

**Breakpoints:** `(max-width: 1023px)` collapses the three columns, opens the wrap to 88 px of top padding (the air the sections take from that width down) and reserves 200 px at the bottom for the sticky bar; `(max-width: 720px)` stacks the bottom row.
