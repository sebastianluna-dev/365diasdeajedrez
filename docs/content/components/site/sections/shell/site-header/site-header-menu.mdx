## Purpose

The narrow screens' version of the bar. It holds the open state, which is the only thing of the header that needs the browser; the header itself stays on the server and passes it data (the links, the login and the WhatsApp link it already built).

## Props

| Prop         | Type            | Required | Meaning                                         |
| ------------ | --------------- | -------- | ----------------------------------------------- |
| `links`      | `SiteNavLink[]` | yes      | The same links as the bar.                      |
| `loginLabel` | `string`        | yes      | «Iniciar sesión».                               |
| `loginHref`  | `string`        | yes      | `LOGIN_PATH`.                                   |
| `cta`        | `string`        | yes      | The main button's words.                        |
| `ctaHref`    | `string`        | yes      | The WhatsApp link, already built by the header. |

## Behaviour

- The toggle is `aria-expanded` and `aria-controls` the panel; its name says what it does («Abrir el menú», «Cerrar el menú»).
- The panel enters in 160 ms (`ease-out`) and leaves in 120 (`ease-in`): `useLingering` keeps it mounted with `_state_closing` while it goes. Under reduced motion it appears and disappears at once.
- Escape closes it and gives the focus back to the toggle; following any of its links closes it.
