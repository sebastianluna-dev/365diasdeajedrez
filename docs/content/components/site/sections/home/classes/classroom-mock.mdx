## Purpose

The canvas's «room»: a Philidor rook ending on the shared board, the student whose turn it is, the moves with the current one lit, the teacher's tools, the videos, the captions and the controls of the call. The classroom is not built, so nothing here can be pressed: the whole mock is one `role="img"` named by `room.label` («Así será el aula dentro de la plataforma, próximamente»), its keys are spans and its icons are Font Awesome's (Classic Solid inside the round keys).

| Prop   | Type                      | Required | Meaning                        |
| ------ | ------------------------- | -------- | ------------------------------ |
| `room` | `HomeClassesCopy["room"]` | yes      | Everything the picture writes. |
