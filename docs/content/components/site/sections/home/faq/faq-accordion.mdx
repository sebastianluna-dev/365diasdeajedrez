## Purpose

The section's only state: which question is open (the first, on load; none after closing it). Each question is an `h3` holding a `button` with `aria-expanded` and `aria-controls` its answer, which is `hidden` while closed; the open one is lit with the canvas and its round icon turns from the plus to the blue cross.

## Props

| Prop        | Type                   | Required | Meaning              |
| ----------- | ---------------------- | -------- | -------------------- |
| `questions` | `FaqQuestionContent[]` | yes      | The CMS's questions. |
