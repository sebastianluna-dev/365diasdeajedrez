# `FaqAccordionItem`

| | |
| --- | --- |

| Composes | `PlusIcon` from `components/icons/` |
| Uses | `FaqQuestionContent` from `services/home/home.types` |

## Purpose

Each question toggles on its own; there is no "only one open" rule, so the state is local to the item and the section stays a Server Component.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `faq` | `FaqQuestionContent` | yes | `question`, `answer`. |

## Behaviour

- `open` state toggled by the `<button>`; `aria-expanded` follows it and the block gets `.faq-item_open`.
- The answer is always in the DOM inside `.faq-item__answer-wrap`; the wrap animates its grid rows / height through CSS, and the plus icon rotates into a cross.

## Markup & styling

Block `.faq-item` (57 lines).

**Modifiers:** `.faq-item_open`

**Tokens:** `--color-primary`

No media queries.

## Usage

From `components/site/sections/home/faq/faq.section.tsx`:

```tsx
import { FaqAccordionItem } from "./faq-accordion-item.comp";

{content.questions.map((faq) => (
  <FaqAccordionItem key={faq.question} faq={faq} />
))}
```
