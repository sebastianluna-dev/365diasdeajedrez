## Purpose

Who teaches. Two blocks inside one `<section id="maestro">`: the profile (photo, stats, ratings, CTA to `/#planes`) and the annotated game, which is where the site's heaviest JavaScript would load. The board is [`ChessBoardLazy`](/components/chess/chess-board-lazy) because the game sits far below the fold: chessground and chessops are not downloaded until the reader scrolls near.

It shares the home slot with [`MentorsSection`](/components/site/sections/home/mentors/mentors-section); `config/site.config.ts` decides which one renders.

## Props

None.

## Behaviour

- Awaits `getTeacherData()`. The photo's `sizes` follows the CSS of `.teacher__media` (full width on mobile, 56 % on tablet, 480 px on desktop); without it the browser requested the photo at 3840 px.
- The stats render twice, once in the photo overlay and once in the content column with `.teacher__stats_variant_mobile`; CSS shows one per breakpoint.
- The Elo ratings go through [`EloTable`](/components/chess/elo-table) with four columns.
- The game passes `flipBoard`, `pgn` and `annotations` from the Global.
- Under 720 px the ratings and the whole game block are hidden by CSS. Both are still rendered on the server, which is deliberate: hiding the game with `display: none` leaves its placeholder without a box, so the observer inside [`ChessBoardLazy`](/components/chess/chess-board-lazy) never fires and chessground is not downloaded on a phone.

## Markup & styling

Block `.teacher` (225 lines) and block `.teacher-game` (49 lines), both imported by this file.

**Elements:** `.teacher__media`, `.teacher__photo`, `.teacher__photo-overlay`, `.teacher__stats`, `.teacher__content`, `.teacher__eyebrow`, `.teacher__name`, `.teacher__badge`, `.teacher__summary`, `.teacher__elo-label`, `.teacher__elo-table`, `.teacher__actions`; `.teacher-game__inner`, `.teacher-game__intro`, `.teacher-game__title`, `.teacher-game__text`

**Modifiers:** `.teacher__stats_variant_mobile`

**Tokens:** `--color-primary`, `--font-gramatika`

**Breakpoints:** `(max-width: 1023px)`, `(max-width: 720px)` — the phone drops `.teacher__elo-label`, `.teacher__elo-table` and the entire `.teacher-game` block, and `.teacher` grows its own vertical padding (88 px, the same as the neighbouring sections) because the game block was what gave the section air underneath.

**Other classes:** `.button.button_variant_primary`.
