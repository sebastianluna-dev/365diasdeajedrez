## Purpose

The grid. Separate from the section so the section's file holds only the heading and the read.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `mentors` | `MentorContent[]` | yes | One card per mentor, keyed by `slug`. |

## Behaviour

None.

## Markup & styling

Block `.mentor-list` (23 lines): a grid whose columns collapse under `(max-width: 1023px)`.

## Usage

From `components/site/sections/home/mentors/mentors.section.tsx`:

```tsx
import { MentorList } from "./mentor-list.comp";

<MentorList mentors={content.mentors} />
```
