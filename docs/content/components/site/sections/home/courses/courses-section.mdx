## Purpose

`#cursos`: «Cuatro cursos, _y así se ven por dentro_». The four courses are the platform's — the Sicilian, Fischer's 60 games, the rook endings and Kotov — with their real chapters and lesson counts copied as static data in `config/academy-home.config.ts` (the owner's decision: the site never reads the platform's database). When a course changes on the platform, its card is updated there by hand.
