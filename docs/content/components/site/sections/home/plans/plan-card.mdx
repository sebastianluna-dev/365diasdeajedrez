# `PlanCard`

## Purpose

The card both layouts share. A featured plan gets the `_featured` modifier and its button the `_variant_alt` one, so the highlighted package is a CMS flag, not a separate component.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `plan` | `PackagePlanContent` | yes | `name`, `price`, `previousPrice?`, `currency`, `period`, `description`, `features`, `ctaLabel`, `ctaUrl`, `featured`. |
| `className` | `string` | no | Appended to the block; the mobile wrapper passes `plans-mobile__card`. |

## Behaviour

- Prices are formatted with `toLocaleString("en-US")` and a `$` prefix.
- The discount row renders only when `previousPrice` is truthy.
- The CTA opens `ctaUrl` in a new tab.

**Other classes:** `.muted-text` from `globals.css` for the currency and period.

## Usage

From `components/site/sections/home/plans/plans-mobile.comp.tsx`:

```tsx
import { PlanCard } from "./plan-card.comp";

<PlanCard plan={activePlan} className="plans-mobile__card" />
```
