## Purpose

The only state of the programme section: which module is open. The list on the left is a column of buttons; the panel on the right shows the active module's badges ("Módulo 03 de 12"), title, description and topic list.

## Props

| Prop            | Type                     | Required | Meaning                                          |
| --------------- | ------------------------ | -------- | ------------------------------------------------ |
| `modules`       | `ProgramModuleContent[]` | yes      | Title, `durationLabel`, `description`, `topics`. |
| `topicsHeading` | `string`                 | yes      | Heading above the topic list, from the Global.   |

## Behaviour

- `activeIndex` state, default `0`; each list item's `onSelect` sets it.
- Module numbers are formatted with two digits in both the panel badge and the list.

## Markup & styling

Blocks `.program-list` and `.program-panel` (126 lines), wrapped in `.program__wrap`.

**Elements:** `.program-panel__badges`, `.program-panel__badge`, `.program-panel__title`, `.program-panel__description`, `.program-panel__subheading`, `.program-panel__topics`, `.program-panel__topic`

**Modifiers:** `.program-panel__badge_variant_primary`, `.program-panel__badge_variant_outline`

**Tokens:** `--color-primary`, `--color-normal-gray`, `--font-gramatika`

**Breakpoints:** `(max-width: 1023px)` turns the list into a horizontal row of numbers; `(max-width: 720px)`.

## Usage

From `components/site/sections/home/program/program.section.tsx`:

```tsx
import { ProgramInteractive } from "./program-interactive.comp";

<ProgramInteractive modules={content.modules} topicsHeading={content.topicsHeading} />;
```
