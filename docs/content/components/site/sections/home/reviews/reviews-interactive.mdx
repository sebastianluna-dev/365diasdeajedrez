## Purpose

Owns the active review. Every review's stat card and chat stay mounted in two stacks; each gets a `position` (`center`, `left`, `right`) relative to the active index so CSS can slide them, and `hidden` marks the inactive ones `aria-hidden`.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `reviews` | `ReviewContent[]` | yes | Keyed by `name`. |

## Behaviour

- `activeIndex` state. An effect sets an interval of `AUTO_ADVANCE_MS` (6000) that advances modulo the length; it depends on `activeIndex`, so clicking a dot restarts the six seconds.
- `getSlidePosition(index, active, total)` returns `center` for the active one, `right` for the next half of the ring and `left` for the rest.
- Dots call `setActiveIndex` with the label "Ver testimonio de …" plus the name.

## Markup & styling

## Usage
