# `ReviewsSection`

| | |
| --- | --- |
| File | `components/site/sections/home/reviews/reviews.section.tsx` |
| Kind | Server Component (async) |

| Composes | [`ReviewsInteractive`](/components/site/sections/home/reviews/reviews-interactive) |

## Purpose

The section wrapper: reads the Global, prints the title with a divider, and hands the reviews to the client carousel.

## Props

None.

## Behaviour

- Awaits `getReviewsData()`.
- `id="reviews"`.

## Markup & styling

Block `.reviews` (24 lines here; the carousel's stylesheet extends the same block), on top of the global `.section.section_theme_light`.

**Elements:** `.reviews__head`, `.reviews__title`, `.reviews__divider`

**Tokens:** `--font-gramatika`

**Other classes:** `.section__inner`.

## Usage

From `app/(frontend)/landing-page.tsx`:

```tsx
import { ReviewsSection } from "@/components/site/sections/home/reviews/reviews.section";

{sections.reviews && <ReviewsSection />}
```
