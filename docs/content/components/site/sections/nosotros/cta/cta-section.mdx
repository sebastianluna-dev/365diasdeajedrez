# `NosotrosCtaSection`

|            |                                                         |
| ---------- | ------------------------------------------------------- |
| File       | `components/site/sections/nosotros/cta/cta.section.tsx` |
| Kind       | Server Component                                        |
| Stylesheet | `cta.section.css` → block `.nosotros-cta`               |
| Used by    | `/nosotros`                                             |

## Purpose

A static card at the end of the about page pointing to `/#informacion`, the home page's «Pide información» (it pointed at the price packages, which the home page no longer has). It reads nothing and sits inside `<main>`.

## Props

None.

## Behaviour

None.

## Markup & styling

Block `.nosotros-cta` (44 lines).

**Elements:** `.nosotros-cta__card`, `.nosotros-cta__copy`, `.nosotros-cta__title`, `.nosotros-cta__text`

**Tokens:** `--font-gramatika`

**Breakpoints:** `(max-width: 720px)` stacks copy and button.

**Other classes:** `.button.button_variant_primary`.

## Usage

From `app/(frontend)/nosotros/page.tsx`:

```tsx
import { NosotrosCtaSection } from "@/components/site/sections/nosotros/cta/cta.section";

<NosotrosCtaSection />;
```
