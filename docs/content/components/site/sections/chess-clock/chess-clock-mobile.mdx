## Purpose

On a phone the two players sit across from each other, so the play screen is rotated and each half is a large tap zone. Choosing the time control happens on a separate first step; the "Configurar" action pauses the clock and returns to it.

## Props

| Prop      | Type      | Required   | Meaning                                            |
| --------- | --------- | ---------- | -------------------------------------------------- |
| `enabled` | `boolean` | no, `true` | Passed to the hook; only the visible variant runs. |

## Behaviour

- `step` state: `"select"` or `"play"`, mirrored as `.chess-clock-mobile_step_<step>`.
- Select step: title, the two dials (no readout), the time-control buttons and "Iniciar".
- Play step: two `<button>` tap zones ("Turno de las blancas" / "Turno de las negras") each holding a dial and a [`TimeRoller`](/components/site/sections/chess-clock/time-roller); knobs are decorative (`aria-hidden`) and reflect `knobPressed`; the middle row has reset, a link to `/` and settings.
- `handleConfig` calls `toggle()` if either side is active before going back to the select step.
