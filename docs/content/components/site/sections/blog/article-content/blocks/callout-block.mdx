## Purpose

A highlighted aside inside an article. The type becomes a BEM modifier so the three looks are pure CSS.

## Props

The block's fields: `title?: string`, `content: string`, `type: "info" | "tip" | "warning"`.

## Behaviour

None.

## Markup & styling

Block `.rich-callout` (34 lines): `.rich-callout__title`, `.rich-callout__content`; modifiers `.rich-callout_type_info`, `.rich-callout_type_tip`, `.rich-callout_type_warning`.

## Usage

From `components/site/sections/blog/article-content/rich-text-converters.tsx`:

```tsx
calloutBlock: ({ node }) => <CalloutBlockRenderer {...node.fields} />,
```
