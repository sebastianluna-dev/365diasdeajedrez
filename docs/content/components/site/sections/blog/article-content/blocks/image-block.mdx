# `ImageBlockRenderer`

|            |                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| File       | `components/site/sections/blog/article-content/blocks/image-block.comp.tsx`                                   |
| Kind       | Server Component                                                                                              |
| Stylesheet | `image-block.comp.css` → block `.rich-image-block`                                                            |
| Used by    | [`articleRichTextConverters`](/components/site/sections/blog/article-content/rich-text-converters)            |
| Uses       | `ImageBlock` from `@/payload-types`, `mapContentImage` from `services/shared/map-content-image`, `next/image` |

## Purpose

An image inside an article. The block's `image` relation is mapped through the same helper the services use, so the URL is the Cloudinary one and never a raw upload path.

## Props

The block's fields: `image` (media relation), `alt: string`, `caption?: string`.

## Behaviour

None. `sizes="(max-width: 1024px) 100vw, 780px"`.

## Markup & styling

Block `.rich-image-block` (22 lines): `.rich-image-block__frame`, `.rich-image-block__caption`.

## Usage

From `components/site/sections/blog/article-content/rich-text-converters.tsx`:

```tsx
blocks: {
  imageBlock: ({ node }) => <ImageBlockRenderer {...node.fields} />,
}
```
