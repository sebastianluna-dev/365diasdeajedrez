## Purpose

A playable game inside an article. Articles are long and the board is the heaviest JavaScript on the site, so the block uses the lazy board: nothing is downloaded until the reader scrolls near it.

## Props

The block's fields: `pgn: string`, `title?`, `players?`, `event?`, `date?`.

## Behaviour

- Builds the subtitle from `players`, `event` and the year of `date`, joined with " · ", skipping empties.
- The meta block renders only when there is a title or a subtitle.

## Markup & styling

Block `.rich-chess-game` (23 lines): `.rich-chess-game__meta`, `.rich-chess-game__title`, `.rich-chess-game__subtitle`.

## Usage

From `components/site/sections/blog/article-content/rich-text-converters.tsx`:

```tsx
chessGameBlock: ({ node }) => <ChessGameBlockRenderer {...node.fields} />,
```
