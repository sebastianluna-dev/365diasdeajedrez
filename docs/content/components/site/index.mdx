# Public site components

`components/site/` mirrors `app/(frontend)`: `shared/` holds the three pieces several sections or the layout need, `sections/` holds one folder per area of the public site. Every section is a Server Component unless marked client; sections read the CMS through the services in `services/home`, `services/articles`, `services/mentors` and `services/site-settings`, whose reads are cached per request and between requests (see [Caching](/architecture/caching-errors-logging)). The pages that compose these sections are described in [Pages](/public-site/pages) and the Globals they read in [CMS](/public-site/cms).

## Global classes

Several sections render classes that are not their own block: `.section`, `.section__inner`, `.section__head`, `.section__eyebrow`, `.section__title`, `.section__text` and `.button` with its `_variant_` and `_size_` modifiers, plus `.eyebrow`, `.card-meta` and `.muted-text`. They live in `app/(frontend)/globals.css`; the entries below list them under "Other classes" so the dependency is visible. Its icons come from `components/icons/`, like the platform's.
