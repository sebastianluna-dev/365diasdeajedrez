# `Logo`

| | |
| --- | --- |
| File | `components/site/shared/logo.comp.tsx` |
| Kind | Server Component |
| Stylesheet | `logo.comp.css` → block `.logo` |
| Used by | [`Header`](/components/site/sections/shell/header/header-section), [`Footer`](/components/site/sections/shell/footer/footer-section) |

## Purpose

The one place the wordmark is drawn. The header and the footer render it on different backgrounds and with different accents (orange on the home page, red on the blog), so the variation is expressed as two BEM modifiers rather than two components.

The drawing is the brand SVG (`viewBox="0 0 703 72"`) inlined in the component instead of an exported file: inline paths can be recoloured from CSS, while an `<img>` or a `next/image` would need one exported file per theme/accent combination. It is the same wordmark on every screen size — only the height changes.

## Props

| Prop | Type | Required | Meaning |
| --- | --- | --- | --- |
| `theme` | `"light" \| "dark"` | no, `"dark"` | Colour of the word and the marks; becomes `.logo_theme_<theme>`. |
| `accent` | `"orange" \| "red"` | no, `"orange"` | Colour of the "365"; becomes `.logo_accent_<accent>`. |

## Behaviour

None. A `next/link` to `/`. The SVG is `aria-hidden`, so the link's accessible name is the `aria-label` — "365 Días de Ajedrez".

## Markup & styling

Block `.logo` (58 lines).

**Elements:** `.logo__image` (the `<svg>`), `.logo__accent` (the "365"), `.logo__word` ("DíasDeAjedrez"), `.logo__marks` (the two squares)

**Modifiers:** `.logo_theme_light`, `.logo_theme_dark`, `.logo_accent_orange`, `.logo_accent_red`

**Tokens:** `--color-primary`, `--color-primary-on-light`, `--color-accent-red`, `--color-accent-red-on-dark`

**Breakpoints:** the height comes from `--site-logo-height`, which the stylesheet does not set: 20 px on desktop, 28 px under 1024 px and 24 px under 400 px. `(max-width: 1023px)` is only used here to drop the desktop offset.

How the colours reach the paths: `.logo__word` and `.logo__marks` are `fill: currentColor`, so they follow the `color` the theme modifier sets, and only `.logo__accent` is filled by the accent modifier. The height is the only measurement — the width follows from the `viewBox` — and it is read from the `--site-logo-height` token rather than written here, because the header is measured from it: the fixed menu toggle centres itself on the logo and `--site-header-height` is made of it (see [Styling › Tokens](/ui/styling#tokens)). The `<svg>` is `display: block` so no line box is added under it, which is what keeps that measurement exact. On desktop the block is nudged 4 px down (`position: relative`, which changes nothing in the layout) to sit on the optical centre of the header's pill; on mobile there is no pill and the offset is dropped.

## Usage

From `components/site/sections/shell/header/header.section.tsx`:

```tsx
import { Logo } from "@/components/site/shared/logo.comp";

{theme === "light" ? <Logo theme="light" accent="red" /> : <Logo theme="dark" accent="orange" />}
```
