## Purpose

What stays on the window over the map: «Salir del modo aventura» (a platform button, small, with its icon on the left; on a phone only the icon shows and the text stays for a screen reader), the zone the middle of the window is over (a kraft tag with its kind and name, announced politely as it changes) and «4/12 rivales · ★ 9 estrellas» (read to a screen reader as a sentence). Since 2026-10-25 the map is the whole window — the owner's «Modo aventura a pantalla completa: sin el header de la plataforma, el mapa es el juego»: its page carries `platform-page_chrome_none`, the shell hides its bar, and «Salir del modo aventura» is the way back to «Jugar» (which holds the shelf too, so «Cuadernos» went). The row is sticky at the top (`top: var(--map-bar, 70px)`, which `AdventureMap` measures from the bar, 0 when it is hidden) and takes no height, so the map's first pixel is under it; the row lets clicks through and only its tags catch them.

## Props

| Prop       | Type             | Required | Meaning                                                          |
| ---------- | ---------------- | -------- | ---------------------------------------------------------------- |
| `zone`     | `{ kind, name }` | yes      | The zone the window is over.                                     |
| `beaten`   | `number`         | yes      | Rivals beaten.                                                   |
| `total`    | `number`         | yes      | Rivals in the adventure.                                         |
| `stars`    | `number`         | yes      | Stars earned.                                                    |
| `isRising` | `boolean`        | no       | The victory has just been written down: the two figures come up. |
