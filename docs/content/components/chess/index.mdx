# Chess components

`components/chess/` is the React side of `lib/chess`: everything here is shared by the public site and the platform. One page per file; the narrative of how they fit together, which one to pick and the engine protocol is in [Board & game viewer](/chess/viewer) and [Stockfish, pieces & sounds](/chess/engine-and-assets).

## Root

| Page                                                                | Kind        | What it is                                                                                                                                                             |
| ------------------------------------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`ChessBoard`](/components/chess/chess-board)                       | client      | The chessground surface: standalone with a PGN (list and toolbar) or controlled with a position; interactive moves validated by chessops, accessible promotion dialog. |
| [`ChessBoardLazy`](/components/chess/chess-board-lazy)              | client      | `ChessBoard` behind `next/dynamic` with no SSR, mounted when it comes near the viewport; for boards below the fold.                                                    |
| [`StaticDiagram`](/components/chess/static-diagram)                 | server      | A position as a CSS grid with SVG pieces; no JavaScript.                                                                                                               |
| [`EloTable`](/components/chess/elo-table)                           | server      | Label/value grid for ratings and titles, with `EloTable.EloItem`.                                                                                                      |
| [`ChessMoveQualityIcon`](/components/chess/chess-move-quality-icon) | server-safe | The ten move-quality badge SVGs and `chessMoveQualityIconFor(quality)`.                                                                                                |

## `analysis-board/`

| Page                                                               | Kind   | What it is                                                                                                                                       |

| [`AnalysisBoard`](/components/chess/analysis-board/analysis-board) | client | The teacher's editable board: moves become the PGN of a hidden form input, with variations, comments, NAGs, arrows, paste and optional autosave. |

## Which one to use

| Need                                             | Use                                  |
| ------------------------------------------------ | ------------------------------------ |
| A game the student reads, navigates or annotates | `GameViewer`. Never a second viewer. |
| A teacher composing a game inside a form         | `AnalysisBoard`.                     |
| An illustration on a long public page            | `ChessBoardLazy`.                    |
| A board that _is_ the screen (explorer, trainer) | `ChessBoard` directly, controlled.   |
| A position that does not move                    | `StaticDiagram`.                     |
| An image of a position or a GIF of a game        | `board-export`, imported on demand.  |
