## Purpose

The "Módulo" block at the top of the viewer's notation panel: a switch, the current depth, and the three best continuations the engine proposes for the position on the board, each opening with its evaluation. Pointing at any move of a line shows the position it leads to on a small preview board, because reading an eight-move line in one's head is exactly what makes engine output hard to use.

It only renders. The viewer owns the engine through [`useEngine`](/components/chess/game-viewer/use-engine-hook) and passes the state in, because the same evaluation also drives the bar next to the board; two consumers of one datum call for keeping it in the component that contains both.

## Props

| Prop               | Type                          | Required             | Meaning                                                                                                                                                                          |
| ------------------ | ----------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fen`              | `string`                      | yes                  | The position on the board; lines are replayed from it.                                                                                                                           |
| `enabled`          | `boolean`                     | yes                  | Whether the engine is on. Off, only the head with the switch renders.                                                                                                            |
| `onToggle`         | `() => void`                  | yes                  | The switch.                                                                                                                                                                      |
| `state`            | `EngineState`                 | yes                  | `{ lines, info, loading, outcome, failed }` from `useEngine`.                                                                                                                    |
| `flipBoard`        | `boolean`                     | no · default `false` | The preview is looked at from the same side as the board next to it.                                                                                                             |
| `onExpandedChange` | `(expanded: boolean) => void` | no                   | Reports whether any line is expanded. The viewer needs it because the height this takes up is given up by the notation, and that accounting belongs to the card, not the engine. |
| `look`             | `"material"`                  | no                   | The new design system's card (2026-10-23, the analysis board; the viewer passes its own `look`). See below.                                                                      |

## Behaviour

- **One line open at a time.** Collapsed, the three lines fit one row each and are compared at a glance. Opening one closes the other, so what the block grows by is always one row and the notation knows how much to give up. `openLine` is derived as `enabled ? expanded : null`, so switching the engine off collapses everything without a reset.
- **Lines.** For each `EngineInfo`, `uciLineSteps(fen, pv.slice(0, 16))` replays up to sixteen moves and `engineLineTokens` numbers them; SAN is shown in Spanish. The first row carries `_rank_best`. The depth is shown once in the head, not per line, because the three are analysed together to the same depth.
- **Preview.** `onMouseEnter` on a move stores its FEN and last move; the preview board always hangs from the panel's edge (its position is not tied to the pointer) so the view does not jump while traversing a line, and `onMouseLeave` on the panel clears it. The preview is `aria-hidden`.
- **Messages.** `failed` → "No se pudo cargar el módulo en este navegador."; a finished position → "Jaque mate: no hay jugadas que analizar." or "Tablas por ahogado: no hay jugadas que analizar.", said at once, without waiting for the module, because the engine has no line to give there; no lines yet → "Cargando el módulo…" while the module is `loading`, and "Pensando…" once it has answered and is searching the position. The message keeps the rows' side padding, so its text starts where the first evaluation would.
- **The body's height is fixed, and counted in rows** (2026-10-05): three rows and the padding above and below them — `calc(3 * var(--engine-panel-row) + 2 * var(--platform-space-2))` —, plus one line of text when a continuation is expanded. Fixed because the block goes through «Cargando», «Pensando» and three lines within seconds and would otherwise move the game each time; counted in rows, in `em`, because the loose 102px it had (`--viewer-engine-body`, worked out when a row measured 26px) no longer held three rows of 15px text: the bottom padding and a few px of the third line were clipped, so the list had air above it and none below. The row's two cells are centred rather than set on the baseline — the arrow's button has no text, so by its baseline the row grew by the text's descender —, and an expanded row aligns them at the top, so the arrow stays beside the first of its two rows. Measured in the stories at 15, 16 and 24px, collapsed and expanded: 8px over the first line and 8px under the last.
- The switch is a button with `aria-pressed`; the expand buttons carry `aria-expanded`.
- **The material look** (`look="material"`, 2026-10-23, «M4» of the owner's canvas): an outlined card (`--platform-m3-container-high`, `--md-sys-shape-corner-lg`). The head is one `role="switch"` button — Material's track and thumb (the primary when on, the outline when off), «Módulo» in bold and «Encendido»/«Apagado» —, with the depth at the right. Each evaluation is a white pill of its own width at the head of its line, so the three line up. The lines have no arrows: one «Ver más jugadas» under them (`mdButton("text", "xs")`, `aria-expanded`) opens the three at once, one more row each, and reads «Ver menos jugadas» while they are open; switching the module off closes them. The preview board takes the material look too.

## Markup & styling

Block `.engine-panel` (405 lines). The lines are written on `--platform-bg`, a fill, so the move numbers are in `--platform-text-muted`: the faint grey is left to the switch's dot, which is not read.

**Elements:** `.engine-panel__head`, `.engine-panel__label`, `.engine-panel__depth`, `.engine-panel__toggle`, `.engine-panel__dot`, `.engine-panel__body`, `.engine-panel__lines`, `.engine-panel__row`, `.engine-panel__line`, `.engine-panel__score`, `.engine-panel__token`, `.engine-panel__move-number`, `.engine-panel__move`, `.engine-panel__more`, `.engine-panel__more-icon`, `.engine-panel__message`, `.engine-panel__preview`; in the material look `.engine-panel__switch`, `.engine-panel__track`, `.engine-panel__thumb`, `.engine-panel__name`, `.engine-panel__state`, `.engine-panel__all`

**Modifiers and states:** `.engine-panel_look_material` (the thumb's slide is off under `prefers-reduced-motion`), `.engine-panel__toggle_state_on`, `.engine-panel__body_state_expanded`, `.engine-panel__line_state_expanded`, `.engine-panel__more_state_expanded`, `.engine-panel__row_rank_best`

**Tokens:** own `--engine-panel-font-size`, `--engine-panel-line` (a line of a continuation, `1.5em`) and `--engine-panel-row` (that line and the row's padding), which the body's height is counted in; `--platform-accent-ink`, `--platform-accent-soft`, `--platform-bg`, `--platform-border`, `--platform-success-ink`, `--platform-success-soft`, `--platform-surface`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-faint`, `--platform-text-muted`, `--platform-text-subtle`, `--platform-track`

No media queries; the panel is as wide as the notation column.

## Usage

From `components/chess/game-viewer/game-viewer.comp.tsx`:

```tsx
import { EnginePanel } from "./engine-panel.comp";

{
  engine && (
    <EnginePanel
      fen={fen}
      enabled={engineOn}
      onToggle={() => {
        setEngineOn((on) => !on);
        setEngineExpanded(false);
      }}
      state={engineState}
      flipBoard={flipBoard}
      onExpandedChange={setEngineExpanded}
    />
  );
}
```
