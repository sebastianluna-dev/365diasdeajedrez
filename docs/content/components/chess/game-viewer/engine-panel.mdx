## Purpose

The "Módulo" block at the top of the viewer's notation panel: a switch, the current depth, and the three best continuations the engine proposes for the position on the board, each opening with its evaluation. Pointing at any move of a line shows the position it leads to on a small preview board, because reading an eight-move line in one's head is exactly what makes engine output hard to use.

It only renders. The viewer owns the engine through [`useEngine`](/components/chess/game-viewer/use-engine-hook) and passes the state in, because the same evaluation also drives the bar next to the board; two consumers of one datum call for keeping it in the component that contains both.

## Props

| Prop               | Type                          | Required             | Meaning                                                                                                                                                                          |
| ------------------ | ----------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fen`              | `string`                      | yes                  | The position on the board; lines are replayed from it.                                                                                                                           |
| `enabled`          | `boolean`                     | yes                  | Whether the engine is on. Off, only the head with the switch renders.                                                                                                            |
| `onToggle`         | `() => void`                  | yes                  | The switch.                                                                                                                                                                      |
| `state`            | `EngineState`                 | yes                  | `{ lines, info, loading, failed }` from `useEngine`.                                                                                                                             |
| `flipBoard`        | `boolean`                     | no · default `false` | The preview is looked at from the same side as the board next to it.                                                                                                             |
| `onExpandedChange` | `(expanded: boolean) => void` | no                   | Reports whether any line is expanded. The viewer needs it because the height this takes up is given up by the notation, and that accounting belongs to the card, not the engine. |

## Behaviour

- **One line open at a time.** Collapsed, the three lines fit one row each and are compared at a glance. Opening one closes the other, so what the block grows by is always one row and the notation knows how much to give up. `openLine` is derived as `enabled ? expanded : null`, so switching the engine off collapses everything without a reset.
- **Lines.** For each `EngineInfo`, `uciLineSteps(fen, pv.slice(0, 16))` replays up to sixteen moves and `engineLineTokens` numbers them; SAN is shown in Spanish. The first row carries `_rank_best`. The depth is shown once in the head, not per line, because the three are analysed together to the same depth.
- **Preview.** `onMouseEnter` on a move stores its FEN and last move; the preview board always hangs from the panel's edge (its position is not tied to the pointer) so the view does not jump while traversing a line, and `onMouseLeave` on the panel clears it. The preview is `aria-hidden`.
- **Messages.** `failed` → "No se pudo cargar el módulo en este navegador."; no lines yet → "Cargando el módulo…" while `loading`, otherwise "Pensando…".
- The switch is a button with `aria-pressed`; the expand buttons carry `aria-expanded`.

## Usage

From `components/chess/game-viewer/game-viewer.comp.tsx`:

```tsx
import { EnginePanel } from "./engine-panel.comp";

{
  engine && (
    <EnginePanel
      fen={fen}
      enabled={engineOn}
      onToggle={() => {
        setEngineOn((on) => !on);
        setEngineExpanded(false);
      }}
      state={engineState}
      flipBoard={flipBoard}
      onExpandedChange={setEngineExpanded}
    />
  );
}
```
