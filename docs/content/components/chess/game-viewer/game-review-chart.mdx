## Purpose

The curve that shows who was better and when. The vertical axis is **not** pawns but win probability: between +7 and +9 there is nothing to tell, while between +0.2 and +1 the game is decided, and a linear pawn scale would flatten exactly the part that matters. It is the same `winPercent` curve accuracy is computed with, so the chart and the numbers next to it tell one story.

Pointing at the chart moves the board. That is what anyone tries the moment they see a chart like this, so clicking and dragging both select the nearest ply.

## Props

| Prop          | Type                    | Required | Meaning                                                                                                    |
| ------------- | ----------------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| `evaluations` | `MoveEvaluation[]`      | yes      | One per main-line position; the first is the starting position.                                            |
| `review`      | `GameReview`            | yes      | The computed review; only `phases.middlegame` and `phases.endgame` (ply indexes) are read, for the labels. |
| `currentPly`  | `number`                | yes      | The ply the board is at, for the cursor. 0 is the initial position.                                        |
| `onSelectPly` | `(ply: number) => void` | yes      | Takes the board to the ply pointed at on the chart.                                                        |

## Behaviour

- The SVG has a fixed `viewBox` of 404×140 and `preserveAspectRatio="none"`, so it stretches to the container's width while the ratio of the drawing stays legible. Points are memoised from the evaluations: `x` is the ply's share of the width, `y` is the middle minus the advantage (−1…1) times an amplitude of 62.
- The filled area is drawn twice from the same path, clipped above and below the axis: what sticks out past the middle belongs to whoever is winning, and is painted in their colour. A line traces the curve on top, and a vertical cursor line marks `currentPly`.
- `onPointerDown` and, while a button is held, `onPointerMove` convert the pointer's horizontal position into the nearest ply and call `onSelectPly`, clamped to the range.
- The three phase labels under the plot get their widths from the review's phase boundaries as percentages of the game's length, so they line up with the curve.
- The SVG is `role="img"` with a Spanish label; it is not keyboard-navigable, because the board's own navigation already is.

## Usage

From `components/chess/game-viewer/game-review.comp.tsx`:

```tsx
import { GameReviewChart } from "./game-review-chart.comp";

<GameReviewChart
  evaluations={evaluations}
  review={review}
  currentPly={currentPly}
  onSelectPly={(ply) => onSelectPath(paths[ply] ?? "")}
/>;
```
