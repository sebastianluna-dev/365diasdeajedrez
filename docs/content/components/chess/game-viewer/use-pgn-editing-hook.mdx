## Purpose

Editing the game **from the viewer**: adding moves, drawing arrows, promoting a variation, copying a line and deleting from a move on. The comment and the quality signs are not here: they are written in the panel under the board, and the move menu only leads to it (see `useToolsTab` in [`GameTools`](/components/chess/game-viewer/game-tools)).

Each operation reparses the PGN, mutates the chessops `Game` and returns the new PGN upwards. It reparses more than strictly needed, but that leaves **one** source of truth (the PGN the viewer renders) instead of a parallel mutable game that could drift out of sync with it, and a game fits easily within that budget. The [`AnalysisBoard`](/components/chess/analysis-board/analysis-board) made the other choice (a long-lived game in a ref) because it owns its PGN; the viewer does not.

## API

### `usePgnEditing`

```ts
export function usePgnEditing({ pgn, onPgnChange, onPathChange }: UsePgnEditingOptions): PgnEditing;
```

| Option         | Type                     | Meaning                                                                 |
| -------------- | ------------------------ | ----------------------------------------------------------------------- |
| `pgn`          | `string`                 | The current PGN: every change starts from it, never from a stored copy. |
| `onPgnChange`  | `(pgn: string) => void`  | Receives the serialised game after a successful change.                 |
| `onPathChange` | `(path: string) => void` | Where to leave the selected move after each change.                     |

### `PgnEditing`

| Method                       | Leaves the viewer at                                                                                                                            |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `addMoveAt(path, san)`       | The new move. Nothing happens for an illegal SAN.                                                                                               |
| `updateShapes(path, shapes)` | The same move.                                                                                                                                  |
| `promoteOneStepAt(path)`     | The same move, wherever its reindexed path now is.                                                                                              |
| `promoteToMainAt(path)`      | The same move, wherever it now is.                                                                                                              |
| `deleteAt(path)`             | The parent: the move no longer exists.                                                                                                          |
| `copyVariation(path)`        | Unchanged; writes the variation's PGN to the clipboard, silently ignoring a permission error (the full PGN is still at hand in the game tools). |

## Behaviour

- `edit(mutate)` is the single pipeline: `parseEditableGame(pgn)`, call `mutate(game)`, and if it returns a path, `onPgnChange(serializeGame(game))` then `onPathChange(path)`. A `null` from `mutate` (illegal move, broken path, unreadable PGN) touches nothing.
- `keepingPlace(path, mutate)` wraps promotions: it grabs the node's **reference** before mutating, because promoting reindexes the siblings and the original dotted path may then point at a different move, and asks `pathOfNode` where the node ended up (falling back to the parent).
- The returned object is memoised on `pgn` and the two callbacks; the viewer keeps its callbacks stable through refs, so this memo rarely invalidates for reasons other than an actual edit.

## Usage

From `components/chess/game-viewer/game-viewer.comp.tsx`:

```tsx
import { usePgnEditing } from "./use-pgn-editing.hook";

const editing = usePgnEditing({ pgn, onPgnChange: publishPgn, onPathChange: setCurrentPath });
// …
<ChessBoard … onMove={(san) => editing.addMoveAt(currentPath, san)} onShapesChange={(shapes) => editing.updateShapes(currentPath, shapes)} />
```
