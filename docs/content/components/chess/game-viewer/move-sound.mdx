# `move-sound`

Exports `playMoveSound` and the `MoveSoundKind` type.

|            |                                                           |
| ---------- | --------------------------------------------------------- |
| File       | `components/chess/game-viewer/move-sound.ts`              |
| Kind       | Module (plain TypeScript, browser only, `"use client"`)   |
| Stylesheet | none                                                      |
| Used by    | [`GameViewer`](/components/chess/game-viewer/game-viewer) |
| Uses       | `public/sounds/move.wav`, `public/sounds/capture.wav`     |

## Purpose

Board sounds. There are only two, move and capture, synthesised by `scripts/make-board-sounds.ts` (`npm run sounds:make`, a strike over a bank of resonators tuned to sound like wood) so the repository carries no third-party audio; check does **not** sound because it is a state of the position, not a gesture on the board.

The files load lazily and only when a sound is first needed: a page can hold several viewers that may never sound, and there is no point requesting the audio in every one of them.

## API

### `playMoveSound`

```ts
export function playMoveSound(kind: "move" | "capture"): void;
```

Plays the sound once at 60 % volume. Safe to call on the server (returns without doing anything when `window` is undefined) and safe before any user gesture: the browser rejects the `play()` promise, which is expected and swallowed.

## Behaviour

- One `HTMLAudioElement` per kind is created on first use with `preload = "auto"` and kept in a module cache.
- Every playback uses a **clone** of the cached element. Navigating quickly with the arrow keys fires several sounds in a row, and reusing one element would cut the previous note off mid-play.
- The viewer decides **when**: on position change (never on mount) and only if the sound preference is on; it picks `capture` when the piece count on the board dropped.

## Markup & styling

Nothing rendered.

## Usage

From `components/chess/game-viewer/game-viewer.comp.tsx`:

```tsx
import { playMoveSound } from "./move-sound";

useEffect(() => {
  const previous = previousFenRef.current;
  previousFenRef.current = fen;
  if (previous === null || previous === fen || !fen) return;
  if (!preferences.sound) return;
  playMoveSound(pieceCount(fen) < pieceCount(previous) ? "capture" : "move");
}, [fen, preferences.sound]);
```
