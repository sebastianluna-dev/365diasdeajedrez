## Purpose

The viewer receives who plays as data — `players: { white: PlayerInfo; black: PlayerInfo }` — and draws the strips itself, because only it knows which side is on top once the board is flipped. This is the strip: a fragment of pieces the viewer's `.game-viewer__player` lays out in a row.

It is drawn as Lichess draws it (2026-10-03, chosen among five options): a band 26px tall — it was 42 —, in the text's `xs` size on white, opening with the **point the player took** once the game has ended — `1`, `0` or `½`, the winner's in the success ink, set apart by a hairline — and with the Elo beside the name instead of at the far end. A screen reader hears what the figure means («Ganó», «Perdió», «Tablas»). There is no chip of the pieces' colour any more: who has White is read from the board's own coordinates.

## Markup & styling

No root of its own: the pieces sit directly in the viewer's `.game-viewer__player`, which lays them out and sets the size. Everything is in `em` for that reason: in full screen the viewer grows with the screen, and only the proportion between the name, the Elo and what accompanies them is kept.

**Elements:** `.player-strip__turn` (`_state_on`), `.player-strip__who`, `.player-strip__line`, `.player-strip__status`, `.player-strip__ending` (`_kind_win`, `_kind_loss`, `_kind_draw`), `.player-strip__ending-icon`, `.player-strip__clock` (`_state_running`), `.player-strip__score` (`_outcome_win`, `_outcome_loss`, `_outcome_draw`; the point, with a hairline after it), `.player-strip__sr` (what the point means, for a screen reader only), `.player-strip__country`, `.player-strip__flag`, `.player-strip__title`, `.player-strip__name`, `.player-strip__elo`

**Tokens:** `--platform-accent`, `--platform-accent-ink`, `--platform-border-strong`, `--platform-danger`, `--platform-font-mono`, `--platform-success-ink`, `--platform-surface`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted`, `--platform-type-2xs`, `--platform-space-*`. The band itself is the viewer's, on `--platform-surface` like the notation panel (it was tried on a grey fill for a few hours on 2026-10-03; the owner kept it white).

## Usage

From `components/chess/game-viewer/game-viewer.comp.tsx`:

```tsx
{
  flipBoard ? (
    <PlayerStrip {...players.white} outcome={outcomes?.white} />
  ) : (
    <PlayerStrip {...players.black} outcome={outcomes?.black} />
  );
}
```
