## Purpose

G6 (2026-10-08) replaced the result card over the board (F1): who won is said in the player strips, and what comes next goes **under the board**, where it covers nothing and the game stays there to be gone through. The viewer draws it from `play.over`, data the game's page gives it, with any interaction.

- **The way on** (`onwards`, the one main action): a link in `_variant_accent` with the arrow on its right, because it leads somewhere — «Volver al mapa» after a game of an adventure, «Ir a Jugar» after an old free game; not drawn when there is nowhere to go (the adventure switched off). The page puts `?victoria=<order>` in the map's address only when the game is the first win of the person over that rival, so the map plays its victory once. «Revancha» and «Otro rival» went on 2026-10-25, with free play: every game against a bot is an encounter of the adventure, and the story goes on on its map.
- **Analizar**: the viewer's own review, the «Evaluación» tab of [`GameTools`](/components/chess/game-viewer/game-tools), brought into view (`useToolsTab().reveal`). Only drawn when the viewer has `tools`.
- **Tablero de análisis**: only while that board is switched on (`analysisBoardHref` not null).
- **Guardar en un estudio**: the page opens its popup.
- The [`BotScoreboard`](/components/chess/bot-scoreboard) against that rival, counting the game just finished.

## Props

| Prop                | Type                          | Required | Meaning                                                                                   |
| ------------------- | ----------------------------- | -------- | ----------------------------------------------------------------------------------------- |
| `scoreboard`        | `BotScoreboardProps \| null`  | yes      | The record against this rival.                                                            |
| `onwards`           | `{ href, label } \| null`     | yes      | The one main action, «Volver al mapa» or «Ir a Jugar»; null where there is nowhere to go. |
| `analysisBoardHref` | `string \| null`              | yes      | The game on the analysis board; null while `ANALYSIS_BOARD_ENABLED` is off.               |
| `onSave`            | `(event: MouseEvent) => void` | yes      | Opens the page's «Guardar en un estudio» popup.                                           |
| `onAnalyse`         | `() => void`                  | no       | Given by the viewer when it has tools; without it «Analizar» is not drawn.                |
