## Purpose

The game seen as a whole: a chart of the advantage over the course of the game, each side's accuracy, and how many inaccuracies, mistakes and blunders they made. It is the studies' equivalent of a "game report".

There is no "already evaluated" state. The evaluation lives **inside the PGN**, one `[%eval]` per main-line move: if the values are there, the chart renders; if not, a "Generar evaluación" button offers to compute them. That makes the review survive a page reload, travel with the game when it is exported and show up in the [`MoveTable`](/components/chess/game-viewer/move-table) as a number next to each move.

| `canEdit`      | `boolean`                | yes      | Without write permission the review still runs and renders, but the PGN is not saved, and the footer says so ("no se guarda: la partida no es tuya"). |
| `white`        | `string`                 | yes      | White's name for the player card.                                                                                                                     |
| `black`        | `string`                 | yes      | Black's name for the player card.                                                                                                                     |
| `currentPath`  | `string`                 | yes      | Dotted path of the board's move, for the chart cursor.                                                                                                |
| `onSelectPath` | `(path: string) => void` | yes      | The chart moves the board: clicking or dragging on a ply selects its path.                                                                            |
| `onPgnChange`  | `(pgn: string) => void`  | yes      | Receives the PGN with the evaluations written in.                                                                                                     |

## Behaviour

**Three states, derived from the PGN and the runner.**

1. `runner.state === "running"`: a progress bar with "Posición n de N", the percentage and a "Cancelar" button.
2. No complete set of evaluations (`mainlineEvaluations` returns `null` when any main-line node lacks one, because half a chart would mislead): the intro text, the move count, the depth and the start button; disabled when the game has no moves. A failed worker shows a `role="alert"` message.
3. Evaluations present: the [`GameReviewChart`](/components/chess/game-viewer/game-review-chart), two `PlayerCard`s (accuracy, the three error counts with coloured dots, average loss in centipawns) and a strip with the depth, whether it is saved, and "Volver a evaluar".

**Computing.** `runner.start(pgn)` hands the PGN to [`useGameReview`](/components/chess/game-viewer/use-game-review-hook), which evaluates every main-line position in its own worker. When it finishes, `onFinished` reparses the PGN **as it is now**, recomputes the main-line paths and writes one `setEvaluation` per path; if the game was edited during the run, leftover results are dropped instead of written onto the wrong moves. The new PGN goes up through `onPgnChange`; the section's autosave takes it from there.

**Reading.** `reviewGame(mainlinePositions(tree))` in `lib/chess/game-review` turns the evaluations into accuracy, error counts and the phase boundaries the chart draws. `currentPly` is the index of `currentPath` among the main-line paths (0 when the board is on a variation).

## Usage

From `components/chess/game-viewer/game-tools.comp.tsx`:

```tsx
import { GameReview } from "@/components/chess/game-viewer/game-review.comp";

<GameReview
  pgn={pgn}
  canEdit={canEdit}
  white={white}
  black={black}
  currentPath={currentPath}
  onSelectPath={onSelectPath}
  onPgnChange={onPgnChange}
/>;
```
