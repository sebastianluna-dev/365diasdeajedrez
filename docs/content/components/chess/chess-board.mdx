## Purpose

The one place where chessground is instantiated. Every board in the app, on the public site or in the platform, is this component; nothing else imports `@lichess-org/chessground`, so the board's configuration, its piece set and its interaction rules are defined once.

It works in two modes, decided by which prop is given:

- **Standalone** (`pgn`): the component replays the PGN with `replayGame`, owns the current ply and renders the board with a notation column and a toolbar (flip, autoplay, first, previous, next, last). This is the board of the home page's annotated game, the mentor page and the blog's game block.
- **Controlled** (`position`): the parent owns the position and the navigation; only the surface renders, with no list and no toolbar. This is how the [`GameViewer`](/components/chess/game-viewer/game-viewer), the explorer and the trainer use it.

Interactive moves are validated by chessops before they are reported: the board never emits an illegal SAN. Promotion, which base chessground does not handle, is resolved with a modal dialog of its own.

## Props

| `position`       | `ChessBoardControlledPosition`           | no                   | Controlled mode: `{ fen, lastMove?, check?, shapes? }`. | `flipBoard`      | `boolean`                                | no · default `false` | Black at the bottom. In standalone mode the toolbar's flip button toggles on top of it.                                                                                                                                                                                                  |
| `annotations`    | `MoveAnnotations`                        | no                   | Per-move quality and glyphs for the standalone notation column (see `lib/chess/types`).                                                                                                                                                                                                  |
| `interactive`    | `boolean`                                | no · default `false` | Lets the user drag or click legal moves, computed by `legalDests`.                                                                                                                                                                                                                       |
| `onMove`         | `(san: string, fromFen: string) => void` | no                   | Called after a legal interactive move with its SAN and the FEN it was played from. The board resets itself to `fromFen` afterwards: the parent decides what the new position is.                                                                                                         |
| `editableShapes` | `boolean`                                | no · default `false` | Lets the user draw arrows and circles with the right mouse button. It also changes where the shapes live: without it they are chessground `autoShapes`, painted but untouchable; with it they are the user's shapes, the only ones that can be edited. Only the analysis editor sets it. |
| `onShapesChange` | `(shapes: DrawShape[]) => void`          | no                   | Called on release after drawing, with the full set of user shapes.                                                                                                                                                                                                                       |

`ChessBoardControlledPosition` and `ChessBoardProps` are exported so wrappers such as `ChessBoardLazy` and the explorer can type their own props against them.

## Behaviour

**Chessground lifecycle.** The API is created once per mode in an effect keyed on `interactive` and `editableShapes`, and destroyed on cleanup. A second effect pushes the current position into it on every change: FEN, last move, orientation, turn colour and check. In interactive mode that same effect installs `movable` with the legal destinations of the side to move and an `after` handler that resolves the SAN.

**Promotion.** When `isPromotionMove` says the drop is a pawn reaching the last rank, the move is held in `pendingPromotion` and an overlay with `role="dialog"` and `aria-modal` opens over the board. The first piece receives focus, Escape cancels (and restores the FEN), and confirming calls `onMove` with the SAN including the chosen piece. Labels are Spanish ("Dama", "Torre", "Alfil", "Caballo").

**Standalone navigation.** `ply` is clamped to the replayed positions. Autoplay advances one move every 900 ms and stops at the end; changing the PGN stops it. The arrow keys move through the game only while the board is at least fully in the viewport or has been clicked, tracked with an `IntersectionObserver` and a click flag, so two boards on one page do not both react. In controlled mode the keyboard handler is not installed at all: navigation belongs to the parent.

**Pieces slide, unless less motion was asked for.** chessground animates a move over 200 ms; under `prefers-reduced-motion: reduce` the animation is switched off when the board is created and the piece lands on its square, with the last move marked as always.

**The current move stays in view.** When the ply changes, its cell in the notation is scrolled into view (`block: "nearest"`): smoothly, or at once for whoever asked the system for less motion (`prefers-reduced-motion: reduce`, read with `matchMedia` because a scroll started from code ignores the stylesheet's media query).

**The notation is read as it is written.** A move's piece is a glyph (a mask on a span) and its quality a badge (an `aria-hidden` SVG): two pictures, which a screen reader skipped, so 17.Td8# was heard as "d8#". The glyph's own text is now the piece's Spanish initial (`piece`, from `buildNotationRows`), pushed out of its box and clipped so only the drawing is seen, and after the move a visually hidden `.chess-board__notation-sr` says the quality in words (`moveQualityLabel`): "T d8#, Mejor jugada". Nothing of what is seen changes.

**Layout.** A `ResizeObserver` on the frame redraws chessground and, from 768 px (the stylesheet's breakpoint; below it the notation is hidden), pins the notation column to the board's height so it scrolls instead of growing. That height is read with `offsetHeight`, not with the bounding rect: a zoom on an ancestor would be inside a rect (the platform carried one until 2026-10-02), and the value is written back as an inline `px` that the zoom would apply a second time. The active notation cell is scrolled into view on every ply change.

**Callbacks by reference.** `onMove` and `onShapesChange` are kept in refs so chessground's handlers, installed once, always call the latest function without re-creating the board.

## Markup & styling

Block `.chess-board` (383 lines).

**Controlled mode has no fill.** Chessground rounds the board down to a whole number of device pixels, so it lands a pixel or two short of the box it is given, and the block's own background showed through as a white rim around it. Standalone keeps the fill, since there it is the card the notation shares.

**The surface takes the width its container gives it.** `.chess-board__surface` is `width: 100%` and square. Until 2026-10-02 it also carried `zoom: calc(1 / var(--platform-zoom, 1))`, to give back the platform's zoom: chessground measures the element with `getBoundingClientRect()` and writes the result back as an inline `px` width, which the zoom applied again, so the board came out a tenth wider than its hole and its pieces drifted off their squares. The platform has no zoom now, so what is measured is what is written. The board's coordinates are the one thing inside drawn at a fixed size, 9px, the platform's one font size off its type scale.

**Elements:** `.chess-board__columns`, `.chess-board__frame`, `.chess-board__surface` (the chessground mount point), `.chess-board__notation`, `.chess-board__notation-rows`, `.chess-board__notation-row`, `.chess-board__notation-number`, `.chess-board__notation-cell`, `.chess-board__notation-quality`, `.chess-board__notation-glyph`, `.chess-board__notation-sr` (the quality in words, visually hidden), `.chess-board__toolbar`, `.chess-board__toolbar-group`, `.chess-board__tool`, `.chess-board__promotion`, `.chess-board__promotion-panel`, `.chess-board__promotion-piece`, `.chess-board__promotion-cancel`

**Modifiers and states:** `.chess-board_mode_controlled` (surface only), `.chess-board__notation-row_striped`, `.chess-board__notation-cell_active`, `.chess-board__notation-cell_empty`, `.chess-board__notation-glyph_kind_{king,queen,rook,bishop,knight}`, `.chess-board__tool_variant_play`, `.chess-board__tool_active`, `.chess-board__tool-icon_flipped`, `.chess-board__promotion-piece_glyph_{w,b}-{queen,rook,bishop,knight}` (the piece SVGs from `public/pieces`)

**Chessground selectors it restyles:** `.cg-wrap`, `.files`, `.ranks`, `.last-move`, `.move-dest`, `.selected`, `.check`, `.oc`. The square colours come from `--board-light` and `--board-dark`, mirrored in `constants/chess-board-colors.const.ts` for the canvas export.

**Tokens:** `--board-dark`, `--board-light`, `--color-primary`, `--foreground` (public site) and `--platform-accent-ink`, `--platform-accent-soft`, `--platform-bg`, `--platform-border`, `--platform-border-strong`, `--platform-surface`, `--platform-surface-neutral`, `--platform-text`, `--platform-text-muted` (platform). The sheet is written so the same block reads its palette from whichever theme is loaded.

**Breakpoints:** `(width < 768px)` stacks the columns and hides the notation, so the board takes the full width above the toolbar.

## Usage

Controlled, from `components/chess/game-viewer/game-viewer.comp.tsx`, where the board is played on only while editing:

```tsx
import { ChessBoard } from "@/components/chess/chess-board.comp";

<ChessBoard
  position={{
    fen,
    lastMove: node?.lastMove,
    check: node?.check ?? false,
    shapes: node ? node.shapes : tree.initialShapes,
  }}
  flipBoard={flipBoard}
  interactive={isEditing}
  onMove={(san) => editing.addMoveAt(currentPath, san)}
  editableShapes={isEditing}
  onShapesChange={(shapes) => editing.updateShapes(currentPath, shapes)}
/>;
```

Standalone, from `components/site/sections/home/teacher/teacher.section.tsx` (through the lazy wrapper):

```tsx
<ChessBoardLazy flipBoard={content.game.flipBoard} pgn={content.game.moves} annotations={content.game.annotations} />
```
