# Routes & URLs

URLs are Spanish because the product is. The single source of truth for private-area hrefs is `lib/platform-routes.ts` (`platformRoutes`, `teacherRoutes`, `staffRoutes`, `homeRouteFor(roles)`); components never build them from strings.

## Public site — `app/(frontend)`

| URL                                               | Rendering                   | Notes                                                                                                                                              |
| ------------------------------------------------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                                               | Static, `revalidate = 3600` | Composed from Payload Globals; regenerated by the Globals' `afterChange` hooks. Visitors with a session cookie are sent to `/entrar` by the proxy. |
| `/blog`, `/blog?categoria=…&pagina=…`             | Dynamic (search params)     | Listing of published article summaries, 9 per page, category filter in the URL.                                                                    |
| `/blog/[slug]`                                    | Dynamic                     | Article with Lexical content and chess blocks; canonical + Open Graph `article`.                                                                   |
| `/nosotros`                                       | Static                      | About page.                                                                                                                                        |
| `/mentor/[slug]`                                  | Dynamic                     | Mentor profile from the `home-mentors` Global, with a lazy board.                                                                                  |
| `/reloj-de-ajedrez`                               | Static                      | Chess clock (client component), one instance chosen by viewport.                                                                                   |
| `/sitemap.xml`, `/robots.txt`, `/opengraph-image` | Generated                   | `app/sitemap.ts`, `app/robots.ts`, `app/(frontend)/opengraph-image.tsx`.                                                                           |

## CMS — `app/(payload)`

| URL      | Notes                                                                                                                                    |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `/admin` | Payload admin UI (its own login, its own users).                                                                                         |
| `/api/*` | Payload REST API. GraphQL is **disabled** (`graphQL: { disable: true }`); the site reads Payload through the local API, never over HTTP. |

## Access — `app/(auth)`

| URL                      | Notes                                                                                                                                                                      |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/iniciar-sesion?next=…` | Login page. A plain server action, so it works without JavaScript. `next` must be an internal path (`safeReturnTo`).                                                       |
| `/entrar`                | Route handler. Reads the real session and redirects to `homeRouteFor(roles)`; if the cookie is stale it deletes it and returns to `/`. `Cache-Control: private, no-store`. |

## Identifiers in URLs

| Entity                | Id                                                                                                                                         | Why                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Course, lesson        | 8 random digits, zero-padded (`/cursos/00020212`, `/lecciones/02482009`), generated by `lib/numeric-id.ts` and used as the **primary key** | Readable, not enumerable, no second column to keep in sync.                                   |
| Chapter (student URL) | Its `order` inside the course (`/cursos/00020212/1`)                                                                                       | It is the number the student sees; reordering reassigns URLs, as expected of an order number. |
| Study, game           | `nanoid(8)` (`/estudios/aB3xK9pQ`)                                                                                                         | Short enough for a URL, generated client-side by Prisma like `uuid()`.                        |
| Everything else       | `uuid()`                                                                                                                                   | Staff URLs keep the internal ids; the two zones have different ids on purpose.                |

## Protection

`constants/platform/auth.const.ts`:

```ts
export const PROTECTED_PATH_PREFIXES = [
  "/inicio",
  "/clases",
  "/estudios",
  "/cursos",
  "/lecciones",
  "/entrenador",
  "/explorador",
  "/profesor",
  "/administracion",
] as const;
```

- `proxy.ts` uses it for the optimistic redirect and repeats it **literally** in `config.matcher` (Next analyses the matcher at build time and discards computed values). `proxy.test.ts` asserts the matcher equals the constant plus `/`.
- `app/robots.ts` disallows the same prefixes plus `/iniciar-sesion`, `/entrar`, `/admin` and `/api`.
- The real check is always the DAL inside the page or action; the proxy cannot distinguish roles or expired sessions.

### Adding a platform route

1. Create the page under `app/(platform)/…`; its first `await` must be a service or `getCurrentUser()` (`requireTeacher()` / `requireStaff()` for the panels).
2. Add a builder to `lib/platform-routes.ts` and use it for every link.
3. If it is a new top-level prefix: add it to `PROTECTED_PATH_PREFIXES` **and** to the `matcher` in `proxy.ts`; run `npm test`.
4. Add it to the navigation in `constants/platform/nav-items.const.ts` only if it is a destination, not a step of another screen.
