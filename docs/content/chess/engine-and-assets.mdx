# Stockfish, pieces & sounds

## Stockfish — `public/engine/`

- `stockfish.js` + `stockfish.wasm`: the **lite, single-threaded** build. Multi-threaded builds need `SharedArrayBuffer`, which requires COOP/COEP headers that would break the Cloudinary images of course covers. The licence (GPL-3.0) is kept next to it in `LICENSE-stockfish.txt`; the engine runs as a separate program in a Web Worker and is not linked with the app's code.
- It is copied into the repo instead of depending on the `stockfish` npm package, which weighs 250 MB because it ships every build.

Update:

```bash
npm install stockfish@<version> --no-save
cp node_modules/stockfish/bin/stockfish-<v>-lite-single.js   public/engine/stockfish.js
cp node_modules/stockfish/bin/stockfish-<v>-lite-single.wasm public/engine/stockfish.wasm
cp node_modules/stockfish/Copying.txt public/engine/LICENSE-stockfish.txt
npm uninstall stockfish
```

### How the app talks to it

Everything that talks UCI goes through **one engine client**, `lib/chess/engine/engine-client.ts` (`createEngineClient(transport)`). It owns the rule that matters: Stockfish aborts (`RuntimeError: unreachable`) if it receives `position` — or `ucinewgame` — while a previous `go` has not answered `bestmove`, and the worker script holds a `setoption` sent mid-search until after the `position` that followed it. So the client sends `position`, `ucinewgame`, `setoption` and `go` only while the engine is idle, one request at a time from a FIFO queue; a request that cannot wait (a new analysis, a new game, new options) sends `stop` and goes when the `bestmove` arrives.

| Method             | What it does                                                                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `ready()`          | Resolves on the boot's `readyok` (`uci` + `isready`). No `UCI_AnalyseMode`: Stockfish 18 has no such option.                                 |
| `setOptions(o)`    | One `setoption` per option (`Hash`, `MultiPV`, `UCI_LimitStrength`, `UCI_Elo`, `Skill Level`, `UCI_ShowWDL`), then `isready`.                |
| `newGame()`        | `ucinewgame` + `isready`: forgets the previous game's hash.                                                                                  |
| `analyse(req, cb)` | Analyses a FEN, calling back with every `EngineInfo`; a newer analysis replaces it. Returns the cancel.                                      |
| `bestMove(req)`    | One move: `{ bestMove, candidates }`, the candidates being the lines of the last complete iteration (`finalCandidates`, `candidate-set.ts`). |
| `terminate()`      | Kills the engine and rejects whatever is pending.                                                                                            |

A budget is a depth, a number of nodes or both (`SearchBudget`); only the full-strength module of the analysis board searches by time (`TimedBudget`), because a bot's strength must not depend on the device. If the engine dies — the worker throws, or the process exits — every pending request is rejected; a search that never answers is taken for dead by a watchdog (four times what its budget should take on a slow phone, never under five seconds), because an iOS worker killed for memory fires no error.

The client reaches the engine through an `EngineTransport` (`lib/chess/engine/engine-transport.ts`): a Web Worker in the browser (`components/chess/engine/worker-transport.ts`, the only place that creates one), and a scripted fake for the tests (`lib/testing/scripted-engine.ts`).

| Hook                      | Engine                                                                    | Depth | Lines         | Use                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------- | ----- | ------------- | ---------------------------------------------------------------------------------------------------------- |
| `use-engine-client.hook`  | creates a worker and its client lazily while `enabled`, kills it when off | —     | —             | The handle the other hooks build on: `{ client, status }`.                                                 |
| `use-engine.hook.ts`      | its own client, or one its caller shares                                  | 20    | 3 (`MultiPV`) | Live analysis of the current position, replaced as the user navigates; feeds the evaluation bar and panel. |
| `use-game-review.hook.ts` | its own client, created by `start`                                        | 16    | 1             | Evaluates every mainline position in series (`bestMove`) for the game review.                              |

Both send `Hash 16` explicitly. `lib/chess/engine-protocol.ts` parses what the engine writes: `parseEngineInfo` (score normalised to White, mate distances, PV as UCI) for the analysis, `parseCandidate` (the mover's centipawns, the mate with its own sign, and whether the score is only a bound) and `parseBestMove` for moves asked for; nothing else in the app reads raw engine output.

A position that is already over is searched at depth 0 and answered at once with `bestmove (none)`. Stalemate prints `info depth 0 score cp 0` without a line; a mate on the board prints `info depth 0 score mate 0`, and that zero has no sign: read as a score it handed the win to the side that is mated, so `parseEngineInfo` returns `null` for it. The review reads the board instead: a stalemate is a draw, and a mate keeps the previous position's figure, the winner's mate in one. The live analysis gets no line either way, so the engine panel reads the board too (`positionOutcome` in `lib/chess/legal-moves.ts`) and says the game is over.

## Pieces — `public/pieces/`

The **cburnett** set (Colin M. L. Burnett, CC BY-SA 3.0) that chessground draws, extracted from `@lichess-org/chessground/assets/chessground.cburnett.css` into twelve standalone SVGs (`w-knight.svg`, `b-queen.svg`, …) so the promotion picker, figurines, static diagrams and image exports show exactly the pieces the board shows.

- Never edit them by hand. `npm run pieces:sync` (`scripts/sync-pieces.ts`) decodes the base64 images from the CSS and adds the `viewBox` the originals lack (without it the SVGs would not scale outside the board). Run it after upgrading chessground; the script fails if it does not find exactly twelve pieces.
- `board-export.ts` reads the pieces from the loaded CSS sheet at export time, not from these files, for the same "always identical" reason.
- Unicode figurines for the hero come from `constants/chess-pieces.const.ts`; figurine notation uses the `ChessGlyph` font.

## Sounds — `public/sounds/`

`move.mp3` and `capture.mp3` are lichess's _standard_ Move and Capture, taken as they are from `lichess-org/lila` (`public/sound/standard/`). lila's `COPYING.md` lists them among its **non-free exceptions**; the decision to use them anyway, the exposure and the way out are written down in the local `WARNINGS.md`. The way out is `scripts/make-board-sounds.ts` (`npm run sounds:make`): **modal synthesis**, a few milliseconds of filtered noise, the strike, ringing a bank of two-pole resonators, the wood, tuned against _measurements_ of the standard recordings (spectral peaks, band energy, time to -20/-30/-40 dB) so the character matches without a single sample of theirs going in; the noise comes from a seeded generator, so the bytes are reproducible. There is deliberately no check sound: a check is a state of the position, not a gesture on the board. Played by `components/chess/game-viewer/move-sound.ts`, loaded lazily, toggled by the viewer preference.

## Fonts — `public/fonts/`

All are woff2 subsets (Latin, punctuation, arrows, check mark) generated with `pyftsubset`; the originals are not in the repository (SF Pro from Apple's site, Gramatika/Suisse in the git history under `public/design-import/`).

| Font                                 | Used by                      | Loaded in                                                                                                                                                                                                                  |
| ------------------------------------ | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Gramatika Bold                       | Public site headings         | `app/(frontend)/fonts.ts`                                                                                                                                                                                                  |
| Suisse Intl (400/500/700)            | Public site text             | `app/(frontend)/fonts.ts`                                                                                                                                                                                                  |
| ChessGlyph                           | Figurine notation            | `app/(frontend)/fonts.ts`, `preload: false`                                                                                                                                                                                |
| SF Pro Display (400/500/600/700/800) | Platform display and text    | `app/(platform)/fonts.ts`, `preload: false` (with Turbopack, every preloaded font is preloaded on every page)                                                                                                              |
| Poppins (600/700)                    | The title of a platform page | `app/(platform)/fonts.ts`, `preload: false`. SIL Open Font License 1.1, whose text travels with the subsets (`public/fonts/poppins-OFL.txt`); the sources are Google Fonts' and are subset with the same `pyftsubset` line |

## Board colours

`--board-light: #eeeed2` and `--board-dark: #769656` in `globals.css`, mirrored in `constants/chess-board-colors.const.ts` for the canvas export, which cannot read CSS variables. Change both together.
