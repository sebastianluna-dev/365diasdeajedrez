# Chess library (`lib/chess`)

Every module here is **pure**: no React, no Prisma, no `server-only` (except where Node's `crypto` is needed). They are unit-tested (`*.test.ts`, fixtures in `lib/chess/__fixtures__/`) and shared by the browser components, the services, the seed and the scripts. The rules engine underneath is [`chessops`](https://github.com/niklasf/chessops); the board is [`@lichess-org/chessground`](https://github.com/lichess-org/chessground).

## Conventions

- **PGN in, positions out.** Nothing stores moves relationally; every consumer parses the PGN it needs.
- **Dotted paths** address a node inside a PGN tree: child indexes from the root, `"0"` is the first move, `"0.0.1.0"` goes down the mainline twice, into the second variation, then one more move. `children[0]` is the mainline by convention (which is what `makePgn` assumes when serialising). Stored in `TrainingExercise.path` and `ClassBlock.movePath`.
- **Paths move.** Deleting or promoting reindexes siblings; hold a node reference and recompute the path with `pathOfNode` after mutating.
- **Spanish SAN for display only.** `sanToSpanish` maps `N→C, B→A, R→T, Q→D, K→R` (and the promotion piece); storage and comparisons keep English SAN.
- **Evaluations are always from White's point of view**, whether they come from the engine or from `[%eval]` comments.

## Typical flows

**Import a PGN into a study**

1. `parseImportedGames(text)` (chessops `parsePgn`) → headers to columns, result token to catalog code, full dates only, Elo/titles/federations.
2. For each game, `indexGamePositions({ gameId, databaseId, pgn }, tx)` → `extractGamePositions` → `GamePosition` rows; replay warnings are logged, not fatal.
3. All inside one `$transaction` with `PGN_IMPORT_TRANSACTION`.

**Mark a lesson trainable**

1. `extractMainline(lessonPgnOf(lesson))` → SANs + initial FEN (null if no moves → rejected).
2. Choose the student's colour (`trainingColorId` or the side to move).
3. `deriveExerciseData({ initialFen, afterSans, lineSans })` → frozen `startFen`, `line`, `path`, plies; stored as a derived `TrainingExercise`.

**Evaluate a game**

1. `replayGame(pgn)` → FEN per ply.
2. A dedicated Stockfish worker analyses each position at depth 16 (`use-game-review.hook.ts`), collecting `MoveEvaluation`s.
3. `reviewGame(positions)` → accuracy, grades, phases; `setEvaluation` can write them back into the PGN as `[%eval]`.
