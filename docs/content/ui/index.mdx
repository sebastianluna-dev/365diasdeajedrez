# UI & styling

How the interface is built: plain CSS with strict BEM, two token sets for two themes, and a small set of shared components.

- [Styling & design tokens](/ui/styling) — the public (dark) and platform (light) stylesheets, which layout loads what, every token and what it is for, fonts, the BEM and nesting rules with examples, global helpers and breakpoints.
- [Shared UI components](/ui/components) — the catalogue of `components/common/`, `components/ui/`, `components/icons/` and the shared sections: what each one is for, its props, whether it is a Server or Client Component, and which one to pick.
