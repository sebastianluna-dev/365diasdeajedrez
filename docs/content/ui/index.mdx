# Styling

How the interface is painted: plain CSS with strict BEM and two token sets for two themes.

- [Styling & design tokens](/ui/styling) — the public (dark) and platform (light) stylesheets, which layout loads what, every token and what it is for, fonts, the BEM and nesting rules with examples, global helpers and breakpoints.

- [Storybook](/ui/storybook) — the pilot setup and, step by step, how a component gets its folder, its story, its controls and its Docs page (done for `PlanCard`).

The components themselves, with their props and importers, are in [Components](/components).
