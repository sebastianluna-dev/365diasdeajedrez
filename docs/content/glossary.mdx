# Glossary

The product speaks Spanish (labels, URLs, catalog labels, error messages) and the code speaks English (models, services, codes, routes builders). This page maps one to the other so you can go from a screenshot or a URL to the right module, and from a model name to what the user calls it.

## Verbs of the interface

One action, one verb, on every screen. The three that are easy to mix up were settled by the owner on 2026-10-01, and `components/ui-verbs.test.ts` fails on the ones that lost.

| Verb                  | What it does                                                                                                                                                                                                                                                                                   | Where                                                                                                                                                | Never                                      |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| **Agregar**           | Puts something into a set that already exists: a game into a study, a course into «Mis cursos», a source, a block, a chapter                                                                                                                                                                   | «Agregar partida», «Agregar a mis cursos», «Agregar fuente»; pending «Agregando…»                                                                    | «Añadir»                                   |
| **Quitar**            | Takes something out of where it is without destroying it: it can be put back                                                                                                                                                                                                                   | «Quitar de mis cursos», an author from a course, a game from a collection, a photo, the date of a field                                              | «Borrar», «Eliminar» for these             |
| **Eliminar**          | Destroys: what goes does not come back                                                                                                                                                                                                                                                         | «Eliminar partida», «Eliminar estudio», «Eliminar mi progreso», a chapter, a lesson; pending «Eliminando…»; the refusal says «No se puede eliminar…» | «Borrar»                                   |
| **Crear**             | Makes something new from nothing                                                                                                                                                                                                                                                               | «Crear ejercicio», a study, a course, an account                                                                                                     | «Agregar» for something that did not exist |
| **Guardar**           | Stores what a form holds                                                                                                                                                                                                                                                                       | «Guardar», «Guardar fuente»; pending «Guardando…», the default of `SubmitButton`                                                                     |                                            |
| **Editar**            | Opens something to change it                                                                                                                                                                                                                                                                   | «Editar», «Editar datos»                                                                                                                             | «Modificar»                                |
| **Subir** / **Bajar** | Moves something one place up or down in an order it has, without dragging                                                                                                                                                                                                                      | A chapter or a lesson in its row's menu, an exercise, a block of a class; «Subir imagen» is the other «subir», to upload                             | «Mover arriba», «Mover abajo»              |
| **Registrar**         | Writes down a fact that happened elsewhere: a payment                                                                                                                                                                                                                                          | «Registrar pago»; pending «Registrando…»                                                                                                             | «Crear pago», «Agregar pago»               |
| **Programar**         | Gives a date to a class a payment covers and has none yet                                                                                                                                                                                                                                      | «Programar clase», a seat «por programar»; pending «Programando…»                                                                                    |                                            |
| **Reprogramar**       | Gives another date to a whole class, or to the seat of a student who missed one                                                                                                                                                                                                                | «Reprogramar», «Reprogramar la plaza»; pending «Reprogramando…»                                                                                      | «Mover», «Cambiar la fecha»                |
| **Cancelar**          | Closes a class for good: history, not destruction; the seats go back to their payments. As the verb of a class it always carries its object («Cancelar la clase»); its confirmation shows the ban sign and its way out says «Volver». The bare «Cancelar» is still the way out of a form popup | «Cancelar la clase»; pending «Cancelando…»                                                                                                           | «Eliminar» a class, «Borrar»               |
| **Finalizar**         | Closes a class that was given, with its attendance                                                                                                                                                                                                                                             | «Finalizar la clase»; pending «Finalizando…»                                                                                                         | «Marcar como terminada», «Cerrar»          |
| **Cambiar**           | Replaces one thing with another: the teacher of a class, its link, a mark of attendance                                                                                                                                                                                                        | «Cambiar profesor», «Cambiar el enlace», «Cambiar asistencia»; pending «Cambiando…»                                                                  | «Corregir», «Modificar»                    |

Two rules go with them:

- **The text of a hint or an error uses the verb of the button it is about**: «Si la eliminas…» under «Eliminar partida», «Un autor no se elimina: se quita de cada curso».
- **The way out of a confirmation never says the same word as its button**: a confirmation of «Cancelar la clase» exits with «Volver» (`exitLabel`), so «Cancelar» is never both the question and the answer.
- **«Eliminar» asks first, and so does a «Quitar» that takes progress along**: through [`PlatformConfirmPopup`](/components/platform/shared/platform-confirm-popup), opened on top of whatever popup is open, with the verb on its button and, when the server requires it, a box to tick. Nothing destroys on one press (the destructive actions still without it are listed in `IMPROVEMENTS.md`).
- **While a form is on its way, its button says what is happening**: a gerund and «…» (`pendingLabel="Eliminando…"`). The one exception is a form with several submit buttons that share a label, which passes the resting label so the text does not change on every row at once (the attendance list); the test names it.

«Borrador» is a draft — a course's status — and has nothing to do with «borrar».

## Chess terms used in the code

| Term                                    | Meaning here                                                                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PGN**                                 | Portable Game Notation: headers in brackets plus movetext with variations, comments and NAGs. The stored content of lessons, games and class blocks. Parsed by `chessops/pgn` through `lib/chess/pgn-tree.ts` (read) and `pgn-edit.ts` (write).                                                                                                                                                                   |
| **Movetext**                            | The moves part of a PGN without headers. `plainMovetext` produces a clean mainline; `movetext-scan` finds malformed tokens.                                                                                                                                                                                                                                                                                       |
| **FEN**                                 | Forsyth–Edwards Notation of a position. `initialFen` on games, `startFen` on exercises, `fen` on saved positions and on every replayed ply.                                                                                                                                                                                                                                                                       |
| **Normalised FEN**                      | The first four FEN fields (placement, side to move, castling, en passant), without move counters, so transpositions match. `normalizePositionFen`.                                                                                                                                                                                                                                                                |
| **Position hash**                       | SHA-256 of the normalised FEN (`createPositionHash`), computed on the server. Identity of a position in `GamePosition` and `TrainingMistake`.                                                                                                                                                                                                                                                                     |
| **SAN**                                 | Standard Algebraic Notation of a move (`Nf3`, `exd5`, `O-O`). Stored in English; shown in Spanish (`Cf3`, `Axf3`) by `sanToSpanish`. Comparisons ignore `+ # ! ?`.                                                                                                                                                                                                                                                |
| **UCI**                                 | Long algebraic move (`g1f3`, `e7e8q`) used to talk to Stockfish and stored as `nextMoveUci` in the position index.                                                                                                                                                                                                                                                                                                |
| **Ply**                                 | A half-move. In the PGN tree the ply is **absolute and 1-based**, derived from the start FEN: `Math.ceil(ply / 2)` is the move number and odd plies are White (move 12 by White is ply 23, by Black ply 24). Exercises store `startPly`/`endPly` in that scale. The position index (`extractGamePositions`) numbers **positions** from 0, the starting position, so its `ply` is the number of half-moves played. |
| **Mainline**                            | The principal sequence of a game: at every node, `children[0]`. `extractMainline`, `mainlinePath`.                                                                                                                                                                                                                                                                                                                |
| **Variation**                           | A sideline: any child other than the first. Can be promoted one step or to the mainline with `promoteOneStep` / `promoteToMainLine`.                                                                                                                                                                                                                                                                              |
| **Dotted path**                         | Address of a node inside a PGN tree as child indexes from the root: `"0.0.1.0"`. Used by `TrainingExercise.path` and `ClassBlock.movePath`. Paths move when siblings are deleted or promoted.                                                                                                                                                                                                                     |
| **NAG**                                 | Numeric Annotation Glyph (`$1` = `!`, `$2` = `?`, `$14` = ⩲…). Move-quality and position NAGs are mapped in `pgn-tree.ts`; the viewer shows them as glyphs and colours.                                                                                                                                                                                                                                           |
| **Move quality**                        | `MoveQuality` in `lib/chess/types.ts`: `brilliant`, `great`, `best`, `excellent`, `good`, `book`, `inaccuracy`, `mistake`, `miss`, `blunder`. The blog's featured games carry them as `MoveAnnotations` keyed `"12w"`/`"12b"`; the game review grades with the four-level subset `good`, `inaccuracy`, `mistake`, `blunder`.                                                                                      |
| **Evaluation**                          | Engine score from White's point of view: centipawns or mate-in-N, parsed by `engine-protocol.ts`; `[%eval]` comments in a PGN carry the same.                                                                                                                                                                                                                                                                     |
| **Game review**                         | Analysis of every mainline position at depth 16 followed by Lichess' accuracy formulas (`game-review.ts`): win percentage per ply, per-move grade, per-player accuracy.                                                                                                                                                                                                                                           |
| **MultiPV**                             | Stockfish option that returns several best lines; the analysis panel asks for 3.                                                                                                                                                                                                                                                                                                                                  |
| **Shapes**                              | chessground arrows and circles. Stored in PGN comments as `[%cal]` (arrows) and `[%csl]` (squares); saved positions store them as JSON.                                                                                                                                                                                                                                                                           |
| **Orientation**                         | Which colour sits at the bottom of the board.                                                                                                                                                                                                                                                                                                                                                                     |
| **ECO**                                 | Encyclopaedia of Chess Openings code (`B90`). A game header stored as a column.                                                                                                                                                                                                                                                                                                                                   |
| **Elo**, **FIDE title**, **federation** | Player rating, title (`GM`, `IM`, `WFM`…) and FIDE three-letter country code (`MEX`, `ESP`, `SUI`), stored per colour on `Game` and shown with flags by `lib/chess/federations.ts`.                                                                                                                                                                                                                               |
| **Figurine**                            | Piece symbols in notation (♘f3) rendered with the ChessGlyph font.                                                                                                                                                                                                                                                                                                                                                |
| **cburnett**                            | The piece set drawn by chessground and extracted to `public/pieces/`.                                                                                                                                                                                                                                                                                                                                             |
